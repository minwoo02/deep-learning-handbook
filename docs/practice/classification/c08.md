---

## 1. 모델 전체 코드

```python
import torch.nn as nn

class XORModel(nn.Module):
    def __init__(self):
        super().__init__()
        self.linear1 = nn.Linear(2, 4)
        self.relu = nn.ReLU()
        self.linear2 = nn.Linear(4, 1)

    def forward(self, x):
        x = self.linear1(x)
        x = self.relu(x)
        x = self.linear2(x)
        return x
```

---

## 2. `__init__` 메서드: 모델의 "부품" 정의하기

모델 객체가 생성될 때 내부적으로 사용할 계층(Layer)과 활성화 함수들을 초기화하고 준비하는 부분입니다.

- **`super().__init__()`**

  - PyTorch의 모든 신경망 모델이 상속받아야 하는 `nn.Module`의 기본 설정(가중치 추적, 파라미터 관리 등)을 초기화합니다. 필수적으로 호출해야 합니다.
- **`self.linear1 = nn.Linear(2, 4)`** (은닉층 - Hidden Layer)

  - 입력 데이터를 받아 가중치 곱과 편향 더하기 연산을 수행하는 첫 번째 선형 계층입니다.
  - `2`: 입력 데이터의 차원 수입니다. (XOR 연산은 2개의 값을 입력받으므로 차원이 2입니다).
  - `4`: 출력 차원 수입니다. 2개의 입력값을 4개의 노드로 확장하여 데이터의 숨겨진 특징을 학습할 수 있게 합니다.
- **`self.relu = nn.ReLU()`** (활성화 함수 - Activation Function)

  - 선형 연산의 결과에 비선형성을 더해주는 활성화 함수입니다.
  - 입력이 0 미만이면 0을, 0 이상이면 그대로 통과시킵니다. 이 비선형성 덕분에 신경망이 XOR 같은 복잡한 문제를 풀 수 있게 됩니다.
- **`self.linear2 = nn.Linear(4, 1)`** (출력층 - Output Layer)

  - 최종 예측값을 계산하는 두 번째 선형 계층입니다.
  - 은닉층에서 전달받은 `4`개의 특징을 종합하여, 최종적으로 정답에 해당하는 `1`개의 출력값으로 압축합니다.

---

## 3. `forward` 메서드: 데이터의 "흐름" 정의하기 (순전파)

`__init__`에서 준비한 부품들을 사용하여, 실제 입력 데이터(`x`)가 들어왔을 때 어떤 순서로 연산을 거쳐 최종 결과를 내놓을지 그 흐름(순전파, Forward Propagation)을 정의합니다.

1. **`x = self.linear1(x)`**: 2차원 입력값이 가중치 행렬과 연산되어 4차원 데이터로 변환됩니다.
2. **`x = self.relu(x)`**: 앞서 계산된 값들에 ReLU 함수를 적용하여 비선형적인 특징을 살려줍니다 (음수는 모두 0으로 처리).
3. **`x = self.linear2(x)`**: ReLU를 통과한 4차원 데이터가 마지막 선형 연산을 거쳐 최종 1차원의 예측값으로 출력됩니다.
4. **`return x`**: 최종 연산 결과를 반환합니다.
