scikit-learn의 `MLPClassifier`를 사용하면 다음 한 줄로 모델을 학습할 수 있다.

```python
model.fit(X_train, y_train)
```

사용하기는 매우 편하지만, 실제로 신경망 내부에서 어떤 과정이 일어나는지는 잘 보이지 않는다.

PyTorch에서는 신경망의 구조와 Training Loop를 직접 작성하기 때문에

- Linear Layer
- Activation Function
- Loss Function
- Backpropagation
- Optimizer

가 코드에서 어떻게 연결되는지 직접 확인할 수 있다.

### 이번 실습의 모델 및 구현 구성

이번 실습에서는 PyTorch를 이용하여 **Multi-Layer Perceptron(MLP)** 을 직접 구현하고, Iris Dataset을 이용한 Multiclass Classification을 수행한다.

`nn.Module`을 상속하여 Neural Network를 정의하고, `nn.Linear`와 `nn.ReLU`를 이용해 모델을 구성한다. 이후 Loss Function과 Optimizer를 사용하여 모델을 학습하는 과정을 살펴본다.

| 항목 | 사용 기술 및 구성 | 역할 |
| --- | --- | --- |
| Framework | PyTorch | Neural Network 구현 및 학습 |
| Dataset | Iris Dataset | 3개 Class 분류 |
| Task | Multiclass Classification | 입력 Feature를 3개 Class 중 하나로 분류 |
| Model Architecture | MLP (Multi-Layer Perceptron) | Fully Connected Neural Network |
| Model Definition | `nn.Module` 상속 | 사용자 정의 모델 구현 |
| Input Layer | 4 Features | 입력 데이터 처리 |
| Hidden Layer | `nn.Linear(4, 100)` | 100차원 Hidden Representation 생성 |
| Activation Function | `nn.ReLU()` | Non-linearity 추가 |
| Output Layer | `nn.Linear(100, 3)` | 3개 Class에 대한 Logit 출력 |
| Loss Function | `nn.CrossEntropyLoss()` | Multiclass Classification Loss 계산 |
| Optimizer | `torch.optim.Adam` | Model Parameter 업데이트 |
| Learning Rate | `0.001` | Parameter Update 크기 조절 |
| Training Epochs | `100` | 전체 Training Dataset 반복 학습 |

#### MLP 모델 구조

```text
Input Layer
(4 Features)
      │
      ▼
Linear Layer
(4 → 100)
      │
      ▼
ReLU Activation
      │
      ▼
Linear Layer
(100 → 3)
      │
      ▼
Output Layer
(3 Class Logits)
      │
      ▼
CrossEntropyLoss
```

이번 실습에서 구분해야 할 핵심 개념은 다음과 같다.

- **MLP**는 여러 Fully Connected Layer로 구성된 Neural Network Architecture이다.
- **`nn.Module`**은 PyTorch에서 사용자 정의 Neural Network를 구현하기 위한 기본 클래스이다.
- **`nn.Linear`**는 Input Feature에 Weight와 Bias를 적용하는 선형 변환 Layer이다.
- **ReLU**는 Hidden Layer에 Non-linearity를 추가하는 Activation Function이다.
- **CrossEntropyLoss**는 모델이 출력한 Logit과 실제 Class Label을 비교하여 Loss를 계산한다.
- **Adam**은 Backpropagation으로 계산된 Gradient를 이용하여 Model Parameter를 업데이트하는 Optimizer이다.

따라서 이번 글의 핵심은 **MLP의 구조를 직접 정의하고, Forward Propagation부터 Loss Calculation, Backpropagation, Parameter Update까지 이어지는 Neural Network의 학습 과정을 구현하는 것**이다.

## 1. 필요한 라이브러리

```python

import torch.optim as optim

from sklearn.datasets import load_iris

from sklearn.preprocessing import StandardScaler
```

각 라이브러리의 역할은 다음과 같다.

```text
torch
→ Tensor 연산

torch.nn
→ Neural Network 구성

torch.optim
→ Optimizer

scikit-learn
→ Dataset / Preprocessing / Evaluation
```

## 6. Neural Network Class 정의

```python
class PyTorchMLP(nn.Module):

    def __init__(
        self,
        input_dim,
        hidden_dim,
        output_dim,
    ):
        super(PyTorchMLP, self).__init__()

        self.fc1 = nn.Linear(
            input_dim,
            hidden_dim
        )

        self.relu = nn.ReLU()

        self.fc2 = nn.Linear(
            hidden_dim,
            output_dim
        )
```

PyTorch의 Neural Network는 일반적으로

```python
nn.Module
```

을 상속받아 만든다.

---

## 7. nn.Linear

```python
self.fc1 = nn.Linear(
    input_dim,
    hidden_dim
)
```

`nn.Linear`는 기본적으로 다음 연산을 수행한다.

$$
\mathbf{z} = \mathbf{W}\mathbf{x}+\mathbf{b}
$$

즉 앞에서 계속 살펴본

- Weight
- Bias
- Matrix Multiplication

이 들어 있는 Layer이다.

---

## 8. ReLU

```python
self.relu = nn.ReLU()
```

비선형 활성화 함수 ReLU를 정의한다.

$$
ReLU(x)=\max(0,x)
$$

Linear Layer 사이에 ReLU가 들어가면서 신경망에 Non-linearity가 추가된다.

---

## 9. Output Layer

```python
self.fc2 = nn.Linear(
    hidden_dim,
    output_dim
)
```

Hidden Representation을 최종 Output Dimension으로 변환한다.

Iris Dataset의 경우 Class가 세 개이므로

```python
output_dim=3
```

을 사용할 수 있다.

---

## 10. forward()

```python
def forward(self, x):

    out = self.fc1(x)
    out = self.relu(out)
    out = self.fc2(out)

    return out
```

`forward()`는 데이터가 모델 내부를 어떻게 통과하는지 정의한다.

구조는 다음과 같다.

```text
Input
  ↓
fc1
  ↓
ReLU
  ↓
fc2
  ↓
Output
```

수식으로는 다음과 같이 볼 수 있다.

$$
\mathbf{z}_1 = \mathbf{W}_1\mathbf{x} + \mathbf{b}_1
$$

$$
\mathbf{a}_1 = ReLU(\mathbf{z}_1)
$$

$$
\mathbf{z}_2 = \mathbf{W}_2\mathbf{a}_1 + \mathbf{b}_2
$$

---

## 11. Model 생성

```python
model = PyTorchMLP(
    input_dim=4,
    hidden_dim=100,
    output_dim=3
)
```

Iris Dataset에는 Feature가 네 개이므로

```text
input_dim = 4
```

Hidden Layer에는 100개의 뉴런을 사용하고

```text
hidden_dim = 100
```

Class는 세 개이므로

```text
output_dim = 3
```

이다.

## 12. Loss Function

```python
criterion = nn.CrossEntropyLoss()
```

다중 분류 문제를 위한 Loss Function으로 Cross Entropy를 사용한다.

Training 과정에서

```python
outputs = model(X_train_tensor)
```

로 얻은 모델 출력과

```python
y_train_tensor
```

의 실제 Label을 비교하여 Loss를 계산한다.

---

## 13. Optimizer

```python
optimizer = optim.Adam(
    model.parameters(),
    lr=0.01
)
```

Adam Optimizer를 생성한다.

```python
model.parameters()
```

에는 모델이 학습해야 하는 Weight와 Bias가 포함된다.

즉 Optimizer는 이 Parameter들을 업데이트한다.

`lr`은 Learning Rate이다.

```python
lr=0.01
```

---

## 14. Training Loop

PyTorch에서 가장 중요한 부분이다.

```python
epochs = 100

for epoch in range(epochs):

    outputs = model(X_train_tensor)

    loss = criterion(
        outputs,
        y_train_tensor
    )

    optimizer.zero_grad()

    loss.backward()

    optimizer.step()
```

이 짧은 코드에 신경망 Training의 핵심 과정이 모두 들어 있다.

---

## 15. Forward Propagation

```python
outputs = model(X_train_tensor)
```

Training Data를 Network에 입력한다.

내부적으로

```text
Linear
↓
ReLU
↓
Linear
```

연산을 수행한다.

이것이 Forward Propagation이다.

---

## 16. Loss Calculation

```python
loss = criterion(
    outputs,
    y_train_tensor
)
```

예측값과 실제 Label을 비교하여 Loss를 계산한다.

```text
Prediction
     ↓
Actual Label
     ↓
Loss
```

---

## 17. optimizer.zero_grad()

```python
optimizer.zero_grad()
```

이전에 계산되어 Parameter에 저장되어 있던 Gradient를 초기화한다.

PyTorch에서는 Gradient가 누적될 수 있기 때문에 새로운 Backpropagation을 수행하기 전에 초기화한다.

---

## 18. loss.backward()

```python
loss.backward()
```

Backpropagation을 수행한다.

Loss에서 시작하여 Network의 각 Parameter에 대한 Gradient를 계산한다.

개념적으로

$$
\frac{\partial L}{\partial W}
$$

와

$$
\frac{\partial L}{\partial b}
$$

를 계산하는 과정이다.

---

## 19. optimizer.step()

```python
optimizer.step()
```

계산된 Gradient를 이용하여 실제 Parameter를 수정한다.

즉

```text
Weight Update
Bias Update
```

가 이루어진다.

---

## 20. PyTorch Training의 핵심 3줄

다음 세 줄은 PyTorch Training에서 매우 자주 등장한다.

```python
optimizer.zero_grad()
loss.backward()
optimizer.step()
```

각각의 의미는 다음과 같다.

```text
zero_grad()
→ 이전 Gradient 초기화

backward()
→ Gradient 계산

step()
→ Parameter 업데이트
```

이 흐름을 반드시 구분해서 이해할 필요가 있다.

## 24. scikit-learn과 PyTorch의 차이

scikit-learn에서는 다음 한 줄을 사용한다.

```python
model.fit(X_train, y_train)
```

이 안에서

```text
Forward
↓
Loss
↓
Backpropagation
↓
Optimizer
↓
Parameter Update
```

가 자동으로 수행된다.

반면 PyTorch에서는 이를 직접 작성한다.

```python
outputs = model(X_train_tensor)

loss = criterion(
    outputs,
    y_train_tensor
)

optimizer.zero_grad()
loss.backward()
optimizer.step()
```

### 핵심 정리

scikit-learn에서는 `fit()` 한 줄로 감춰져 있던 신경망 학습 과정이 PyTorch에서는 코드에 직접 나타난다.

특히 다음 세 줄은 Backpropagation 기반 Training의 핵심이다.

```python
optimizer.zero_grad()
loss.backward()
optimizer.step()
```

이를 각각

```text
Gradient 초기화
→
Gradient 계산
→
Parameter 업데이트
```

로 이해하면 된다.

앞에서 이론으로 배운

$$
\boxed{ \text{Forward} \rightarrow \text{Loss} \rightarrow \text{Backward} \rightarrow \text{Update} }
$$

라는 Training Loop가 실제 코드에서 그대로 구현되어 있는 것이다.
