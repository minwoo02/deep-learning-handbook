# 1. Iris Dataset

Iris Dataset은 붓꽃(Iris)의 꽃받침과 꽃잎 크기를 이용하여 붓꽃의 품종을 구분하는 대표적인 Classification Dataset이다.

전체 150개의 Sample로 구성되어 있으며, 각 Sample은 4개의 Feature를 가진다.

## 1.1 Input Features

| Feature | 의미 |
| --- | --- |
| Sepal Length | 꽃받침 길이 |
| Sepal Width | 꽃받침 너비 |
| Petal Length | 꽃잎 길이 |
| Petal Width | 꽃잎 너비 |

따라서 하나의 Sample은 다음과 같은 Feature Vector로 표현할 수 있다.

$$
\boxed{ \mathbf{x} = \begin{bmatrix} x_1\\ x_2\\ x_3\\ x_4 \end{bmatrix} }
$$

각 Feature는 꽃의 물리적인 크기를 나타내며, 단위는 cm이다.

## 1.2 Target Classes

Iris Dataset에서는 붓꽃을 세 가지 품종으로 분류한다.

| Class Index | Class Name |
| --- | --- |
| 0 | Setosa |
| 1 | Versicolor |
| 2 | Virginica |

각 Class에는 50개의 Sample이 존재한다.

따라서 전체 데이터는 다음과 같다.

$$
\boxed{ N=150 }
$$

$$
\boxed{ N_{\mathrm{features}}=4 }
$$

$$
\boxed{ N_{\mathrm{classes}}=3 }
$$

모델은 4개의 Feature를 입력받아 세 가지 품종 중 하나를 예측해야 한다.

즉 다음과 같은 문제이다.

$$
\boxed{ f:\mathbb{R}^{4}\rightarrow\mathbb{R}^{3} }
$$

여기서 모델의 출력은 각 Class에 대한 Score를 나타내며, 최종적으로 가장 높은 Score를 갖는 Class를 선택한다.

# 2. Dataset과 DataLoader

PyTorch에서는 데이터를 모델에 입력하기 위해 주로 `Dataset`과 `DataLoader`를 함께 사용한다.

두 객체는 서로 다른 역할을 가진다.

**Dataset**

개별 Sample과 Label을 관리하고, 특정 인덱스에 해당하는 데이터를 반환한다.

**DataLoader**

Dataset에서 여러 Sample을 가져와 Mini-batch 단위로 묶어 모델에 공급한다.

두 객체의 관계는 다음과 같다.

```text
Raw Data
    │
    ▼
Dataset
    │
    ├── Sample 0
    ├── Sample 1
    ├── Sample 2
    ├── ...
    └── Sample N
    │
    ▼
DataLoader
    │
    ├── Batch 1
    ├── Batch 2
    ├── Batch 3
    └── ...
    │
    ▼
Neural Network
```

즉 Dataset은 **개별 데이터를 어떻게 가져올 것인가**를 정의하고, DataLoader는 **그 데이터를 어떤 단위와 순서로 모델에 전달할 것인가**를 담당한다.

# 3. Custom Dataset 구현

PyTorch에서는 `torch.utils.data.Dataset`을 상속하여 사용자 정의 데이터셋을 만들 수 있다.

일반적으로 다음 세 가지 메서드를 구현한다.

| 메서드 | 역할 |
| --- | --- |
| `__init__()` | 데이터 로딩 및 초기화 |
| `__len__()` | Dataset의 Sample 수 반환 |
| `__getitem__()` | 특정 인덱스의 Sample 반환 |

특히 `__len__()`과 `__getitem__()`은 Custom Dataset을 구현할 때 중요한 메서드이다.

---

## 3.1 IrisDataset 클래스 구현

Scikit-learn에서는 `load_iris()`를 이용하여 Iris Dataset을 불러올 수 있다.

```python
import torch

from torch.utils.data import Dataset
from sklearn.datasets import load_iris


class IrisDataset(Dataset):

    def __init__(self, transform=None):

        iris = load_iris()

        self.X = torch.tensor(
            iris.data,
            dtype=torch.float32,
        )

        self.y = torch.tensor(
            iris.target,
            dtype=torch.long,
        )

        self.transform = transform

    def __len__(self):
        return len(self.X)

    def __getitem__(self, idx):

        X = self.X[idx]
        y = self.y[idx]

        if self.transform is not None:
            X = self.transform(X)

        return X, y
```

이 클래스를 구성하는 각 메서드를 살펴보자.

---

## 3.2 **init**(): 데이터 로딩 및 초기화

```python
def __init__(self, transform=None):

    iris = load_iris()

    self.X = torch.tensor(
        iris.data,
        dtype=torch.float32,
    )

    self.y = torch.tensor(
        iris.target,
        dtype=torch.long,
    )

    self.transform = transform
```

`__init__()`은 `IrisDataset`의 인스턴스를 생성할 때 실행된다.

먼저 다음 코드를 통해 Iris Dataset을 불러온다.

```python
iris = load_iris()
```

`load_iris()`에서 반환한 객체는 Feature Data와 Target Label을 포함한다.

주요 데이터는 다음과 같다.

```python
iris.data
```
```python
iris.target
```

`iris.data`는 입력 Feature를 나타내고, `iris.target`은 각 Sample의 Class Index를 나타낸다.

이후 NumPy 배열을 PyTorch Tensor로 변환한다.

```python
self.X = torch.tensor(
    iris.data,
    dtype=torch.float32,
)
```

여기서 `torch.float32`를 사용하는 이유는 신경망의 Weight와 입력 Tensor가 일반적으로 부동소수점 연산을 수행하기 때문이다.

Target은 다음과 같이 변환한다.

```python
self.y = torch.tensor(
    iris.target,
    dtype=torch.long,
)
```

여기서 `torch.long`은 일반적으로 64-bit Integer에 해당한다.

다중 분류에서 `nn.CrossEntropyLoss`에 Class Index를 전달하는 경우 Target은 정수형 Tensor여야 하며, 일반적으로 `torch.long`을 사용한다.

---

## 3.3 **len**(): Sample 개수 반환

```python
def __len__(self):
    return len(self.X)
```

`__len__()`은 데이터셋에 포함된 Sample의 개수를 반환한다.

따라서 다음 코드로 데이터셋의 크기를 확인할 수 있다.

```python
dataset = IrisDataset()

print(len(dataset))
```

출력:

```text
150
```

즉 Iris Dataset에는 총 150개의 Sample이 존재한다.

---

## 3.4 **getitem**(): 개별 Sample 반환

```python
def __getitem__(self, idx):

    X = self.X[idx]
    y = self.y[idx]

    if self.transform is not None:
        X = self.transform(X)

    return X, y
```

`__getitem__()`은 특정 Index에 해당하는 입력 데이터와 Label을 반환한다.

예를 들어 다음과 같이 사용할 수 있다.

```python
X, y = dataset[0]
```

이때

```python
X
```

는 첫 번째 Sample의 Feature Vector이며,

```python
y
```

는 해당 Sample의 Class Index이다.

`transform`이 지정되어 있다면 반환하기 전에 입력 Feature에 변환을 적용한다.

```python
if self.transform is not None:
    X = self.transform(X)
```

즉 다음 순서로 동작한다.

```text
dataset[idx]
     │
     ▼
self.X[idx]
     │
     ▼
self.y[idx]
     │
     ▼
Transform 적용
     │
     ▼
(X, y) 반환
```

여기서는 입력 Feature인 `X`에만 Transform을 적용한다.

Target인 `y`는 변경하지 않는다.

# 5. Train / Validation / Test Split

머신러닝에서는 전체 데이터를 일반적으로 다음 세 부분으로 나눈다.

1. Training Set
2. Validation Set
3. Test Set

각 Dataset은 서로 다른 목적을 가진다.

| Dataset | 목적 |
| --- | --- |
| Training Set | 모델의 Parameter 학습 |
| Validation Set | Hyperparameter 조정 및 모델 선택 |
| Test Set | 최종 일반화 성능 평가 |

특히 Test Set은 최종 평가에 사용해야 하므로 모델 학습이나 Hyperparameter 선택 과정에서 사용하지 않는 것이 중요하다.

---

## 5.1 데이터 분할 비율

전체 Iris Dataset은 150개의 Sample로 구성된다.

여기서는 다음 비율로 나눈다.

| Dataset | 비율 | Sample 수 |
| --- | --- | --- |
| Training | 60% | 90 |
| Validation | 20% | 30 |
| Test | 20% | 30 |
| Total | 100% | 150 |

수식으로 나타내면

$$
N_{\mathrm{train}}=150\times0.6=90
$$

$$
N_{\mathrm{val}}=150\times0.2=30
$$

$$
N_{\mathrm{test}}=150\times0.2=30
$$

이다.

# 6. Stratified Sampling

Iris Dataset은 3-Class Classification Dataset이다.

따라서 데이터를 무작위로 분할할 때 Class의 비율이 달라질 수 있다.

예를 들어 Training Set에 Setosa가 지나치게 많이 포함되고 Virginica가 적게 포함되면 학습 데이터의 Class 분포가 원본 데이터와 달라진다.

이러한 문제를 줄이기 위해 **Stratified Sampling(계층적 샘플링)** 을 사용할 수 있다.

Stratified Sampling은 원본 데이터의 Class 비율을 최대한 유지하면서 데이터를 분할하는 방법이다.

Scikit-learn의 `train_test_split()` 함수에서는 `stratify` 옵션을 사용한다.

---

## 6.1 train_test_split() 사용하기

```python
from sklearn.model_selection import train_test_split


seed = 23

dataset = IrisDataset()

labels = dataset.y.numpy()

indices = list(
    range(len(dataset))
)


train_indices, test_indices = train_test_split(
    indices,
    test_size=0.2,
    random_state=seed,
    stratify=labels,
)


train_indices, val_indices = train_test_split(
    train_indices,
    test_size=0.25,
    random_state=seed,
    stratify=labels[train_indices],
)
```

이 코드에서는 `train_test_split()`을 두 번 사용한다.

---

## 6.2 첫 번째 분할

```python
train_indices, test_indices = train_test_split(
    indices,
    test_size=0.2,
    random_state=seed,
    stratify=labels,
)
```

첫 번째 분할에서는 전체 Dataset의 20%를 Test Set으로 사용한다.

따라서

$$
150\times0.2=30
$$

개의 Sample이 Test Set에 포함된다.

나머지 120개 Sample은 일단 `train_indices`에 저장된다.

```text
Original Dataset: 150
        │
        ├── 120 Samples
        │
        └── 30 Samples → Test
```

`random_state=seed`는 데이터 분할 결과를 재현할 수 있도록 난수 상태를 고정하는 역할을 한다.

`stratify=labels`는 전체 Dataset의 Class 비율을 유지하도록 한다.

---

## 6.3 두 번째 분할

```python
train_indices, val_indices = train_test_split(
    train_indices,
    test_size=0.25,
    random_state=seed,
    stratify=labels[train_indices],
)
```

두 번째 분할에서는 남아 있는 120개 Sample을 다시 나눈다.

이때

```python
test_size=0.25
```

로 설정한 이유는 Validation Set이 전체 Dataset의 20%가 되도록 하기 위해서이다.

첫 번째 분할 이후 전체 데이터의 80%가 남아 있으므로

$$
0.8\times0.25=0.2
$$

이다.

따라서 Validation Set은

$$
120\times0.25=30
$$

개의 Sample을 가지게 된다.

나머지 90개 Sample은 Training Set으로 사용한다.

최종 결과는 다음과 같다.

```text
Original Dataset: 150
        │
        ├── Training: 90
        │
        ├── Validation: 30
        │
        └── Test: 30
```

---

# 7. Standardization

신경망을 학습할 때는 입력 Feature들의 Scale을 적절하게 조절하는 것이 중요하다.

예를 들어 하나의 Feature는 0~1의 범위를 가지지만 다른 Feature는 0~10000의 범위를 가진다고 하자.

이러한 경우 Feature마다 수치적인 크기가 크게 다르기 때문에 최적화 과정에 영향을 줄 수 있다.

이를 해결하기 위한 대표적인 전처리 방법이 **Standardization(표준화)** 이다.

---

## 7.1 Standardization의 수학적 정의

Standardization은 각 Feature에 대해 평균을 빼고 표준편차로 나누는 과정이다.

$$
\boxed{ z=\frac{x-\mu}{\sigma} }
$$

여기서

- $x$: 원본 Feature 값
- $\mu$: Feature의 평균
- $\sigma$: Feature의 표준편차
- $z$: 표준화된 Feature 값

이다.

표준화를 수행하면 Training Data의 각 Feature가 평균 0, 표준편차 1에 가까운 분포를 갖도록 변환된다.

주의할 점은 Validation Set과 Test Set은 Training Set에서 계산한 평균과 표준편차를 사용하므로, 각각의 평균이 반드시 0이 되는 것은 아니라는 것이다.

---

## 7.2 Training Set에서만 통계량을 계산해야 하는 이유

데이터 표준화에서 중요한 개념은 **Data Leakage(데이터 누수)** 이다.

Data Leakage는 학습 과정에서 사용해서는 안 되는 정보가 모델의 학습 또는 모델 선택 과정에 유입되는 현상이다.

예를 들어 전체 Dataset으로 평균과 표준편차를 계산하면 Validation Set과 Test Set의 정보가 전처리 과정에 포함된다.

```python
# 권장하지 않는 방식

mean = dataset.X.mean(dim=0)

std = dataset.X.std(dim=0)
```

이 경우 모델을 학습하기 전에 이미 Test Set의 통계적인 정보가 전처리 과정에 반영된다.

따라서 표준화에 사용할 평균과 표준편차는 **Training Set에서만 계산해야 한다.**

---

## 7.3 Training Set의 평균과 표준편차 계산

```python
X_train = dataset.X[
    train_indices
]

mean = X_train.mean(
    dim=0
)

std = X_train.std(
    dim=0
)
```

여기서 `X_train`의 Shape는 다음과 같다.

```text
torch.Size([90, 4])
```

각 Feature별 평균을 계산하므로

```python
mean = X_train.mean(dim=0)
```

의 결과는 4개의 값을 가진다.

표준편차도 마찬가지이다.

```python
std = X_train.std(dim=0)
```

Shape를 확인하면 다음과 같다.

```python
print(mean.shape)
print(std.shape)
```

출력:

```text
torch.Size([4])
torch.Size([4])
```

즉 각각의 Feature에 대한 평균과 표준편차가 계산된다.

$$
\boldsymbol{\mu} = \begin{bmatrix} \mu_1\\ \mu_2\\ \mu_3\\ \mu_4 \end{bmatrix}
$$

$$
\boldsymbol{\sigma} = \begin{bmatrix} \sigma_1\\ \sigma_2\\ \sigma_3\\ \sigma_4 \end{bmatrix}
$$

이다.

---

# 8. Transformer 구현

계산한 평균과 표준편차를 이용하여 입력 Feature를 표준화하는 Transform을 구성할 수 있다.

원본 예제에서는 `torchvision.transforms.Lambda`를 사용한다.

```python
from torchvision import transforms

transform = transforms.Lambda(
    lambda x: (x - mean) / std
)
```

`transforms.Lambda`는 사용자가 정의한 함수를 Callable Transform 객체로 만든다.

따라서 다음과 같이 사용할 수 있다.

```python
X, y = dataset[0]

X_scaled = transform(X)
```

여기서 각 Feature는 다음과 같이 표준화된다.

$$
x_i' = \frac{x_i-\mu_i}{\sigma_i}
$$

---

## 8.1 Lambda Expression이란?

다음 코드를 살펴보자.

```python
lambda x: (x - mean) / std
```

`lambda`는 Python에서 간단한 함수를 표현하기 위한 문법이다.

위 코드는 다음 함수와 동일한 역할을 한다.

```python
def standardize(x):
    return (x - mean) / std
```

따라서 다음 두 표현은 동일한 표준화 연산을 수행한다.

```python
transform = lambda x: (x - mean) / std
```
```python
def transform(x):
    return (x - mean) / std
```

Iris Dataset처럼 일반적인 Feature Vector에 간단한 수학적 변환을 적용하는 경우에는 `torchvision.transforms.Lambda`를 사용하지 않고 Python의 일반적인 Callable Function을 사용해도 된다.

---

## 8.2 표준편차가 0인 경우

표준화에서는 다음 연산을 수행한다.

$$
z=\frac{x-\mu}{\sigma}
$$

그런데 특정 Feature의 표준편차가 0이라면 0으로 나누는 문제가 발생할 수 있다.

이를 방지하기 위해 다음과 같이 작은 값을 하한으로 설정할 수 있다.

```python
std = std.clamp_min(1e-8)
```

이 코드는 표준편차가 `1e-8`보다 작은 경우 해당 값으로 대체한다.

Iris Dataset의 네 Feature에는 이러한 문제가 발생하지 않지만, 일반적인 데이터 처리 코드를 구현할 때 고려할 수 있는 방법이다.

---

# 9. torch.utils.data.Subset

`Subset`은 기존 Dataset에서 특정 Index에 해당하는 데이터만 선택하여 새로운 Dataset처럼 사용할 수 있도록 하는 클래스이다.

중요한 특징은 다음과 같다.

- 원본 Dataset을 참조한다.
- 지정한 Index에 해당하는 Sample만 선택한다.
- 원본 데이터를 별도로 복사할 필요가 없다.
- Training, Validation, Test Dataset을 구성할 때 사용할 수 있다.

기본적인 사용 방법은 다음과 같다.

```python
from torch.utils.data import Subset

subset = Subset(
    dataset,
    indices
)
```

여기서

- `dataset`: 원본 Dataset
- `indices`: 선택할 Sample의 Index 목록

이다.

---

```python
dataset.transform = transform
```

의 구조가 된다.

# 10. DataLoader 구성

지금까지 Training, Validation, Test Dataset을 구성하였다.

이제 DataLoader를 이용하여 데이터를 Mini-batch 단위로 모델에 전달할 수 있다.

이하 ANN 모델 정의부터 학습 및 평가까지는 앞에서 구성한 Dataset을 활용하는 추가 실습 예제이다.

---

## 10.1 DataLoader 생성

```python
from torch.utils.data import DataLoader


train_loader = DataLoader(
    train_dataset,
    batch_size=16,
    shuffle=True
)

val_loader = DataLoader(
    val_dataset,
    batch_size=16,
    shuffle=False
)

test_loader = DataLoader(
    test_dataset,
    batch_size=16,
    shuffle=False
)
```

각 Parameter의 역할은 다음과 같다.

| Parameter | 역할 |
| --- | --- |
| `dataset` | 사용할 Dataset |
| `batch_size` | 한 번에 처리할 Sample 수 |
| `shuffle` | Sample 순서를 섞을지 결정 |

Training Set에서는 일반적으로 `shuffle=True`를 사용한다.

이는 Epoch마다 학습 데이터의 순서를 변경하여 모델이 특정 데이터 순서에 과도하게 의존하는 것을 줄이는 데 도움이 된다.

반면 Validation Set과 Test Set에서는 일반적으로 `shuffle=False`를 사용한다.

---

## 10.2 Mini-batch란?

Mini-batch는 전체 데이터 중 일부 Sample을 묶은 것이다.

예를 들어 Training Set에는 90개의 Sample이 존재한다.

`batch_size=16`이라면 한 번의 Forward Propagation에서 최대 16개 Sample을 처리한다.

```text
Training Dataset: 90 Samples

Batch 1 : 16 Samples
Batch 2 : 16 Samples
Batch 3 : 16 Samples
Batch 4 : 16 Samples
Batch 5 : 16 Samples
Batch 6 : 10 Samples
```

따라서 한 Epoch에서 총 6개의 Batch를 처리한다.

마지막 Batch는 Sample 수가 16보다 적을 수 있다.

---

## 10.3 Batch의 Tensor Shape 확인

```python
X_batch, y_batch = next(
    iter(train_loader)
)

print(X_batch.shape)
print(y_batch.shape)
```

출력:

```text
torch.Size([16, 4])
torch.Size([16])
```

입력 Tensor는 다음과 같다.

$$
\boxed{ X_{\mathrm{batch}}\in\mathbb{R}^{16\times4} }
$$

Target은 다음과 같다.

$$
\boxed{ y_{\mathrm{batch}}\in\{0,1,2\}^{16} }
$$

즉 한 번의 Forward Propagation에서 16개의 Sample이 모델에 전달된다.

# 11. ANN 모델 정의

이제 Iris Dataset을 분류하기 위한 ANN을 구현해 보자.

사용할 모델은 두 개의 Hidden Layer를 포함하는 Multi-Layer Perceptron(MLP)이다.

전체 구조는 다음과 같다.

```text
Input
  │
  │ 4 Features
  ▼
Linear(4, 16)
  │
  ▼
ReLU
  │
  ▼
Linear(16, 16)
  │
  ▼
ReLU
  │
  ▼
Linear(16, 3)
  │
  ▼
Output Logits
```

입력 Feature는 4개이고, 출력 Class는 3개이므로 입력층과 출력층의 크기를 각각 4와 3으로 설정한다.

---

## 11.1 ANN 클래스 구현

```python
import torch.nn as nn


class IrisANN(nn.Module):

    def __init__(self):

        super().__init__()

        self.net = nn.Sequential(

            nn.Linear(4, 16),
            nn.ReLU(),

            nn.Linear(16, 16),
            nn.ReLU(),

            nn.Linear(16, 3)
        )

    def forward(self, x):

        return self.net(x)
```

여기서 `nn.Module`을 상속하므로 PyTorch의 모델 관리 기능을 사용할 수 있다.

`nn.Sequential`은 여러 계층을 순서대로 연결한다.

따라서 입력 Tensor는 정의된 계층들을 차례대로 통과한다.

---

## 11.2 Linear Layer의 연산

Linear Layer는 다음 연산을 수행한다.

$$
\boxed{ \mathbf{y}=W\mathbf{x}+\mathbf{b} }
$$

여기서

- $\mathbf{x}$: 입력 벡터
- $W$: Weight Matrix
- $\mathbf{b}$: Bias Vector
- $\mathbf{y}$: 출력 벡터

이다.

첫 번째 Linear Layer는 다음과 같다.

```python
nn.Linear(4, 16)
```

따라서 4개의 입력 Feature를 16개의 출력 Feature로 변환한다.

$$
\boxed{ \mathbb{R}^{4}\rightarrow\mathbb{R}^{16} }
$$

두 번째 Linear Layer는 다음과 같다.

```python
nn.Linear(16, 16)
```

따라서

$$
\boxed{ \mathbb{R}^{16}\rightarrow\mathbb{R}^{16} }
$$

의 변환을 수행한다.

마지막 Linear Layer는 다음과 같다.

```python
nn.Linear(16, 3)
```

따라서

$$
\boxed{ \mathbb{R}^{16}\rightarrow\mathbb{R}^{3} }
$$

의 변환을 수행한다.

---

## 11.3 ReLU Activation Function

ReLU(Rectified Linear Unit)는 다음과 같이 정의된다.

$$
\boxed{ f(x)=\max(0,x) }
$$

즉 입력이 0보다 작으면 0을 출력하고, 0보다 크면 입력값을 그대로 출력한다.

$$
f(x)= \begin{cases} 0,&x<0\\ x,&x\ge0 \end{cases}
$$

ReLU는 신경망에 비선형성을 부여한다.

만약 여러 Linear Layer를 연결하더라도 Activation Function을 사용하지 않으면 전체 연산은 하나의 Affine Transformation으로 표현할 수 있다.

따라서 복잡한 비선형 관계를 학습하기 위해 Activation Function이 필요하다.

---

이제 모델 인스턴스를 생성한다.

```python
model = IrisANN()

print(model)
```



출력:


$$

$$

# 13. CrossEntropyLoss

Iris Dataset은 세 개의 Class 중 하나를 선택하는 Multi-class Classification 문제이다.

이러한 분류 문제에서는 일반적으로 `nn.CrossEntropyLoss`를 사용할 수 있다.

```python
criterion = nn.CrossEntropyLoss()
```

`CrossEntropyLoss`는 모델에서 출력한 Logit과 실제 Class Label을 비교하여 Loss를 계산한다.

---

## 13.1 Logit이란?

Logit은 Softmax를 적용하기 전의 모델 출력값이다.

예를 들어 모델이 다음 값을 출력했다고 하자.

$$
\mathbf{z} = \begin{bmatrix} 2.1\\ 0.3\\ -1.2 \end{bmatrix}
$$

이는 각각 Setosa, Versicolor, Virginica에 대응하는 Logit이다.

이 값들은 확률이 아니므로 합이 1일 필요가 없다.

---

## 13.2 Softmax Function

Softmax는 Logit을 Class Probability로 변환한다.

$$
\boxed{ P(y=i\mid\mathbf{x}) = \frac{e^{z_i}} {\sum_{j=1}^{C}e^{z_j}} }
$$

여기서

- $z_i$: $i$번째 Class의 Logit
- $C$: Class 개수

이다.

Softmax 결과는 다음 조건을 만족한다.

$$
0\le P(y=i\mid\mathbf{x})\le1
$$

$$
\sum_{i=1}^{C}P(y=i\mid\mathbf{x})=1
$$

따라서 각 Class에 대한 확률 분포로 해석할 수 있다.

---

## 13.3 Cross Entropy

실제 Class가 $y$일 때 Cross Entropy Loss는 다음과 같다.

$$
\boxed{ L=-\log P(y\mid\mathbf{x}) }
$$

즉 실제 Class에 할당된 확률이 높을수록 Loss는 작아진다.

반대로 실제 Class의 확률이 낮으면 Loss가 커진다.

---

## 13.4 CrossEntropyLoss 사용 시 주의점

PyTorch의 `nn.CrossEntropyLoss`는 내부적으로 Log-Softmax와 Negative Log-Likelihood에 해당하는 계산을 수행한다.

따라서 모델의 마지막 계층에 Softmax를 별도로 추가하지 않아야 한다.

권장 구조는 다음과 같다.

```text
Linear Output
      │
      ▼
Raw Logits
      │
      ▼
CrossEntropyLoss
```

즉 다음과 같이 사용한다.

```python
logits = model(X_batch)

loss = criterion(
    logits,
    y_batch
)
```

여기서 입력 Shape는

```text
logits : [16, 3]
target : [16]
```

이다.

또한 Target의 dtype은 `torch.long`이어야 한다.

# 14. Optimizer 설정

Optimizer는 Loss를 줄이는 방향으로 모델의 Parameter를 갱신한다.

이번 예제에서는 Adam Optimizer를 사용한다.

```python
optimizer = torch.optim.Adam(
    model.parameters(),
    lr=0.01
)
```

여기서

```python
model.parameters()
```

는 모델에 등록된 Parameter들을 반환한다.

`lr`은 Learning Rate를 의미한다.

Learning Rate는 Parameter가 갱신되는 크기에 영향을 준다.

값이 너무 크면 학습이 불안정할 수 있고, 너무 작으면 학습 속도가 느려질 수 있다.

---

# 15. Training Loop 구현

이제 실제로 ANN을 학습해 보자.

학습 과정에서는 다음 순서를 반복한다.

1. Forward Propagation
2. Loss Calculation
3. Gradient Initialization
4. Backward Propagation
5. Parameter Update

이를 코드로 표현하면 다음과 같다.

```python
model.train()

for X, y in train_loader:

    optimizer.zero_grad()

    logits = model(X)

    loss = criterion(logits, y)

    loss.backward()

    optimizer.step()
```

각 코드를 살펴보자.

---

## 15.1 model.train()

```python
model.train()
```

모델을 Training Mode로 설정한다.

Dropout이나 Batch Normalization처럼 학습 모드와 평가 모드에서 동작이 달라지는 계층이 있다면 이에 맞게 동작하도록 설정한다.

---

## 15.2 optimizer.zero_grad()

```python
optimizer.zero_grad()
```

이전 단계에서 계산된 Gradient를 초기화한다.

PyTorch에서는 기본적으로 Gradient가 누적될 수 있으므로 일반적인 학습에서는 매 Step마다 초기화한다.

---

## 15.3 Forward Propagation

```python
logits = model(X)
```

입력 데이터가 신경망의 계층을 통과하여 Logit을 생성한다.

---

## 15.4 Loss Calculation

```python
loss = criterion(
    logits,
    y
)
```

모델의 예측값과 실제 Label을 비교하여 Loss를 계산한다.

---

## 15.5 Backward Propagation

```python
loss.backward()
```

Loss에 대한 Parameter들의 Gradient를 계산한다.

수학적으로는 다음과 같은 미분값을 계산하는 과정이다.

$$
\boxed{ \frac{\partial L}{\partial W} }
$$

---

## 15.6 Parameter Update

```python
optimizer.step()
```

계산된 Gradient를 이용하여 모델의 Parameter를 갱신한다.

이 과정을 반복하면서 모델은 입력 Feature와 Target Class 사이의 관계를 학습한다.

---

# 16. Validation 과정

Training Set으로 모델을 학습하는 동안 Validation Set을 이용하여 성능을 확인할 수 있다.

Validation 단계에서는 모델의 Parameter를 갱신하지 않는다.

따라서 다음과 같이 작성한다.

```python
model.eval()

val_loss = 0.0

with torch.no_grad():

    for X, y in val_loader:

        logits = model(X)

        loss = criterion(
            logits,
            y
        )

        val_loss += loss.item() * X.size(0)

val_loss /= len(val_dataset)
```

여기서 중요한 두 가지는 다음과 같다.

**`model.eval()`**

모델을 평가 모드로 설정한다.

**`torch.no_grad()`**

Gradient 계산을 비활성화한다.

이 두 기능은 서로 다른 역할을 가진다.

또한 각 Batch의 Loss에 Sample 수를 곱해 누적한 이유는 마지막 Batch의 크기가 달라질 수 있기 때문이다.

---

# 17. 전체 학습 코드

이제 Training과 Validation 과정을 하나로 결합해 보자.

다음 코드는 앞에서 생성한 `model`, `train_loader`, `val_loader`, `criterion`, `optimizer`를 사용한다.

```python
import copy

epochs = 200

train_losses = []
val_losses = []

best_val_loss = float("inf")
best_model_state = None

patience = 20
early_stop_counter = 0


for epoch in range(epochs):

    # -------------------------
    # Training
    # -------------------------

    model.train()

    train_loss = 0.0

    for X, y in train_loader:

        optimizer.zero_grad()

        logits = model(X)

        loss = criterion(
            logits,
            y
        )

        loss.backward()

        optimizer.step()

        train_loss += loss.item() * X.size(0)

    train_loss /= len(train_dataset)


    # -------------------------
    # Validation
    # -------------------------

    model.eval()

    val_loss = 0.0

    with torch.no_grad():

        for X, y in val_loader:

            logits = model(X)

            loss = criterion(
                logits,
                y
            )

            val_loss += loss.item() * X.size(0)

    val_loss /= len(val_dataset)


    # -------------------------
    # Loss 기록
    # -------------------------

    train_losses.append(train_loss)
    val_losses.append(val_loss)


    # -------------------------
    # Best Model 저장
    # -------------------------

    if val_loss < best_val_loss - 1e-4:

        best_val_loss = val_loss

        best_model_state = copy.deepcopy(
            model.state_dict()
        )

        early_stop_counter = 0

    else:

        early_stop_counter += 1


    # -------------------------
    # 학습 상태 출력
    # -------------------------

    if (epoch + 1) % 10 == 0:

        print(
            f"Epoch [{epoch+1}/{epochs}] "
            f"Train Loss: {train_loss:.4f} "
            f"Val Loss: {val_loss:.4f}"
        )


    # -------------------------
    # Early Stopping
    # -------------------------

    if early_stop_counter >= patience:

        print(
            f"Early Stopping at Epoch {epoch+1}"
        )

        break


# Best Model 복원
if best_model_state is not None:

    model.load_state_dict(
        best_model_state
    )
```

---

## 17.1 Epoch이란?

Epoch은 전체 Training Dataset을 한 번 학습하는 과정을 의미한다.

예를 들어 Training Dataset이 90개 Sample이고 Batch Size가 16이라면 하나의 Epoch에서는 6번의 Mini-batch 처리가 이루어진다.

전체 Epoch이 100이면 이러한 과정을 최대 100번 반복한다.

---

## 17.2 Early Stopping

Early Stopping은 Validation 성능이 일정 기간 개선되지 않으면 학습을 중단하는 방법이다.

학습을 오래 수행한다고 해서 반드시 일반화 성능이 계속 좋아지는 것은 아니다.

Training Loss는 감소하지만 Validation Loss는 증가할 수 있다.

이는 Overfitting의 한 가지 징후이다.

Early Stopping은 이러한 문제를 줄이기 위해 사용할 수 있다.

위 코드에서는

```python
patience = 20
```

으로 설정하였다.

따라서 Validation Loss가 정해진 개선 기준을 만족하지 못하는 상태가 20 Epoch 연속 발생하면 학습을 중단한다.

---

# 18. Learning Curve 시각화

학습 과정에서 기록한 Loss를 그래프로 나타내면 모델의 학습 상태를 확인할 수 있다.

```python
import matplotlib.pyplot as plt


plt.figure(figsize=(8, 5))

plt.plot(
    train_losses,
    label="Training Loss"
)

plt.plot(
    val_losses,
    label="Validation Loss"
)

plt.xlabel("Epoch")
plt.ylabel("Cross Entropy Loss")

plt.title("Iris ANN Learning Curve")

plt.legend()
plt.grid(True)

plt.show()
```

그래프를 통해 다음과 같은 현상을 확인할 수 있다.

### 정상적인 학습

Training Loss와 Validation Loss가 함께 감소한다.

### Overfitting

Training Loss는 계속 감소하지만 Validation Loss가 증가한다.

### Underfitting

Training Loss와 Validation Loss가 모두 충분히 감소하지 않는다.

단, Iris Dataset은 Sample 수가 적기 때문에 데이터 분할과 모델 초기값에 따라 Learning Curve의 형태가 달라질 수 있다.

# 19. Test Set으로 최종 성능 평가

Training과 Validation이 완료되면 Test Set으로 최종 성능을 평가한다.

Test Set은 학습 과정에서 사용하지 않은 데이터이다.

따라서 모델의 일반화 성능을 확인하는 데 사용된다.

---

## 19.1 Accuracy 계산

Accuracy는 전체 Sample 중 정확하게 분류한 Sample의 비율이다.

$$
\boxed{ Accuracy = \frac{\text{Correct Predictions}} {\text{Total Predictions}} }
$$

예를 들어 30개의 Test Sample 중 28개를 정확하게 분류했다면

$$
Accuracy=\frac{28}{30}
$$

이므로

$$
Accuracy\approx93.3\%
$$

이다.

이는 계산을 설명하기 위한 예시이며 실제 모델 실행 결과는 아니다.

---

## 19.2 Test Accuracy 구현

```python
model.eval()

correct = 0
total = 0

with torch.no_grad():

    for X, y in test_loader:

        logits = model(X)

        predictions = torch.argmax(
            logits,
            dim=1
        )

        correct += (
            predictions == y
        ).sum().item()

        total += y.size(0)


test_accuracy = correct / total

print(
    f"Test Accuracy: {test_accuracy:.4f}"
)
```

여기서

```python
torch.argmax(logits, dim=1)
```

는 각 Sample에서 가장 높은 Logit을 가진 Class Index를 선택한다.

예를 들어 Logit이 다음과 같다고 하자.

$$
\mathbf{z} = \begin{bmatrix} 0.2\\ 2.5\\ 0.8 \end{bmatrix}
$$

가장 높은 값은 두 번째 원소인 2.5이다.

따라서 예측 Class는

$$
\boxed{ \hat{y}=1 }
$$

이다.

즉 Versicolor로 분류한다.

---

# 20. Confusion Matrix

Accuracy만으로는 어떤 Class에서 분류 오류가 발생했는지 확인하기 어렵다.

따라서 Confusion Matrix(혼동 행렬)를 함께 사용할 수 있다.

Confusion Matrix는 실제 Class와 예측 Class를 비교한 표이다.

3-Class Classification에서는 다음과 같은 형태를 가진다.

$$
C= \begin{bmatrix} C_{00}&C_{01}&C_{02}\\ C_{10}&C_{11}&C_{12}\\ C_{20}&C_{21}&C_{22} \end{bmatrix}
$$

여기서

- 행: 실제 Class
- 열: 예측 Class

이다.

대각선 성분은 올바르게 분류한 Sample 수를 의미한다.

---

## 20.1 Confusion Matrix 구현

```python
from sklearn.metrics import confusion_matrix
from sklearn.metrics import classification_report


model.eval()

y_true = []
y_pred = []

with torch.no_grad():

    for X, y in test_loader:

        logits = model(X)

        predictions = torch.argmax(
            logits,
            dim=1
        )

        y_true.extend(
            y.numpy()
        )

        y_pred.extend(
            predictions.numpy()
        )


cm = confusion_matrix(
    y_true,
    y_pred
)

print("Confusion Matrix")

print(cm)
```

추가로 Precision, Recall, F1-score를 계산할 수 있다.

```python
print(
    classification_report(
        y_true,
        y_pred,
        target_names=[
            "Setosa",
            "Versicolor",
            "Virginica"
        ]
    )
)
```

이를 통해 Class별 분류 성능을 확인할 수 있다.

# 21. 새로운 Sample에 대한 예측

학습된 ANN에 하나의 새로운 Sample을 입력하여 품종을 예측할 수 있다.

예를 들어 다음과 같은 Feature를 가진 붓꽃을 생각하자.

```python
new_sample = torch.tensor(
    [5.1, 3.5, 1.4, 0.2],
    dtype=torch.float32
)
```

이 데이터는 4개의 Feature로 구성되어 있다.

하지만 모델은 일반적으로 Batch Dimension을 포함한 입력을 기대한다.

따라서 다음과 같이 차원을 추가한다.

```python
new_sample = new_sample.unsqueeze(0)
```

Shape는 다음과 같다.

```text
torch.Size([1, 4])
```

여기서 중요한 점은 **새로운 Sample에도 Training Set에서 계산한 평균과 표준편차를 사용해야 한다는 것**이다.

```python
new_sample = (
    new_sample - mean
) / std
```

이제 모델에 입력한다.

```python
model.eval()

with torch.no_grad():

    logits = model(new_sample)

    probabilities = torch.softmax(
        logits,
        dim=1
    )

    prediction = torch.argmax(
        probabilities,
        dim=1
    )


class_names = [
    "Setosa",
    "Versicolor",
    "Virginica"
]

print(
    "Predicted Class:",
    class_names[prediction.item()]
)

print(
    "Class Probabilities:",
    probabilities
)
```

이 코드는 모델의 예측 Class와 각 Class에 대한 Softmax Probability를 출력한다.

단, Softmax 결과는 모델의 확률 점수이며 항상 정확하게 보정된 실제 확률을 의미하는 것은 아니다.

# 24. 최종 정리

Iris Dataset은 4개의 Feature를 이용하여 붓꽃을 세 가지 품종으로 분류하는 대표적인 Multi-class Classification Dataset이다.

PyTorch에서는 `Dataset` 클래스를 상속하여 사용자 정의 데이터셋을 구성하고, `DataLoader`를 이용하여 데이터를 Mini-batch 단위로 모델에 공급할 수 있다.

전체 데이터를 Training, Validation, Test Set으로 나눌 때는 `train_test_split()`과 `stratify`를 사용하여 Class 비율을 유지할 수 있다.

특히 Standardization은 Training Set에서 계산한 통계량만 사용해야 한다.

그렇지 않으면 Validation Set과 Test Set의 정보가 전처리 과정에 포함되어 Data Leakage가 발생할 수 있다.

이후 `Subset`으로 각 Dataset을 구성하고, `DataLoader`를 사용하여 ANN에 데이터를 공급한다.

ANN 모델은 `nn.Module`을 상속하여 구현하며, 입력 Feature의 차원과 출력 Class의 개수에 맞추어 신경망의 구조를 정의한다.

다중 분류에서는 일반적으로 `CrossEntropyLoss`를 사용하고, Optimizer를 통해 모델의 Parameter를 갱신한다.

학습 중에는 Validation Loss를 이용하여 모델을 선택하고, 최종적으로 Test Set을 사용하여 일반화 성능을 평가한다.

전체 과정에서 중요한 점은 단순히 높은 Accuracy를 얻는 것이 아니라, **데이터 분할부터 전처리, 학습, 모델 선택, 최종 평가까지 각 단계의 역할을 명확하게 구분하는 것**이다.
