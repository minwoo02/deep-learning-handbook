Deep Neural Network는 Forward Propagation과 Backpropagation을 반복하며 Weight와 Bias를 학습한다.

일반적인 학습 과정은 다음과 같다.

```text
Input
  │
  ▼
Forward Propagation
  │
  ▼
Loss Calculation
  │
  ▼
Backpropagation
  │
  ▼
Gradient Calculation
  │
  ▼
Parameter Update
```

그렇다면 학습이 시작되기 전, **Weight와 Bias의 초기값은 어떻게 결정해야 할까?**

이러한 초기값을 설정하는 과정이 **Weight Initialization(가중치 초기화)** 이다.

Weight Initialization은 단순히 무작위 값을 할당하는 과정이 아니다. 초기 Weight의 Scale과 Distribution은 Forward Propagation에서 전달되는 Activation과 Backpropagation에서 전달되는 Gradient의 크기에 영향을 준다.

대표적인 초기화 방법은 다음과 같다.

- Zero Initialization
- Random Initialization
- LeCun Initialization
- Xavier(Glorot) Initialization
- He(Kaiming) Initialization
- Orthogonal Initialization

이 글에서는 Weight Initialization이 필요한 이유와 수학적 원리를 살펴보고, PyTorch의 `torch.nn.init` 모듈을 이용하여 각 초기화 방법을 구현한다.

마지막으로 실제 Deep MLP에서 **Initialization Method에 따른 Activation의 변화를 비교**한다.

---

# 1. Weight Initialization이란?

Neural Network의 Linear Layer에서는 다음과 같은 연산이 수행된다.

$$
\boxed{ \mathbf{z}=W\mathbf{x}+\mathbf{b} }
$$

여기서

- $\mathbf{x}$: Input Vector
- $W$: Weight Matrix
- $\mathbf{b}$: Bias Vector
- $\mathbf{z}$: Linear Transformation의 출력

이다.

이후 Activation Function을 적용한다.

$$
\boxed{ \mathbf{a}=f(\mathbf{z}) }
$$

Deep Neural Network에서는 이 과정이 여러 Layer에 걸쳐 반복된다.

$$
\boxed{ \mathbf{z}^{(l)} = W^{(l)}\mathbf{a}^{(l-1)} + \mathbf{b}^{(l)} }
$$

$$
\boxed{ \mathbf{a}^{(l)} = f\left(\mathbf{z}^{(l)}\right) }
$$

여기서 $l$은 Layer Index이다.

Training을 통해 Weight와 Bias를 업데이트하려면 먼저 초기 Parameter가 존재해야 한다.

$$
\boxed{ W^{(0)},\quad \mathbf{b}^{(0)} }
$$

이 값을 결정하는 과정이 Weight Initialization이다.

초기화 방법에 따라 모델은 서로 다른 Parameter에서 학습을 시작한다.

따라서 **동일한 Architecture와 Dataset을 사용하더라도 초기 Weight에 따라 학습 과정과 결과가 달라질 수 있다.**

---

# 2. Weight Initialization이 중요한 이유

신경망이 깊어질수록 Signal은 여러 Layer를 통과한다.

```text
Input
  │
  ▼
Linear Layer 1
  │
  ▼
Activation
  │
  ▼
Linear Layer 2
  │
  ▼
Activation
  │
  ▼
Linear Layer 3
  │
  ▼
Output
```

각 Layer에서는 Weight Matrix와 Activation Function을 이용한 연산이 반복된다.

Weight의 초기 크기가 적절하지 않으면 Forward Propagation과 Backpropagation에서 Signal의 크기가 지나치게 변화할 수 있다.

대표적으로 다음 문제가 발생할 수 있다.

- Vanishing Gradient
- Exploding Gradient

---

## 2.1 Vanishing Gradient

Vanishing Gradient는 Backpropagation 과정에서 Gradient의 크기가 지나치게 감소하는 현상이다.

Deep Neural Network에서는 Chain Rule에 의해 여러 미분값이 반복적으로 곱해진다.

예를 들어 다음 연산을 생각해 보자.

$$
0.1\times0.1\times0.1\times0.1 = 0.0001
$$

1보다 작은 값이 반복적으로 곱해지면 결과가 빠르게 작아진다.

신경망에서도 Weight Matrix와 Activation Function의 미분값이 반복적으로 곱해지면서 Gradient가 감소할 수 있다.

특히 Sigmoid Function은 다음과 같다.

$$
\boxed{ \sigma(x)=\frac{1}{1+e^{-x}} }
$$

Sigmoid의 미분값은 다음과 같다.

$$
\boxed{ \sigma'(x) = \sigma(x)(1-\sigma(x)) }
$$

이 미분값은 다음 범위에 존재한다.

$$
\boxed{ 0<\sigma'(x)\le\frac14 }
$$

따라서 여러 Layer를 통과하면서 작은 미분값이 반복적으로 곱해지면 Gradient가 감소할 수 있다.

결과적으로 입력층에 가까운 Layer까지 충분한 Gradient가 전달되지 않아 Parameter Update가 어려워질 수 있다.

```text
Backpropagation
      │
      ▼
Repeated Chain Rule
      │
      ▼
Small Gradient
      │
      ▼
Vanishing Gradient
      │
      ▼
Early Layer 학습 어려움
```

다만 Vanishing Gradient는 단순히 Sigmoid의 미분값만으로 결정되는 현상은 아니다.

실제 Gradient의 크기는 Weight Matrix, Activation Function, Network Depth 등 여러 요소의 영향을 받는다.

---

## 2.2 Exploding Gradient

Exploding Gradient는 Backpropagation 과정에서 Gradient가 지나치게 커지는 현상이다.

예를 들어 다음 연산을 생각해 보자.

$$
3\times3\times3\times3=81
$$

1보다 큰 값이 반복적으로 곱해지면 결과가 빠르게 증가한다.

Deep Neural Network에서도 특정 조건에서 Gradient Norm이 크게 증가할 수 있다.

Gradient Descent의 기본적인 Parameter Update는 다음과 같다.

$$
\boxed{ \theta_{t+1} = \theta_t-\eta\nabla_\theta L(\theta_t) }
$$

여기서

- $\theta$: Model Parameter
- $\eta$: Learning Rate
- $\nabla_\theta L$: Gradient

이다.

Gradient가 지나치게 크면 Parameter Update도 커질 수 있다.

그 결과 Loss가 심하게 진동하거나 발산할 수 있다.

```text
Large Gradient
      │
      ▼
Large Parameter Update
      │
      ▼
Training Instability
      │
      ▼
Loss Divergence 가능
```

이러한 현상을 Exploding Gradient라고 한다.

---

## 2.3 초기화가 두 문제와 연결되는 이유

초기 Weight가 지나치게 작으면 여러 Layer를 통과하면서 Signal의 크기가 감소할 수 있다.

반면 초기 Weight가 지나치게 크면 Signal의 크기가 증가하거나 Activation Function의 Saturation 영역에 들어갈 수 있다.

따라서 Weight Initialization의 중요한 목적은 다음과 같다.

> Forward Propagation과 Backpropagation에서 전달되는 Signal의 Scale이 Layer를 통과하면서 지나치게 감소하거나 증가하지 않도록 초기 Weight를 설정한다.

이를 위해 Weight의 분산을 적절하게 설정하는 방법이 사용된다.

---

# 3. Zero Initialization과 Symmetry Problem

가장 단순한 초기화 방법은 모든 Weight를 0으로 설정하는 것이다.

$$
\boxed{ W=0 }
$$

PyTorch에서는 다음과 같이 구현할 수 있다.

```python
import torch
import torch.nn as nn

layer = nn.Linear(4, 3)

nn.init.zeros_(layer.weight)

print(layer.weight)
```

모든 Weight가 0으로 초기화된다.

하지만 일반적인 다층 신경망의 Hidden Layer에서는 모든 Weight를 0으로 초기화하는 것이 적절하지 않다.

---

## 3.1 Symmetry Problem

하나의 Hidden Layer에 두 개의 Neuron이 있다고 하자.

두 Neuron의 Weight Vector가 다음과 같이 동일하다고 가정한다.

$$
\boxed{ \mathbf{w}_1=\mathbf{w}_2 }
$$

두 Neuron에 동일한 입력이 전달되고 Bias까지 동일하다면 두 Neuron은 같은 출력을 생성한다.

$$
\boxed{ a_1=a_2 }
$$

이후 Backpropagation에서도 두 Neuron에 동일한 Gradient가 전달될 수 있다.

따라서 Parameter Update 이후에도 두 Neuron이 동일한 상태를 유지할 수 있다.

이 경우 여러 Neuron이 서로 다른 Feature를 학습하기 어려워진다.

이러한 현상을 **Symmetry Problem(대칭성 문제)** 이라고 한다.

이를 방지하기 위해 일반적인 Hidden Layer에서는 Weight를 서로 다른 값으로 초기화한다.

---

## 3.2 Bias도 0으로 초기화하면 안 될까?

Weight와 Bias는 구분해야 한다.

Weight는 Neuron 간의 대칭성을 깨뜨리기 위해 무작위 초기화를 사용하는 경우가 많다.

반면 Bias는 0으로 초기화하는 경우가 일반적이다.

```python
nn.init.zeros_(layer.bias)
```

따라서 다음과 같은 초기화 방법을 사용할 수 있다.

```python
nn.init.xavier_uniform_(
    layer.weight
)

nn.init.zeros_(
    layer.bias
)
```

이 경우 Weight는 서로 다른 값으로 초기화되고 Bias는 0으로 초기화된다.

다만 모든 신경망에서 0 초기화가 금지되는 것은 아니다. 일부 Parameter는 모델 구조에 따라 의도적으로 0으로 초기화하기도 한다.

---

# 4. Random Initialization

Zero Initialization의 대칭성 문제를 피하기 위해 Weight를 무작위로 초기화할 수 있다.

대표적인 Random Initialization은 다음 두 가지이다.

1. Normal Initialization
2. Uniform Initialization

---

## 4.1 Normal Initialization

Normal Distribution(정규분포)에서 Weight를 무작위로 추출한다.

$$
\boxed{ W\sim\mathcal{N}(\mu,\sigma^2) }
$$

여기서

- $\mu$: Mean
- $\sigma$: Standard Deviation
- $\sigma^2$: Variance

이다.

PyTorch에서는 다음과 같이 구현한다.

```python
layer = nn.Linear(4, 8)

nn.init.normal_(
    layer.weight,
    mean=0.0,
    std=0.01
)
```

이 코드는 평균 0, 표준편차 0.01인 정규분포에서 Weight를 추출한다.

여기서 `std`에 전달하는 값은 Variance가 아니라 Standard Deviation이다.

---

## 4.2 Uniform Initialization

Uniform Distribution(균등분포)은 일정 범위에서 균등한 확률밀도로 값을 추출하는 분포이다.

$$
\boxed{ W\sim U(a,b) }
$$

PyTorch에서는 다음과 같이 구현할 수 있다.

```python
layer = nn.Linear(4, 8)

nn.init.uniform_(
    layer.weight,
    a=-0.1,
    b=0.1
)
```

이 코드는 -0.1에서 0.1 사이의 값을 이용하여 Weight를 초기화한다.

---

## 4.3 단순한 Random Initialization의 한계

Random Initialization을 사용하면 Neuron 사이의 Symmetry Problem을 완화할 수 있다.

하지만 무작위 초기화라고 해서 항상 안정적인 학습이 보장되는 것은 아니다.

예를 들어 모든 Layer의 Weight를 평균 0, 표준편차 0.01로 초기화한다고 하자.

Layer의 입력 개수나 Activation Function의 특성을 고려하지 않으면 깊은 신경망에서 Signal의 크기가 빠르게 감소하거나 증가할 수 있다.

따라서 단순히 Weight를 무작위로 설정하는 것보다 **Layer의 Fan-in과 Fan-out을 고려하여 초기 Weight의 분산을 조절하는 것**이 중요하다.

---

# 5. Variance Propagation

Weight Initialization의 수학적 원리를 이해하기 위해 하나의 Linear Transformation을 생각해 보자.

$$
\boxed{ z=\sum_{i=1}^{n}w_ix_i }
$$

여기서

- $n$: Input Neuron 수
- $w_i$: Weight
- $x_i$: Input

이다.

다음과 같은 단순화된 조건을 가정한다.

- Weight의 평균은 0이다.
- Weight와 Input은 서로 독립이다.
- 각 Weight는 동일한 분산을 가진다.
- 입력 성분들이 적절한 독립성 및 동일 분포 조건을 만족한다.
- Bias의 영향은 제외한다.

이러한 조건에서 출력의 분산은 다음과 같이 표현할 수 있다.

$$
\boxed{ \operatorname{Var}(z) = n\operatorname{Var}(w)\operatorname{Var}(x) }
$$

이 식에서 중요한 점은 **Input Neuron 수와 Weight의 분산이 출력의 분산을 결정하는 데 영향을 준다는 것**이다.

예를 들어 Weight Variance가 일정하다면 Input Neuron 수가 증가할수록 출력의 분산도 커질 수 있다.

따라서 Weight Initialization에서는 Layer의 크기를 고려해야 한다.

---

## 5.1 Forward Propagation에서 분산을 유지하려면?

입력과 출력의 분산이 비슷하게 유지되도록 설정하고 싶다고 하자.

$$
\boxed{ \operatorname{Var}(z) \approx \operatorname{Var}(x) }
$$

앞의 식에 대입하면

$$
n\operatorname{Var}(w)\operatorname{Var}(x) \approx \operatorname{Var}(x)
$$

이다.

따라서

$$
\boxed{ \operatorname{Var}(w) \approx \frac1n }
$$

의 관계를 얻을 수 있다.

이러한 원리는 LeCun Initialization을 이해하는 기초가 된다.

다만 실제 신경망에서는 Activation Function에 의해 입력분포의 평균과 분산이 변한다.

따라서 위 식은 초기화의 기본적인 원리를 설명하기 위한 단순화된 관계이다.

특히 ReLU처럼 출력이 0 이상인 함수에서는 Variance뿐 아니라 Activation의 Second Moment도 중요한 역할을 한다.

---

# 6. Fan-in과 Fan-out

Weight Initialization에서는 다음 두 개념이 자주 등장한다.

- Fan-in
- Fan-out

**Fan-in**은 하나의 Output Neuron에 연결되는 Input의 개수이다.

**Fan-out**은 하나의 Input Neuron에서 연결되는 Output의 개수이다.

예를 들어 다음 Linear Layer를 생각하자.

```python
layer = nn.Linear(4, 8)
```

이 Layer는 4개의 Input Feature를 8개의 Output Feature로 변환한다.

$$
\boxed{ \mathbb{R}^{4}\rightarrow\mathbb{R}^{8} }
$$

따라서

$$
\boxed{ fan_{in}=4 }
$$

$$
\boxed{ fan_{out}=8 }
$$

이다.

PyTorch에서 Weight Shape는 다음과 같다.

```python
print(layer.weight.shape)
```

출력:

```text
torch.Size([8, 4])
```

즉 `nn.Linear`에서는 다음 관계를 가진다.

$$
\boxed{ W.shape=(fan_{out},fan_{in}) }
$$

이 값들은 이후 LeCun, Xavier, He Initialization의 분산을 결정하는 데 사용된다.

참고로 Convolution Layer에서는 Kernel Size까지 고려하여 Fan-in과 Fan-out을 계산한다.

---

# 7. LeCun Initialization

LeCun Initialization은 Fan-in을 기준으로 초기 Weight의 분산을 결정하는 방법이다.

대표적인 LeCun Normal Initialization은 다음과 같다.

$$
\boxed{ W\sim \mathcal{N} \left( 0,\frac{1}{fan_{in}} \right) }
$$

따라서 Weight의 분산은 다음과 같다.

$$
\boxed{ \operatorname{Var}(W) = \frac{1}{fan_{in}} }
$$

표준편차는 다음과 같다.

$$
\boxed{ \sigma_W = \sqrt{\frac{1}{fan_{in}}} }
$$

이다.

---

## 7.1 LeCun Initialization의 원리

앞에서 다음 관계를 살펴보았다.

$$
\operatorname{Var}(z) = fan_{in} \operatorname{Var}(W) \operatorname{Var}(x)
$$

여기에

$$
\operatorname{Var}(W) = \frac1{fan_{in}}
$$

을 대입하면

$$
\operatorname{Var}(z) = fan_{in} \frac1{fan_{in}} \operatorname{Var}(x)
$$

이다.

따라서

$$
\boxed{ \operatorname{Var}(z) = \operatorname{Var}(x) }
$$

이다.

즉 단순화된 조건에서 Forward Propagation의 분산을 유지하도록 초기 Weight를 설정한다.

---

## 7.2 PyTorch 구현

PyTorch에서는 `nn.init.normal_()`을 이용하여 LeCun Normal Initialization을 구현할 수 있다.

```python
import math
import torch.nn as nn

layer = nn.Linear(128, 64)

fan_in = layer.in_features

std = math.sqrt(
    1.0 / fan_in
)

nn.init.normal_(
    layer.weight,
    mean=0.0,
    std=std
)

nn.init.zeros_(
    layer.bias
)
```

여기서는

$$
fan_{in}=128
$$

이므로

$$
\boxed{ \sigma_W = \sqrt{\frac1{128}} }
$$

이다.

LeCun 계열 초기화는 특히 SELU를 이용하는 Self-Normalizing Neural Network와 관련이 있다.

SELU의 Self-normalizing 특성을 활용하는 경우에는 해당 모델에서 요구하는 Initialization과 Architecture 조건을 함께 고려해야 한다.

---

# 8. Xavier(Glorot) Initialization

Xavier Initialization은 Glorot Initialization이라고도 한다.

LeCun Initialization이 Fan-in을 기준으로 분산을 조절한다면, Xavier Initialization은 Fan-in과 Fan-out을 함께 고려한다.

Xavier Initialization의 중요한 목적은 Forward Propagation에서 전달되는 Activation과 Backpropagation에서 전달되는 Gradient의 Scale을 함께 고려하는 것이다.

대표적인 Weight Variance는 다음과 같다.

$$
\boxed{ \operatorname{Var}(W) = \frac{2}{fan_{in}+fan_{out}} }
$$

이 식은 입력과 출력 연결 수를 함께 고려하여 초기 Weight의 분산을 설정한다.

Xavier Initialization은 Tanh 계열 Activation Function을 사용하는 Neural Network에서 자주 활용된다.

---

## 8.1 Xavier Normal Initialization

정규분포를 사용하는 경우 다음과 같다.

$$
\boxed{ W\sim \mathcal{N} \left( 0, \frac{2}{fan_{in}+fan_{out}} \right) }
$$

표준편차는 다음과 같다.

$$
\boxed{ \sigma_W = \sqrt{ \frac{2}{fan_{in}+fan_{out}} } }
$$

PyTorch에서는 다음과 같이 구현한다.

```python
layer = nn.Linear(128, 64)

nn.init.xavier_normal_(
    layer.weight
)

nn.init.zeros_(
    layer.bias
)
```

---

## 8.2 Xavier Uniform Initialization

균등분포를 사용하는 경우 다음과 같다.

$$
\boxed{ W\sim U(-a,a) }
$$

여기서

$$
\boxed{ a= \sqrt{ \frac{6}{fan_{in}+fan_{out}} } }
$$

이다.

따라서

$$
\boxed{ W\sim U\left( -\sqrt{\frac{6}{fan_{in}+fan_{out}}}, \sqrt{\frac{6}{fan_{in}+fan_{out}}} \right) }
$$

이다.

PyTorch에서는 다음과 같이 구현한다.

```python
layer = nn.Linear(128, 64)

nn.init.xavier_uniform_(
    layer.weight
)

nn.init.zeros_(
    layer.bias
)
```

Xavier Normal과 Xavier Uniform은 사용하는 확률분포가 다르지만, 기본 설정에서 같은 이론적 Variance를 목표로 한다.

---

## 8.3 Xavier Initialization의 한계

Xavier Initialization은 Fan-in과 Fan-out을 함께 고려한다.

하지만 ReLU를 사용하는 깊은 신경망에서는 적절한 분산 유지가 어려울 수 있다.

ReLU는 다음과 같이 정의된다.

$$
\boxed{ f(x)=\max(0,x) }
$$

음수 입력은 0으로 변환되므로 Activation의 분포가 달라진다.

따라서 ReLU의 특성을 고려한 다른 초기화 방식이 필요할 수 있다.

대표적인 방법이 He Initialization이다.

---

# 9. He(Kaiming) Initialization

He Initialization은 Kaiming Initialization이라고도 한다.

이 초기화 방식은 ReLU 계열 Activation Function에 적합하도록 설계되었다.

ReLU는 음수 입력을 0으로 변환한다.

$$
\boxed{ f(x)= \begin{cases} 0,&x<0\\ x,&x\ge0 \end{cases} }
$$

따라서 대칭적인 입력분포를 가정하면 ReLU 적용 후 Signal의 Second Moment가 감소한다.

He Initialization은 이 특성을 고려하여 Weight의 분산을 설정한다.

대표적인 ReLU 기반 He Initialization은 다음과 같다.

$$
\boxed{ \operatorname{Var}(W) = \frac{2}{fan_{in}} }
$$

따라서 표준편차는 다음과 같다.

$$
\boxed{ \sigma_W = \sqrt{ \frac{2}{fan_{in}} } }
$$

이다.

---

## 9.1 He Normal Initialization

정규분포를 사용하는 경우 다음과 같다.

$$
\boxed{ W\sim \mathcal{N} \left( 0,\frac{2}{fan_{in}} \right) }
$$

PyTorch에서는 다음과 같이 구현한다.

```python
layer = nn.Linear(128, 64)

nn.init.kaiming_normal_(
    layer.weight,
    mode="fan_in",
    nonlinearity="relu"
)

nn.init.zeros_(
    layer.bias
)
```

여기서 `mode`는 분산을 계산할 때 사용할 Fan을 결정한다.

### mode="fan_in"

```python
mode="fan_in"
```

Forward Propagation에서 전달되는 Signal Scale을 유지하는 데 초점을 둔다.

### mode="fan_out"

```python
mode="fan_out"
```

Backward Propagation에서 전달되는 Gradient Scale을 고려한다.

---

## 9.2 He Uniform Initialization

균등분포를 사용하는 경우 다음과 같다.

$$
\boxed{ W\sim U(-a,a) }
$$

ReLU와 Fan-in을 기준으로 하면

$$
\boxed{ a= \sqrt{ \frac{6}{fan_{in}} } }
$$

이다.

따라서

$$
\boxed{ W\sim U\left( -\sqrt{\frac{6}{fan_{in}}}, \sqrt{\frac{6}{fan_{in}}} \right) }
$$

이다.

PyTorch에서는 다음과 같이 구현한다.

```python
layer = nn.Linear(128, 64)

nn.init.kaiming_uniform_(
    layer.weight,
    mode="fan_in",
    nonlinearity="relu"
)

nn.init.zeros_(
    layer.bias
)
```

여기서 `nonlinearity="relu"`는 ReLU에 적합한 Gain을 사용하도록 지정한다.

---

# 10. Gain과 Leaky ReLU Initialization

PyTorch의 Initialization Function에서는 Gain이라는 계수를 사용할 수 있다.

**Gain은 Activation Function의 특성을 고려하여 초기 Weight의 Scale을 조절하는 값**이다.

대표적인 Gain은 다음과 같다.

| Activation Function | Gain |
| --- | --- |
| Linear | $1$ |
| Sigmoid | $1$ |
| Tanh | $5/3$ |
| ReLU | $\sqrt2$ |
| Leaky ReLU | $\sqrt{2/(1+a^2)}$ |

여기서 $a$는 Leaky ReLU의 Negative Slope이다.

---

## 10.1 Xavier Initialization에 Gain 적용

예를 들어 Tanh를 사용하는 경우 다음과 같이 Gain을 설정할 수 있다.

```python
gain = nn.init.calculate_gain(
    "tanh"
)

nn.init.xavier_uniform_(
    layer.weight,
    gain=gain
)
```

Xavier Normal Initialization에 Gain을 적용하면 표준편차는 다음과 같다.

$$
\boxed{ \sigma_W = gain \sqrt{ \frac{2}{fan_{in}+fan_{out}} } }
$$

따라서 Gain을 적용하면 Initialization의 Scale이 조절된다.

---

## 10.2 Leaky ReLU

Leaky ReLU는 음수 영역에서도 작은 기울기를 유지하는 Activation Function이다.

$$
\boxed{ f(x)= \begin{cases} x,&x\ge0\\ ax,&x<0 \end{cases} }
$$

여기서 $a$는 Negative Slope이다.

Leaky ReLU에 대한 Kaiming Initialization에서는 다음 Gain을 사용할 수 있다.

$$
\boxed{ gain= \sqrt{ \frac{2}{1+a^2} } }
$$

따라서 Fan-in 기준 Weight Variance는 다음과 같다.

$$
\boxed{ \operatorname{Var}(W) = \frac{2}{(1+a^2)fan_{in}} }
$$

PyTorch에서는 다음과 같이 구현한다.

```python
layer = nn.Linear(128, 64)

nn.init.kaiming_normal_(
    layer.weight,
    a=0.01,
    mode="fan_in",
    nonlinearity="leaky_relu"
)
```

이때 초기화 함수에 설정한 `a=0.01`은 실제 Leaky ReLU에서 사용하는 Negative Slope와 일치시키는 것이 중요하다.

---

# 11. Orthogonal Initialization

Orthogonal Initialization은 Weight Matrix가 직교 또는 준직교 조건을 만족하도록 초기화하는 방법이다.

정사각형 직교 행렬은 다음 조건을 만족한다.

$$
\boxed{ W^TW=WW^T=I }
$$

직교 변환은 벡터의 Euclidean Norm을 보존한다.

$$
\boxed{ \|W\mathbf{x}\|_2 = \|\mathbf{x}\|_2 }
$$

따라서 특정 조건에서 Signal의 크기를 유지하는 데 도움이 될 수 있다.

PyTorch에서는 다음과 같이 구현한다.

```python
layer = nn.Linear(128, 128)

nn.init.orthogonal_(
    layer.weight
)

nn.init.zeros_(
    layer.bias
)
```

Orthogonal Initialization은 일부 Recurrent Neural Network와 깊은 신경망에서 사용된다.

다만 비정사각형 Weight Matrix에서는 모든 방향의 Norm이 보존되는 것은 아니다.

또한 Activation Function이나 반복적인 학습 과정까지 고려하면 직교 초기화가 항상 Gradient Norm을 유지한다고 보장할 수는 없다.

---

# 12. Weight Initialization 방법 비교

지금까지 살펴본 주요 초기화 방법을 비교하면 다음과 같다.

| Initialization | Weight Variance | 대표적인 특징 |
| --- | --- | --- |
| Zero | $0$ | Hidden Layer에서 Symmetry Problem 가능 |
| Random Normal | 사용자 설정 | 정규분포 기반 |
| Random Uniform | 사용자 설정 | 균등분포 기반 |
| LeCun | $1/fan_{in}$ | Forward Signal Scale 고려 |
| Xavier | $2/(fan_{in}+fan_{out})$ | Fan-in과 Fan-out 고려 |
| He | $2/fan_{in}$ | ReLU 계열 Activation 고려 |
| Orthogonal | 직교 조건 기반 | 일부 구조에서 Norm 보존 특성 활용 |

대표적인 Activation Function과 초기화 방법을 연결하면 다음과 같다.

| Activation Function | 고려할 Initialization |
| --- | --- |
| Linear | Xavier 또는 구조에 적합한 초기화 |
| Sigmoid | Xavier 계열, Saturation 주의 |
| Tanh | Xavier |
| ReLU | He(Kaiming) |
| Leaky ReLU | Negative Slope를 고려한 He |
| SELU | LeCun 계열 |

이 표는 일반적인 출발점이다.

실제로 가장 적합한 초기화 방식은 Network Architecture, Activation Function, Normalization Layer 및 Training Configuration에 따라 달라질 수 있다.

---

# 13. PyTorch의 기본 Weight Initialization

PyTorch에서는 `nn.Linear`와 같은 Layer를 생성할 때 Weight가 자동으로 초기화된다.

예를 들어 다음과 같다.

```python
layer = nn.Linear(4, 8)
```

별도의 Initialization Function을 호출하지 않아도 Weight와 Bias가 초기화된다.

`nn.Linear`의 기본 Weight 초기화는 다음 Uniform Distribution에 해당한다.

$$
\boxed{ W\sim U\left( -\frac{1}{\sqrt{fan_{in}}}, \frac{1}{\sqrt{fan_{in}}} \right) }
$$

기본 Bias 초기화 역시 동일한 범위의 Uniform Distribution을 사용한다.

여기서 중요한 점은 다음과 같다.

> `nn.Linear`의 기본 초기화는 Xavier 또는 ReLU에 맞춘 He Initialization과 동일하지 않다.

따라서 별도의 초기화가 반드시 필요한 것은 아니지만, Model Architecture와 Activation Function에 따라 사용자 정의 Initialization을 적용할 수 있다.

---

# 14. PyTorch에서 Weight Initialization 적용하기

이제 사용자 정의 MLP에 Weight Initialization을 적용해 보자.

다음과 같은 Network를 구성한다.

```text
Input(4)
   │
   ▼
Linear(4, 32)
   │
   ▼
ReLU
   │
   ▼
Linear(32, 32)
   │
   ▼
ReLU
   │
   ▼
Linear(32, 3)
   │
   ▼
Output Logits(3)
```

Hidden Layer에는 ReLU를 사용한다.

따라서 Hidden Layer에는 He Initialization을 적용하고 Output Layer에는 Xavier Initialization을 적용하는 예제를 구성한다.

이 조합은 설명을 위한 예시이며 모든 모델에 반드시 동일하게 적용해야 하는 규칙은 아니다.

---

## 14.1 Custom MLP 정의

```python
import torch
import torch.nn as nn


class CustomMLP(nn.Module):

    def __init__(self):

        super().__init__()

        self.net = nn.Sequential(
            nn.Linear(4, 32),
            nn.ReLU(),

            nn.Linear(32, 32),
            nn.ReLU(),

            nn.Linear(32, 3)
        )

    def forward(self, x):

        return self.net(x)
```

마지막 Output Layer에는 별도의 Activation Function을 적용하지 않았다.

예를 들어 Multiclass Classification에서 `nn.CrossEntropyLoss`를 사용하는 경우 Raw Logit을 그대로 전달할 수 있다.

---

## 14.2 Hidden Layer와 Output Layer를 다르게 초기화

```python
model = CustomMLP()

# Hidden Layer 1
nn.init.kaiming_normal_(
    model.net[0].weight,
    mode="fan_in",
    nonlinearity="relu"
)

# Hidden Layer 2
nn.init.kaiming_normal_(
    model.net[2].weight,
    mode="fan_in",
    nonlinearity="relu"
)

# Output Layer
nn.init.xavier_uniform_(
    model.net[4].weight
)

# Bias Initialization
for module in model.modules():

    if isinstance(module, nn.Linear):

        if module.bias is not None:

            nn.init.zeros_(module.bias)
```

여기서

- `model.net[0]`: 첫 번째 Hidden Linear Layer
- `model.net[2]`: 두 번째 Hidden Linear Layer
- `model.net[4]`: Output Linear Layer

이다.

이처럼 Layer의 역할에 따라 서로 다른 Weight Initialization을 적용할 수 있다.

---

## 14.3 model.apply()를 이용한 초기화

모델의 Layer가 많아지면 모든 Layer를 직접 지정하는 것이 번거로울 수 있다.

PyTorch에서는 `model.apply()`를 이용하여 모델 내부 Module에 초기화 함수를 재귀적으로 적용할 수 있다.

```python
def initialize_relu_layers(module):

    if isinstance(module, nn.Linear):

        nn.init.kaiming_normal_(
            module.weight,
            mode="fan_in",
            nonlinearity="relu"
        )

        if module.bias is not None:

            nn.init.zeros_(
                module.bias
            )
```

이제 모델을 생성한 뒤 다음과 같이 적용한다.

```python
model = CustomMLP()

model.apply(
    initialize_relu_layers
)
```

이 코드는 모델 내부의 모든 `nn.Linear` Layer에 He Initialization을 적용한다.

다만 Output Layer까지 동일하게 초기화한다는 점에 주의해야 한다.

Output Layer에 다른 Initialization을 적용하고 싶다면 다음과 같이 별도로 처리할 수 있다.

```python
nn.init.xavier_uniform_(
    model.net[4].weight
)
```

따라서 `model.apply()`는 동일한 초기화 방식을 여러 Layer에 적용할 때 유용하다.

# 15. 초기화 이후 Weight Statistics 확인

Weight Initialization을 수행한 뒤 실제 Weight의 평균과 표준편차를 확인할 수 있다.

```python
for name, param in model.named_parameters():

    if "weight" in name:

        print(
            name,
            "Mean:",
            param.mean().item(),
            "Std:",
            param.std().item()
        )
```

이 코드는 각 Weight Tensor의 Mean과 Standard Deviation을 출력한다.

다만 실제로 생성된 Weight의 통계량은 이론적인 값과 정확하게 일치하지 않을 수 있다.

예를 들어 다음과 같은 Initialization을 수행했다고 하자.

$$
W\sim\mathcal{N}(0,\sigma^2)
$$

이론적으로는

$$
E[W]=0
$$

$$
\operatorname{Var}(W)=\sigma^2
$$

이다.

하지만 실제 Tensor는 유한한 개수의 Sample로 구성되므로 표본평균과 표본분산에 차이가 발생할 수 있다.

따라서 초기화가 제대로 적용되었는지 확인할 때는 이론적인 Scale과 실제 통계량을 비교하되, 완전히 동일한 숫자를 기대해서는 안 된다.

# 16. 실습: Initialization에 따른 Activation 변화

지금까지 살펴본 초기화 방법이 실제 Deep Neural Network의 Activation에 어떤 영향을 미치는지 비교해 보자.

이번 실습에서는 다음 세 가지를 비교한다.

1. Small Random Initialization
2. Xavier Initialization
3. He Initialization

동일한 MLP Architecture에서 Initialization Method만 변경한다.

이를 통해 초기 Weight의 Scale이 깊은 신경망의 Forward Signal Propagation에 어떤 영향을 주는지 확인한다.

---

## 16.1 Deep MLP 구성

10개의 Linear Layer를 사용하는 모델을 정의한다.

```python
import torch
import torch.nn as nn

class DeepMLP(nn.Module):

    def __init__(
        self,
        depth=10,
        width=128
    ):

        super().__init__()

        self.layers = nn.ModuleList([
            nn.Linear(width, width)
            for _ in range(depth)
        ])

    def forward(self, x):

        activation_stds = []

        for layer in self.layers:

            x = torch.relu(
                layer(x)
            )

            activation_stds.append(
                x.std(unbiased=False).item()
            )

        return x, activation_stds
```

이 모델에서는 각 Layer가 다음 변환을 수행한다.

$$
\boxed{ \mathbb{R}^{128} \rightarrow \mathbb{R}^{128} }
$$

각 Linear Layer 이후 ReLU를 적용한다.

또한 Layer별 Activation Standard Deviation을 저장한다.

---

## 16.2 Initialization Method 정의

```python
def initialize_model(model, method):

    for layer in model.layers:

        if method == "small":

            nn.init.normal_(
                layer.weight,
                mean=0.0,
                std=0.01
            )

        elif method == "xavier":

            nn.init.xavier_normal_(
                layer.weight
            )

        elif method == "he":

            nn.init.kaiming_normal_(
                layer.weight,
                mode="fan_in",
                nonlinearity="relu"
            )

        else:

            raise ValueError(
                f"Unknown initialization: {method}"
            )

        nn.init.zeros_(
            layer.bias
        )
```

세 가지 Initialization은 다음 차이를 가진다.

| Method | 초기화 기준 |
| --- | --- |
| Small Random | 고정된 표준편차 0.01 |
| Xavier | Fan-in과 Fan-out을 고려 |
| He | Fan-in과 ReLU의 특성을 고려 |

따라서 동일한 Network라도 Layer를 통과하면서 Activation Scale이 다르게 변화할 수 있다.

---

## 16.3 Activation Standard Deviation 비교

```python
import matplotlib.pyplot as plt

# 동일한 Input Data 생성
torch.manual_seed(7)

x = torch.randn(1024, 128)

results = {}

for method in [
    "small",
    "xavier",
    "he"
]:

    # 초기화 비교를 위한 Random Seed
    torch.manual_seed(42)

    model = DeepMLP(
        depth=10,
        width=128
    )

    initialize_model(
        model,
        method
    )

    with torch.no_grad():

        _, activation_stds = model(x)

    results[method] = activation_stds


# Visualization
plt.figure(figsize=(9, 5))

for method, values in results.items():

    plt.plot(
        range(1, len(values) + 1),
        values,
        marker="o",
        label=method
    )

plt.xlabel("Layer")
plt.ylabel("Activation Standard Deviation")

plt.title(
    "Weight Initialization Comparison"
)

plt.legend()
plt.grid(alpha=0.3)

plt.show()
```

이 실습에서는 같은 Input Data와 동일한 Network Architecture를 사용한다.

다른 점은 Weight Initialization Method뿐이다.

따라서 Layer별 Activation의 변화가 초기화 방식에 따라 어떻게 달라지는지 비교할 수 있다.

---

## 16.4 결과 해석

### Small Random Initialization

Weight의 초기 표준편차가 0.01로 매우 작다.

따라서 Layer를 통과할수록 Activation Scale이 빠르게 감소할 수 있다.

깊은 Network에서는 뒤쪽 Layer의 Activation이 매우 작아지는 현상을 관찰할 수 있다.

### Xavier Initialization

Fan-in과 Fan-out을 함께 고려한다.

따라서 단순한 Small Random Initialization보다 Signal Scale을 안정적으로 유지하는 데 도움이 될 수 있다.

하지만 ReLU를 사용하는 깊은 Network에서는 Activation의 크기가 Layer를 통과하면서 감소할 수 있다.

### He Initialization

ReLU의 특성을 고려하여 초기 Weight의 분산을 결정한다.

따라서 ReLU 기반 Network에서 Activation의 Scale을 상대적으로 안정적으로 유지하는 데 도움이 될 수 있다.

다만 각 Layer의 Activation Standard Deviation이 반드시 일정하게 유지되는 것은 아니다.

실제 결과는 Random Seed, Network Width, Depth 및 Activation Distribution에 따라 달라질 수 있다.

---

## 16.5 Standard Deviation과 Second Moment의 차이

여기서 한 가지 주의할 점이 있다.

He Initialization은 ReLU를 통과한 Signal의 크기를 조절할 때 **Second Moment**를 중요한 기준으로 사용한다.

Second Moment는 다음과 같다.

$$
\boxed{ E[X^2] }
$$

반면 Variance는 다음과 같다.

$$
\boxed{ \operatorname{Var}(X) = E[X^2]-(E[X])^2 }
$$

ReLU의 출력은 일반적으로 평균이 0이 아니므로 두 값은 동일하지 않다.

따라서 He Initialization을 사용했다고 해서 Layer별 Activation Standard Deviation이 반드시 일정하게 유지된다고 해석해서는 안 된다.

더 정확하게 Signal Scale을 확인하고 싶다면 RMS(Root Mean Square)를 함께 측정할 수 있다.

$$
\boxed{ \operatorname{RMS}(X) = \sqrt{E[X^2]} }
$$

PyTorch에서는 다음과 같이 계산할 수 있다.

```python
activation_rms = (
    x.square()
    .mean()
    .sqrt()
    .item()
)
```

즉 Activation Standard Deviation과 RMS는 모두 Signal Scale을 확인하는 데 사용할 수 있지만, 서로 다른 통계량이라는 점을 구분해야 한다.

---

# 17. Weight Initialization과 Batch Normalization의 차이

Weight Initialization과 Batch Normalization은 모두 Deep Neural Network의 Training Stability와 관련된다.

하지만 역할은 다르다.

**Weight Initialization**

학습 시작 전에 Weight의 초기값과 Scale을 설정하는 방법이다.

**Batch Normalization**

Forward Propagation 과정에서 Mini-batch Statistics를 이용하여 Activation을 정규화하고, 학습 가능한 Scale·Shift Parameter를 적용하는 방법이다.

두 방법을 비교하면 다음과 같다.

| 구분 | Weight Initialization | Batch Normalization |
| --- | --- | --- |
| 적용 시점 | Training 시작 전 | Forward Propagation 중 |
| 주요 대상 | 초기 Weight | Layer Activation |
| 주요 목적 | 적절한 초기 Signal Scale 설정 | Activation Scale 및 학습 안정성 조절 |
| 대표적인 방법 | Xavier, He, LeCun | `nn.BatchNorm1d`, `nn.BatchNorm2d` |

따라서 두 방법은 서로 대체되는 개념이 아니다.

실제 모델에서는 적절한 Weight Initialization과 Batch Normalization을 함께 사용할 수 있다.

---

# 18. Weight Initialization과 Gradient Clipping의 차이

Weight Initialization과 Gradient Clipping도 Vanishing·Exploding Gradient 문제와 관련이 있다.

하지만 적용 시점과 목적은 서로 다르다.

**Weight Initialization**

Training을 시작하기 전 Weight의 초기 분산을 조절하여 신경망의 초기 Signal Propagation을 안정화한다.

**Gradient Clipping**

Backpropagation을 통해 계산된 Gradient가 지나치게 클 경우 그 크기를 제한한다.

예를 들어 PyTorch에서는 다음과 같이 사용할 수 있다.

```python
loss.backward()

torch.nn.utils.clip_grad_norm_(
    model.parameters(),
    max_norm=1.0
)

optimizer.step()
```

두 방법을 비교하면 다음과 같다.

| 구분 | Weight Initialization | Gradient Clipping |
| --- | --- | --- |
| 적용 시점 | Training 시작 전 | Backpropagation 이후 |
| 조절 대상 | 초기 Weight | 계산된 Gradient |
| 주요 목적 | 초기 Signal Propagation 안정화 | 지나치게 큰 Gradient 제한 |
| 대표적인 방법 | Xavier, He | Norm Clipping, Value Clipping |

즉 Weight Initialization은 **학습의 출발점을 조절하는 방법**이고, Gradient Clipping은 **학습 중 발생하는 큰 Gradient를 제어하는 방법**이다.

# 19. 핵심 공식 총정리

### Linear Transformation

$$
\boxed{ z=\sum_{i=1}^{n}w_ix_i+b }
$$

### Variance Propagation

단순화된 조건에서 다음 관계가 성립한다.

$$
\boxed{ \operatorname{Var}(z) \approx fan_{in} \operatorname{Var}(W) \operatorname{Var}(x) }
$$

### LeCun Initialization

$$
\boxed{ \operatorname{Var}(W) = \frac1{fan_{in}} }
$$

### Xavier Initialization

$$
\boxed{ \operatorname{Var}(W) = \frac{2}{fan_{in}+fan_{out}} }
$$

### He Initialization

$$
\boxed{ \operatorname{Var}(W) = \frac2{fan_{in}} }
$$

### Leaky ReLU Kaiming Initialization

$$
\boxed{ \operatorname{Var}(W) = \frac{2}{(1+a^2)fan_{in}} }
$$

### Xavier Uniform

$$
\boxed{ W\sim U\left( -\sqrt{\frac6{fan_{in}+fan_{out}}}, \sqrt{\frac6{fan_{in}+fan_{out}}} \right) }
$$

### He Normal

$$
\boxed{ W\sim \mathcal{N} \left( 0,\frac2{fan_{in}} \right) }
$$

# 20. 최종 정리

Weight Initialization은 Neural Network의 학습을 시작하기 전에 Weight와 Bias의 초기값을 설정하는 과정이다.

초기 Weight의 크기와 분포는 Forward Propagation에서 전달되는 Activation과 Backpropagation에서 전달되는 Gradient에 영향을 미친다.

초기 Weight가 부적절하게 설정되면 Vanishing Gradient 또는 Exploding Gradient 문제가 발생할 가능성이 커질 수 있다.

또한 모든 Hidden Neuron의 Weight를 동일하게 초기화하면 Symmetry Problem이 발생할 수 있다.

따라서 일반적인 Neural Network에서는 Weight를 무작위로 초기화하되, Network Architecture와 Activation Function을 고려하여 초기 분산을 조절한다.

대표적인 방법은 다음과 같다.

**LeCun Initialization**

Fan-in을 기준으로 Weight의 분산을 결정한다.

**Xavier Initialization**

Fan-in과 Fan-out을 함께 고려하여 Forward와 Backward Signal Scale을 조절한다.

**He Initialization**

ReLU 계열 Activation Function의 특성을 고려하여 초기 Weight의 분산을 결정한다.

PyTorch에서는 다음과 같이 구현할 수 있다.

```python
nn.init.xavier_uniform_(
    layer.weight
)
```
```python
nn.init.kaiming_normal_(
    layer.weight,
    mode="fan_in",
    nonlinearity="relu"
)
```

또한 `model.apply()`를 이용하면 여러 Layer에 Initialization을 일괄 적용할 수 있다.

Initialization Method에 따른 Activation Scale의 변화를 직접 비교하면 초기 Weight가 깊은 신경망의 Signal Propagation에 어떤 영향을 미치는지 확인할 수 있다.

따라서 중요한 것은 어떤 Initialization Method가 절대적으로 우수한지를 판단하는 것이 아니라, **Activation Function과 Network Architecture에 적합한 초기 Weight의 Scale을 설정하는 것**이다.

---

## 핵심 요약

> Weight Initialization은 신경망이 학습을 시작하기 전에 Weight의 초기값과 분산을 설정하는 과정이다. LeCun Initialization은 Fan-in을 고려하고, Xavier Initialization은 Fan-in과 Fan-out을 함께 고려하며, He Initialization은 ReLU 계열 Activation Function의 특성을 반영한다. 적절한 초기화는 Vanishing·Exploding Gradient 문제를 완화하고 Deep Neural Network의 학습 안정성을 높이는 데 도움이 된다.
