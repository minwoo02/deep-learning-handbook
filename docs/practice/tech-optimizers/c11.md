Deep Learning에서 Neural Network는 Loss Function을 최소화하는 방향으로 Weight와 Bias를 업데이트한다.

이때 Parameter Update를 수행하는 알고리즘을 **Optimizer(최적화 알고리즘)** 라고 한다.

대표적인 Optimizer는 다음과 같다.

- SGD(Stochastic Gradient Descent)
- SGD with Momentum
- AdaGrad
- RMSProp
- Adam
- AdamW

이 중 **AdamW(Adam with Decoupled Weight Decay)** 는 Adam의 Adaptive Moment Estimation을 유지하면서 Weight Decay를 Gradient 기반 Optimization과 분리한 알고리즘이다.

AdamW를 이해하려면 다음 개념들을 먼저 연결해야 한다.

```text
Gradient Descent
       │
       ▼
      SGD
       │
       ├── Momentum
       │     └── Gradient 방향의 이동평균
       │
       └── Adaptive Learning Rate
             ├── AdaGrad
             └── RMSProp
                    │
                    ▼
                   Adam
                    │
                    ├── First Moment
                    └── Second Moment
                    │
                    ▼
           L2 Regularization 문제
                    │
                    ▼
       Decoupled Weight Decay
                    │
                    ▼
                   AdamW
```

이 글에서는 SGD부터 Adam으로 발전하는 과정을 살펴보고, Adam에서 L2 Regularization과 Weight Decay가 동일하게 동작하지 않는 이유를 수학적으로 이해한다.

이후 AdamW의 Parameter Update Equation을 유도하고, PyTorch 및 Hugging Face Transformers에서 실제로 사용하는 방법을 정리한다.

---

## 1. Optimizer란?

Optimizer는 Loss Function을 최소화하기 위해 Model Parameter를 업데이트하는 알고리즘이다.

Neural Network의 학습 목적은 일반적으로 다음과 같이 표현할 수 있다.

$$
\boxed{ \theta^* = \underset{\theta}{\arg\min} \mathcal{L}(\theta) }
$$

여기서

- $\theta$: Model Parameter
- $\mathcal{L}$: Loss Function
- $\theta^*$: 최적의 Parameter

이다.

Gradient Descent에서는 Loss Function의 Gradient를 이용하여 Parameter를 업데이트한다.

$$
\boxed{ \theta_{t+1} = \theta_t-\eta\nabla_\theta\mathcal{L}(\theta_t) }
$$

여기서

- $\theta_t$: 현재 Parameter
- $\eta$: Learning Rate
- $\nabla_\theta\mathcal{L}$: Gradient

이다.

Gradient는 현재 위치에서 Loss가 가장 빠르게 증가하는 방향을 나타낸다.

따라서 Gradient의 반대 방향으로 Parameter를 이동시키면 Loss를 감소시키는 방향으로 업데이트할 수 있다.

다만 실제 Loss Function은 비선형이며 복잡한 구조를 가지므로, Gradient의 반대 방향으로 이동한다고 모든 Step에서 Loss가 반드시 감소하는 것은 아니다.

---

## 2. SGD와 Optimization의 한계

SGD(Stochastic Gradient Descent)는 전체 Training Dataset 대신 Mini-batch 등을 이용하여 Gradient를 추정하고 Parameter를 업데이트한다.

$$
\boxed{ g_t = \nabla_\theta\mathcal{L}_{B_t}(\theta_t) }
$$

$$
\boxed{ \theta_{t+1} = \theta_t-\eta g_t }
$$

여기서 $B_t$는 현재 Mini-batch이다.

SGD는 비교적 단순하지만 다음과 같은 문제를 고려해야 한다.

**① Gradient Direction의 변동**

Mini-batch마다 데이터 구성이 다르므로 계산된 Gradient가 달라질 수 있다.

따라서 Parameter Update Direction이 반복적으로 변동할 수 있다.

**② Learning Rate 선택 문제**

Learning Rate가 지나치게 크면 Training이 불안정해질 수 있다.

반대로 Learning Rate가 지나치게 작으면 Convergence가 느려질 수 있다.

이러한 문제를 완화하기 위해 두 가지 방향의 Optimizer가 발전하였다.

```text
SGD
 │
 ├── Direction Stabilization
 │     │
 │     ▼
 │   Momentum
 │
 └── Adaptive Step Size
       │
       ├── AdaGrad
       └── RMSProp
```

Adam은 이러한 두 가지 아이디어를 결합한 Optimizer로 이해할 수 있다.

## 3. Momentum이란?

Momentum을 이해하기 위해 먼저 물리학의 운동량 개념을 살펴보자.

물리학에서 Momentum은 다음과 같다.

$$
\boxed{ p=mv }
$$

여기서

- $m$: Mass
- $v$: Velocity

이다.

운동량은 물체의 운동 방향과 크기를 나타내는 물리량이다.

Optimization에서도 과거 Gradient를 고려하여 현재 Update Direction을 조절하는 방법을 사용할 수 있다.

이를 **Momentum Optimization**이라고 한다.

---

### 3.1 Momentum SGD

Momentum SGD는 다음과 같이 표현할 수 있다.

$$
\boxed{ v_t = \beta v_{t-1} + (1-\beta)g_t }
$$

$$
\boxed{ \theta_{t+1} = \theta_t-\eta v_t }
$$

여기서

- $v_t$: Gradient의 Exponential Moving Average
- $\beta$: 과거 Gradient를 반영하는 비율
- $g_t$: 현재 Gradient
- $\eta$: Learning Rate

이다.

위 수식은 Momentum을 이동평균 형태로 표현한 것이다. 구현과 문헌에 따라 $(1-\beta)$가 생략되거나 Learning Rate가 Momentum Buffer에 포함되는 등 다른 표기법도 사용한다.

Momentum은 현재 Gradient만 사용하는 것이 아니라 과거 Gradient의 방향을 함께 고려한다.

```text
Gradient at Step 1
        ↓
Gradient at Step 2
        ↓
Gradient at Step 3
        ↓
Exponential Moving Average
        ↓
Smoothed Update Direction
```

따라서 Gradient가 계속 비슷한 방향을 가리키면 그 방향으로 누적된 Update 효과가 나타난다.

반대로 Gradient가 자주 바뀌는 방향에서는 진동이 완화될 수 있다.

---

## 4. Moment와 Momentum의 차이

Adam을 이해할 때 혼동하기 쉬운 용어가 Moment와 Momentum이다.

두 단어는 비슷하지만 서로 다른 의미를 가진다.

#### Momentum

Optimization에서 과거 Gradient의 영향을 누적하여 Parameter Update의 방향을 조절하는 방법이다.

#### Moment

통계에서 확률분포의 특성을 나타내는 수학적 값이다.

확률변수 $X$에 대해 일반적인 Raw Moment는 다음과 같다.

$$
\boxed{ \mu_k'=E[X^k] }
$$

여기서 $k$는 Moment의 차수이다.

대표적으로 다음과 같다.

**First Raw Moment**

$$
\boxed{ E[X] }
$$

평균과 관련된다.

**Second Raw Moment**

$$
\boxed{ E[X^2] }
$$

값을 제곱한 크기의 평균과 관련된다.

Variance는 다음과 같다.

$$
\boxed{ \operatorname{Var}(X) = E[X^2]-(E[X])^2 }
$$

즉 Second Raw Moment와 Variance는 동일한 값이 아니다.

Adam은 Gradient의 First Moment와 Second Raw Moment를 추정한다.

## 5. Adam: Adaptive Moment Estimation

Adam은 **Adaptive Moment Estimation**의 약자이다.

Adam은 Gradient의 First Moment와 Second Moment를 Exponential Moving Average(EMA)로 추정하여 Parameter Update에 활용한다.

핵심 아이디어는 다음과 같다.

```text
Gradient
    │
    ├── First Moment
    │       │
    │       ▼
    │   Gradient Direction
    │
    └── Second Moment
            │
            ▼
      Gradient Scale
            │
            ▼
    Adaptive Step Size
```

First Moment는 Gradient의 평균적인 방향을 반영한다.

Second Moment는 Parameter별 Gradient의 Scale을 반영한다.

Adam은 두 값을 이용하여 각 Parameter의 Update Scale을 적응적으로 조절한다.

---

## 6. First Moment Estimation

Adam에서는 Gradient의 First Moment를 다음과 같이 추정한다.

$$
\boxed{ m_t = \beta_1m_{t-1} + (1-\beta_1)g_t }
$$

여기서

- $m_t$: First Moment Estimate
- $\beta_1$: First Moment의 Decay Factor
- $g_t$: 현재 Gradient

이다.

일반적으로 다음과 같은 값을 사용한다.

$$
\boxed{ \beta_1=0.9 }
$$

이는 과거 Gradient의 정보를 이동평균 형태로 유지하면서 현재 Gradient를 반영한다는 의미이다.

---

### 6.1 First Moment의 역할

First Moment는 Gradient의 평균적인 방향을 나타내는 역할을 한다.

예를 들어 Gradient가 다음과 같이 관측된다고 하자.

```text
Step 1 → Gradient: +0.8
Step 2 → Gradient: +1.2
Step 3 → Gradient: +0.9
Step 4 → Gradient: +1.1
```

각 Step의 Gradient가 조금씩 달라도 전체적으로 양의 방향을 가리키고 있다.

First Moment를 이용하면 이러한 Gradient의 방향을 평균적으로 반영할 수 있다.

즉 Moment Estimation을 통해 Update Direction의 급격한 변동을 완화하는 효과를 얻을 수 있다.

---

## 7. Second Moment Estimation

Adam의 Second Moment는 Gradient 제곱값의 Exponential Moving Average이다.

$$
\boxed{ v_t = \beta_2v_{t-1} + (1-\beta_2)g_t^2 }
$$

여기서 $g_t^2$는 Gradient Vector의 각 요소를 Element-wise로 제곱한 값이다.

일반적으로 다음 값을 사용한다.

$$
\boxed{ \beta_2=0.999 }
$$

Second Moment는 Gradient가 얼마나 큰 Scale을 가지는지 나타낸다.

예를 들어 다음 두 Parameter가 있다고 하자.

```text
Parameter A
Gradient Magnitude: Large

Parameter B
Gradient Magnitude: Small
```

Adam은 각 Parameter의 Second Moment를 이용하여 Update를 서로 다르게 Scaling할 수 있다.

일반적으로 과거 Gradient의 제곱값이 큰 Parameter는 분모가 커지므로 Update가 상대적으로 작아질 수 있다.

반면 과거 Gradient의 제곱값이 작은 Parameter는 분모가 작아져 상대적으로 큰 Update가 가능하다.

다만 실제 Update 방향과 크기는 First Moment도 함께 고려해야 한다.

---

## 8. Bias Correction

Adam에서는 First Moment와 Second Moment를 일반적으로 0으로 초기화한다.

$$
\boxed{ m_0=0,\qquad v_0=0 }
$$

그런데 초기 Step에서는 Moving Average가 0에서 시작하기 때문에 추정값이 작게 나타나는 Bias가 존재한다.

이를 보정하기 위해 **Bias Correction**을 적용한다.

First Moment의 Bias Correction은 다음과 같다.

$$
\boxed{ \hat m_t = \frac{m_t}{1-\beta_1^t} }
$$

Second Moment는 다음과 같다.

$$
\boxed{ \hat v_t = \frac{v_t}{1-\beta_2^t} }
$$

여기서 $\hat m_t$와 $\hat v_t$는 Bias-corrected Moment Estimate이다.

---

### 8.1 첫 번째 Step 예제

초기 상태에서

$$
m_0=0
$$

이고

$$
\beta_1=0.9
$$

라고 하자.

첫 번째 Gradient가 다음과 같다고 가정한다.

$$
g_1=2
$$

그러면

$$
m_1 = 0.9(0)+0.1(2)
$$

따라서

$$
\boxed{ m_1=0.2 }
$$

이다.

하지만 실제 첫 번째 Gradient는 2이다.

Bias Correction을 적용하면

$$
\hat m_1 = \frac{0.2}{1-0.9}
$$

따라서

$$
\boxed{ \hat m_1=2 }
$$

이다.

즉 EMA를 0으로 초기화하면서 발생하는 초기 Bias를 보정할 수 있다.

---

## 9. Adam의 Parameter Update

이제 Adam의 핵심 수식을 하나로 연결해 보자.

First Moment는 다음과 같다.

$$
\boxed{ m_t = \beta_1m_{t-1} + (1-\beta_1)g_t }
$$

Second Moment는 다음과 같다.

$$
\boxed{ v_t = \beta_2v_{t-1} + (1-\beta_2)g_t^2 }
$$

Bias Correction을 적용하면 다음과 같다.

$$
\boxed{ \hat m_t = \frac{m_t}{1-\beta_1^t} }
$$

$$
\boxed{ \hat v_t = \frac{v_t}{1-\beta_2^t} }
$$

최종 Parameter Update는 다음과 같다.

$$
\boxed{ \theta_{t+1} = \theta_t - \eta \frac{\hat m_t} {\sqrt{\hat v_t}+\epsilon} }
$$

여기서 $\epsilon$은 Numerical Stability를 위해 사용하는 작은 상수이다.

Vector Parameter에서는 나눗셈과 제곱근이 Element-wise로 계산된다.

---

### 9.1 Adam의 핵심 구조

Adam의 Parameter Update를 구성하는 두 요소는 다음과 같다.

#### First Moment

$$
\hat m_t
$$

Parameter를 업데이트할 Gradient의 평균적인 방향과 크기를 반영한다.

#### Second Moment

$$
\sqrt{\hat v_t}
$$

Gradient의 과거 Scale을 반영하여 각 Parameter의 Update를 조절한다.

따라서 Adam은 다음과 같이 이해할 수 있다.

```text
First Moment
      │
      ▼
Smoothed Gradient Direction
      │
      └─────────┐
                │
                ▼
          Adam Update
                ▲
                │
      ┌─────────┘
      │
Second Moment
      │
      ▼
Adaptive Scaling
```

중요한 점은 Adam이 단순히 Momentum SGD에 Learning Rate를 추가로 조절한 것이 아니라, **Gradient의 1차 및 2차 Moment Estimate를 함께 사용하는 Optimizer**라는 것이다.

---

## 10. Weight Decay란?

이제 AdamW를 이해하기 위해 Weight Decay를 살펴보자.

Weight Decay는 Parameter의 크기를 지속적으로 감소시키는 방법이다.

기본적인 Weight Decay Update는 다음과 같다.

$$
\boxed{ \theta_{t+1} = (1-\eta\lambda)\theta_t }
$$

여기서

- $\eta$: Learning Rate
- $\lambda$: Weight Decay Coefficient

이다.

일반적으로 $\eta\lambda$가 0과 1 사이의 작은 값이면 Parameter가 각 Step에서 0에 가까워지는 방향으로 감소한다.

예를 들어 다음과 같이 가정하자.

$$
\theta_t=2
$$

$$
\eta=0.01
$$

$$
\lambda=0.1
$$

그러면

$$
\theta_{t+1} = (1-0.001)\times2
$$

따라서

$$
\boxed{ \theta_{t+1}=1.998 }
$$

이다.

즉 Parameter가 2에서 1.998로 감소하였다.

이러한 방식은 Parameter가 지나치게 큰 값을 가지는 것을 억제하기 위해 사용한다.

---

## 11. L2 Regularization

Weight Decay와 관련된 개념이 **L2 Regularization**이다.

L2 Regularization은 기존 Loss Function에 Parameter 크기에 대한 Penalty를 추가한다.

다음과 같이 표현할 수 있다.

$$
\boxed{ \mathcal{L}_{reg}(\theta) = \mathcal{L}(\theta) + \frac{\lambda}{2}\|\theta\|_2^2 }
$$

여기서

- $\mathcal{L}(\theta)$: Data Loss
- $\lambda$: Regularization Strength
- $\|\theta\|_2^2$: Parameter의 Squared L2 Norm

이다.

L2 Penalty가 포함된 목적함수를 최소화하면 Parameter의 크기를 제한하는 효과를 얻을 수 있다.

---

### 11.1 L2 Regularization의 Gradient

Regularization이 포함된 Loss를 미분하면 다음과 같다.

$$
\nabla_\theta\mathcal{L}_{reg} = \nabla_\theta\mathcal{L} + \lambda\theta
$$

즉

$$
\boxed{ g_t^{reg} = g_t+\lambda\theta_t }
$$

이다.

따라서 L2 Regularization은 원래 Gradient에 $\lambda\theta_t$를 추가하는 방식으로 표현할 수 있다.

---

## 12. SGD에서는 L2 Regularization과 Weight Decay가 연결된다

L2 Regularization이 적용된 SGD를 생각해 보자.

SGD의 기본 Update는 다음과 같다.

$$
\theta_{t+1} = \theta_t-\eta g_t^{reg}
$$

여기에

$$
g_t^{reg} = g_t+\lambda\theta_t
$$

를 대입하면

$$
\theta_{t+1} = \theta_t-\eta(g_t+\lambda\theta_t)
$$

이다.

이를 전개하면 다음과 같다.

$$
\theta_{t+1} = \theta_t-\eta g_t-\eta\lambda\theta_t
$$

공통항을 묶으면 다음과 같다.

$$
\boxed{ \theta_{t+1} = (1-\eta\lambda)\theta_t - \eta g_t }
$$

여기서

$$
(1-\eta\lambda)\theta_t
$$

는 Weight Decay와 동일한 형태이다.

따라서 **일반적인 SGD에서는 동일한 계수 정의 아래 L2 Regularization과 Decoupled Weight Decay가 같은 Parameter Update를 생성한다.**

그러나 이 관계가 Adam 같은 Adaptive Optimizer에서도 그대로 성립하는 것은 아니다.

---

## 13. Adam에서는 왜 L2 Regularization이 문제가 되는가?

이 부분이 AdamW의 핵심이다.

앞에서 Adam은 Gradient의 First Moment와 Second Moment를 이용한다고 설명하였다.

그런데 L2 Regularization을 적용한 Gradient는 다음과 같다.

$$
\boxed{ g_t^{reg} = g_t+\lambda\theta_t }
$$

기존 Adam 방식에서 이 Gradient를 그대로 사용하면 어떻게 될까?

---

### 13.1 First Moment에 Regularization이 포함된다

Adam의 First Moment는 다음과 같이 계산된다.

$$
\boxed{ m_t = \beta_1m_{t-1} + (1-\beta_1) (g_t+\lambda\theta_t) }
$$

즉 Data Loss의 Gradient뿐 아니라 Regularization Gradient까지 First Moment에 포함된다.

---

### 13.2 Second Moment에도 Regularization이 포함된다

Second Moment도 마찬가지이다.

$$
\boxed{ v_t = \beta_2v_{t-1} + (1-\beta_2) (g_t+\lambda\theta_t)^2 }
$$

따라서 Weight Decay에 해당하는 항이 Second Moment에도 영향을 준다.

이로 인해 Parameter별 Adaptive Scaling에도 Regularization Gradient가 반영된다.

---

### 13.3 무엇이 문제인가?

Adam의 Parameter Update는 다음 구조를 가진다.

$$
\boxed{ \theta_{t+1} = \theta_t - \eta \frac{\hat m_t} {\sqrt{\hat v_t}+\epsilon} }
$$

여기서 Second Moment는 Parameter마다 다른 값을 가진다.

따라서 L2 Penalty의 Gradient를 Adam의 Moment 계산에 포함하면, Parameter를 줄이는 효과가 Adaptive Scaling의 영향을 받게 된다.

즉 단순히 Parameter를 일정 비율로 줄이는 Weight Decay와는 다른 Update가 발생한다.

```text
L2 Regularization
        │
        ▼
Gradient에 λθ 추가
        │
        ▼
First Moment Calculation
        │
        ▼
Second Moment Calculation
        │
        ▼
Adaptive Scaling
        │
        ▼
Parameter Update
```

핵심은 **Regularization 항이 Moment Estimation 안으로 들어간다는 것**이다.

이것이 Adam에서 L2 Regularization과 Weight Decay가 일반적으로 동일하지 않은 이유이다.

---

## 14. AdamW: Decoupled Weight Decay

AdamW의 핵심 아이디어는 다음과 같다.

> Adam의 Moment-based Optimization과 Weight Decay를 서로 분리하여 적용한다.

이를 **Decoupled Weight Decay**라고 한다.

AdamW에서는 Data Loss의 Gradient만으로 First Moment와 Second Moment를 계산한다.

$$
\boxed{ m_t = \beta_1m_{t-1} + (1-\beta_1)g_t }
$$

$$
\boxed{ v_t = \beta_2v_{t-1} + (1-\beta_2)g_t^2 }
$$

즉 Moment Estimation 과정에 $\lambda\theta_t$를 포함하지 않는다.

이후 Adam의 Adaptive Update와 Weight Decay를 별도로 적용한다.

---

### 14.1 Adam Update

Bias-corrected Moment를 이용하여 다음 Update를 계산한다.

$$
\boxed{ \Delta\theta_{\mathrm{Adam}} = -\eta \frac{\hat m_t} {\sqrt{\hat v_t}+\epsilon} }
$$

이는 Data Loss를 줄이기 위한 Adaptive Update이다.

---

### 14.2 Weight Decay

Weight Decay는 다음과 같이 계산한다.

$$
\boxed{ \Delta\theta_{\mathrm{decay}} = -\eta\lambda\theta_t }
$$

중요한 점은 Weight Decay 항이 Moment Estimate와 Adaptive Scaling에 포함되지 않는다는 것이다.

---

### 14.3 AdamW 최종 Update

두 Update를 합치면 다음과 같다.

$$
\boxed{ \theta_{t+1} = \theta_t - \eta \frac{\hat m_t} {\sqrt{\hat v_t}+\epsilon} - \eta\lambda\theta_t }
$$

또는 다음과 같이 표현할 수 있다.

$$
\boxed{ \theta_{t+1} = (1-\eta\lambda)\theta_t - \eta \frac{\hat m_t} {\sqrt{\hat v_t}+\epsilon} }
$$

즉 AdamW는 다음 두 연산을 결합한다.

```text
Data Loss Gradient
        │
        ▼
Adam Moment Estimation
        │
        ▼
Adaptive Update
        │
        ├──────────────────┐
        │                  │
        ▼                  ▼
   Adam Update        Weight Decay
        │                  │
        └────────┬─────────┘
                 │
                 ▼
          Parameter Update
```

여기서 AdamW가 분리하는 것은 Moment-based Optimization과 Weight Decay이다.

Weight Decay가 Learning Rate와 완전히 독립적인 것은 아니다. Weight Decay Update에도 $\eta$가 곱해진다.

---

## 15. Adam과 AdamW의 차이

두 방법을 비교하면 다음과 같다.

| 구분 | Adam + Coupled L2 Penalty | AdamW |
| --- | --- | --- |
| Moment Estimation | $g_t+\lambda\theta_t$ 사용 | $g_t$ 사용 |
| First Moment | Regularization 항 포함 | Data Gradient만 포함 |
| Second Moment | Regularization 항 포함 | Data Gradient만 포함 |
| Weight Decay | Adaptive Scaling과 결합됨 | 별도로 적용 |
| Parameter Shrinkage | Moment State의 영향 | 현재 Parameter에 직접 적용 |
| 핵심 특징 | Coupled Regularization | Decoupled Weight Decay |

이를 수식으로 구분하면 다음과 같다.

#### Coupled L2 Penalty

$$
\boxed{ g_t^{reg} = g_t+\lambda\theta_t }
$$

위 값을 Adam의 Moment 계산에 사용한다.

#### AdamW

$$
\boxed{ g_t = \nabla_\theta\mathcal{L}(\theta_t) }
$$

Moment 계산에는 Data Gradient를 사용하고 Weight Decay는 별도의 Update 항으로 계산한다.

따라서 두 방법은 일반적으로 같은 결과를 만들지 않는다.

---

## 16. AdamW와 L2 Regularization은 완전히 같은가?

여기서 개념을 정확하게 구분해야 한다.

**L2 Regularization**은 Loss Function에 Penalty를 추가하는 방법이다.

$$
\boxed{ \mathcal{L}_{reg} = \mathcal{L} + \frac{\lambda}{2}\|\theta\|_2^2 }
$$

**Decoupled Weight Decay**는 Parameter Update에서 직접 Shrinkage를 적용하는 방법이다.

$$
\boxed{ \theta \leftarrow (1-\eta\lambda)\theta }
$$

일반적인 SGD에서는 두 방식이 동일한 Parameter Update로 표현될 수 있다.

그러나 Adam처럼 Adaptive Scaling을 사용하는 Optimizer에서는 두 방식이 일반적으로 동등하지 않다.

AdamW는 L2 Penalty를 Loss에 추가하여 Adam으로 최적화하는 방식이 아니라, **Adam Update와 Parameter Shrinkage를 분리하는 방법**이다.

따라서 AdamW가 L2-regularized Loss를 일반적인 Adam으로 최적화하는 것과 수학적으로 동일하다고 설명해서는 안 된다.

---

## 17. PyTorch로 Adam과 AdamW 차이 확인하기

실제로 두 Optimizer가 서로 다른 Parameter Update를 수행하는지 확인해 보자.

간단한 실험을 구성한다.

초기 Parameter는 다음과 같다.

$$
\boxed{ \theta_0=1 }
$$

Data Loss Gradient는 0이라고 가정한다.

$$
\boxed{ g_1=0 }
$$

Hyperparameter는 다음과 같이 설정한다.

$$
\eta=0.01,\qquad\lambda=0.1
$$

---

### 17.1 Adam과 AdamW 비교 코드

```python
import torch

# 동일한 초기 Parameter
p_adam = torch.nn.Parameter(
    torch.tensor([1.0])
)

p_adamw = torch.nn.Parameter(
    torch.tensor([1.0])
)

# Adam: Coupled L2 Penalty
optimizer_adam = torch.optim.Adam(
    [p_adam],
    lr=0.01,
    weight_decay=0.1
)

# AdamW: Decoupled Weight Decay
optimizer_adamw = torch.optim.AdamW(
    [p_adamw],
    lr=0.01,
    weight_decay=0.1
)

# Data Loss Gradient = 0
p_adam.grad = torch.zeros_like(p_adam)
p_adamw.grad = torch.zeros_like(p_adamw)

optimizer_adam.step()
optimizer_adamw.step()

print("Adam :", p_adam.item())
print("AdamW:", p_adamw.item())
```

이 예제에서는 두 Optimizer 모두 같은 Parameter와 Hyperparameter를 사용한다.

차이는 Weight Decay를 적용하는 방식뿐이다.

---

### 17.2 결과 해석

일반적인 설정에서 첫 번째 Step의 결과는 다음과 비슷하다.

```text
Adam : 0.990000
AdamW: 0.999000
```

Adam에서는 L2 Penalty의 Gradient가 Moment Estimation에 포함된다.

따라서 Data Gradient가 0이더라도 Regularization Gradient가 Adaptive Update에 영향을 준다.

반면 AdamW는 Data Gradient가 0이므로 Adam의 Adaptive Update는 발생하지 않고, Decoupled Weight Decay만 적용된다.

$$
\theta_1 = (1-0.01\times0.1)(1)
$$

따라서

$$
\boxed{ \theta_1=0.999 }
$$

이다.

이 실험을 통해 **Coupled L2 Penalty와 Decoupled Weight Decay는 서로 다른 Parameter Update를 생성한다**는 사실을 확인할 수 있다.

참고로 이 코드는 0으로 채워진 Gradient Tensor를 직접 지정한 예제이다. PyTorch에서는 Gradient가 `None`인 Parameter에 대해 Optimizer Step이 수행되지 않을 수 있으므로, Gradient가 0인 경우와 아예 존재하지 않는 경우를 구분해야 한다.

---

## 18. PyTorch에서 AdamW 사용하기

PyTorch에서는 `torch.optim.AdamW`를 제공한다.

기본적인 사용법은 다음과 같다.

```python
import torch

optimizer = torch.optim.AdamW(
    model.parameters(),
    lr=0.001,
    betas=(0.9, 0.999),
    eps=1e-8,
    weight_decay=0.01
)
```

각 Argument의 의미는 다음과 같다.

| Argument | 의미 |
| --- | --- |
| `model.parameters()` | 업데이트할 Model Parameter |
| `lr` | Learning Rate |
| `betas` | First·Second Moment의 EMA 계수 |
| `eps` | Numerical Stability |
| `weight_decay` | Decoupled Weight Decay Coefficient |

여기서 `weight_decay`는 Loss Function에 자동으로 L2 Penalty를 더하는 설정이 아니다.

AdamW는 해당 값을 이용하여 Parameter Shrinkage를 별도로 수행한다.

---

### 18.1 AdamW의 기본 Hyperparameter

PyTorch의 `torch.optim.AdamW`에서 대표적인 기본값은 다음과 같다.

```python
lr = 0.001
betas = (0.9, 0.999)
eps = 1e-8
weight_decay = 0.01
```

따라서 Weight Decay를 사용하지 않으려면 다음과 같이 설정해야 한다.

```python
optimizer = torch.optim.AdamW(
    model.parameters(),
    lr=0.001,
    weight_decay=0.0
)
```

반면 `torch.optim.Adam`의 기본 `weight_decay`는 0이다.

따라서 두 Optimizer를 비교할 때는 기본 Hyperparameter까지 동일하게 설정했는지 확인해야 한다.

---

## 19. Bias와 LayerNorm에 Weight Decay를 적용하지 않는 이유

실제 Deep Learning Model에서는 모든 Parameter에 동일한 Weight Decay를 적용하지 않는 경우가 많다.

특히 Transformer에서는 다음 Parameter를 Weight Decay 대상에서 제외하는 관행이 널리 사용된다.

- Bias
- LayerNorm의 Scale·Shift Parameter

그 이유는 이러한 Parameter가 일반적인 Weight Matrix와 다른 역할을 하기 때문이다.

예를 들어 Layer Normalization은 다음과 같이 표현할 수 있다.

$$
\boxed{ y = \gamma \frac{x-\mu}{\sqrt{\sigma^2+\epsilon}} + \beta }
$$

여기서

- $\gamma$: Learnable Scale Parameter
- $\beta$: Learnable Shift Parameter

이다.

이 Parameter들을 지속적으로 0으로 감소시키는 것이 항상 바람직한 것은 아니다.

따라서 많은 Transformer Training Recipe에서는 Weight Matrix에 Decay를 적용하고 Bias 및 Normalization Parameter에서는 제외한다.

다만 모든 모델에서 이러한 분리가 반드시 최적이라는 의미는 아니다.

Weight Decay 대상은 Model Architecture와 Training Recipe에 따라 결정해야 한다.

---

## 20. Parameter Grouping

PyTorch에서는 Parameter마다 서로 다른 Hyperparameter를 적용할 수 있다.

이를 **Parameter Grouping**이라고 한다.

예를 들어 Weight Decay를 적용할 Parameter와 적용하지 않을 Parameter를 구분할 수 있다.

```python
import torch

decay_params = []
no_decay_params = []

for name, param in model.named_parameters():

    if not param.requires_grad:
        continue

    # 실무에서 사용하는 간단한 분류 기준
    if param.ndim >= 2:
        decay_params.append(param)
    else:
        no_decay_params.append(param)

optimizer = torch.optim.AdamW(
    [
        {
            "params": decay_params,
            "weight_decay": 0.01
        },
        {
            "params": no_decay_params,
            "weight_decay": 0.0
        }
    ],
    lr=0.001
)
```

이 예제는 Tensor Dimension을 기준으로 Parameter를 구분한다.

일반적인 Linear Weight Matrix는 2차원 Tensor이므로 Weight Decay가 적용된다.

반면 Bias나 LayerNorm Scale Parameter는 보통 1차원 Tensor이므로 제외된다.

다만 이러한 구분은 간단한 실습용 규칙이다.

실제 연구 코드에서는 Parameter Name 또는 Module Type에 따라 더 정확하게 Parameter Group을 구성하기도 한다.

---

## 21. AdamW를 이용한 Training Loop

AdamW를 사용하더라도 일반적인 PyTorch Training Loop의 구조는 달라지지 않는다.

```text
Input Batch
     │
     ▼
Forward Propagation
     │
     ▼
Loss Calculation
     │
     ▼
Backward Propagation
     │
     ▼
Gradient Calculation
     │
     ▼
AdamW Optimizer Step
     │
     ├── Adaptive Moment Update
     │
     └── Decoupled Weight Decay
     │
     ▼
Updated Parameters
```

예를 들어 다음과 같이 작성할 수 있다.

```python
import torch
import torch.nn as nn

model = nn.Sequential(
    nn.Linear(4, 64),
    nn.ReLU(),
    nn.Linear(64, 3)
)

criterion = nn.CrossEntropyLoss()

optimizer = torch.optim.AdamW(
    model.parameters(),
    lr=1e-3,
    weight_decay=0.01
)

# 예제용 Synthetic Data
torch.manual_seed(42)

X = torch.randn(100, 4)
y = torch.randint(0, 3, (100,))

epochs = 20

for epoch in range(epochs):

    model.train()

    optimizer.zero_grad()

    logits = model(X)

    loss = criterion(logits, y)

    loss.backward()

    optimizer.step()

    print(
        f"Epoch {epoch+1:02d} "
        f"| Loss: {loss.item():.4f}"
    )
```

이 예제에서 AdamW는 Backpropagation으로 계산된 Gradient를 이용하여 Model Parameter를 업데이트한다.

또한 `weight_decay=0.01`이 설정되어 있으므로 해당 Parameter에 Decoupled Weight Decay를 적용한다.

이 코드는 Optimizer의 동작을 보여주기 위한 예제이다.

실제 Generalization Performance를 확인하려면 별도의 Validation Set과 Test Set을 사용해야 한다.

## 22. Hugging Face Transformers에서 AdamW 사용하기

AdamW는 Transformer 기반 모델의 Training과 Fine-tuning에서 널리 사용된다.

Hugging Face Transformers에서는 `Trainer`와 `TrainingArguments`를 이용하여 Optimizer 설정을 관리할 수 있다.

대표적인 예제는 다음과 같다.

```python
from transformers import (
    Trainer,
    TrainingArguments
)

training_args = TrainingArguments(
    output_dir="./results",

    learning_rate=5e-5,
    weight_decay=0.01,

    per_device_train_batch_size=8,
    num_train_epochs=3,

    optim="adamw_torch",

    lr_scheduler_type="linear",
    warmup_steps=100
)

trainer = Trainer(
    model=model,
    args=training_args,
    train_dataset=train_dataset,
    eval_dataset=eval_dataset
)

trainer.train()
```

이 코드는 이미 준비된 Transformer-compatible Model과 Dataset이 있다는 가정하에 작성한 설정 예제이다.

---

### 22.1 Trainer의 AdamW 설정

`TrainingArguments`에서는 다음과 같은 Hyperparameter를 설정할 수 있다.

| Hyperparameter | 의미 |
| --- | --- |
| `learning_rate` | Optimizer Learning Rate |
| `weight_decay` | Weight Decay Strength |
| `adam_beta1` | First Moment EMA |
| `adam_beta2` | Second Moment EMA |
| `adam_epsilon` | Numerical Stability |
| `optim` | Optimizer 종류 |
| `lr_scheduler_type` | Learning Rate Schedule |
| `warmup_steps` | Warmup Step 수 |

Hugging Face Trainer는 설정에 따라 AdamW Optimizer와 Learning Rate Scheduler를 구성한다.

일반적으로 Bias와 LayerNorm Parameter는 Weight Decay 대상에서 제외하는 방식으로 Parameter Grouping을 처리한다.

---

### 22.2 PyTorch와 Hugging Face의 기본값 차이

주의해야 할 점은 `torch.optim.AdamW`와 Hugging Face `TrainingArguments`의 기본값이 완전히 같지 않다는 것이다.

대표적으로 다음과 같은 차이가 있다.

| 설정 | PyTorch AdamW | Hugging Face TrainingArguments |
| --- | --- | --- |
| Learning Rate 기본값 | `0.001` | `5e-5` |
| Weight Decay 기본값 | `0.01` | `0.0` |
| Betas | `(0.9, 0.999)` | `(0.9, 0.999)` |
| Epsilon | `1e-8` | `1e-8` |

따라서 동일한 AdamW 알고리즘을 사용하더라도 Framework의 기본 설정 차이로 인해 학습 결과가 달라질 수 있다.

또한 Hugging Face에서 `linear` Scheduler가 기본으로 사용되더라도, 기본 `warmup_steps`가 0이면 Warmup은 수행되지 않는다.

## 23. Learning Rate Warmup

Transformer Training에서는 AdamW와 함께 Learning Rate Warmup을 사용하는 경우가 많다.

Warmup은 Training 초기부터 큰 Learning Rate를 적용하는 대신, 작은 Learning Rate에서 시작하여 일정 Step 동안 점진적으로 증가시키는 방법이다.

```text
Learning Rate
      ↑
      │        ┌────────
      │       /
      │      /
      │     /
      │    /
      │___/__________________→ Step
          Warmup
```

대표적인 Linear Warmup은 다음과 같은 개념으로 표현할 수 있다.

$$
\boxed{ \eta_t = \eta_{\max} \frac{t}{T_{\mathrm{warmup}}} }
$$

단, $t$가 Warmup 구간에 포함된다고 가정한다.

여기서

- $\eta_{\max}$: Target Learning Rate
- $T_{\mathrm{warmup}}$: Warmup Step 수

이다.

Warmup 이후에는 일정한 Learning Rate를 유지하거나 Linear Decay, Cosine Decay 등의 Scheduler를 사용할 수 있다.

Warmup은 초기 Training Stability를 개선하는 데 도움이 될 수 있지만, 모든 AdamW Training에서 필수적인 것은 아니다.

---

## 24. AdamW의 장점과 고려사항

### 24.1 장점

**Decoupled Weight Decay**

Weight Decay를 Adaptive Moment Estimation과 분리하여 Parameter Shrinkage를 직접 적용한다.

**Adaptive Optimization 유지**

Adam의 First·Second Moment 기반 Update를 그대로 활용한다.

**Parameter별 Adaptive Scaling**

Gradient의 Scale에 따라 Parameter별 Update를 조절할 수 있다.

**Transformer Training에 활용**

Transformer 기반 모델의 Training과 Fine-tuning에서 널리 사용되는 Optimizer이다.

---

### 24.2 고려사항

AdamW가 모든 문제에서 가장 좋은 Optimizer인 것은 아니다.

학습 성능은 다음 요소의 영향을 받는다.

- Learning Rate
- Weight Decay Strength
- Model Architecture
- Batch Size
- Dataset
- Learning Rate Scheduler
- Training Duration

특히 Weight Decay는 Model Parameter에 제약을 가하는 Hyperparameter이므로 지나치게 크게 설정하면 Underfitting을 유발할 수도 있다.

따라서 실제 최적의 Weight Decay는 Validation Performance를 이용하여 선택해야 한다.

---

## 25. AdamW에서 혼동하기 쉬운 개념

### 25.1 AdamW는 Adam보다 항상 성능이 좋은가?

그렇지 않다.

AdamW는 Weight Decay를 Adaptive Update와 분리한다는 구조적 차이를 가진다.

하지만 실제 성능은 Task와 Hyperparameter에 따라 달라질 수 있다.

특히 Weight Decay를 사용하지 않는 경우에는 일반적인 설정에서 Adam과 AdamW가 같은 방식으로 동작할 수 있다.

---

### 25.2 AdamW의 W는 무엇을 의미하는가?

AdamW의 W는 일반적으로 Weight Decay를 분리한 Adam Variant를 구분하는 명칭이다.

즉 AdamW의 핵심은 **Decoupled Weight Decay**이다.

---

### 25.3 AdamW는 Weight Initialization 방법인가?

아니다.

Weight Initialization은 Training 시작 전에 Parameter의 초기값을 설정하는 방법이다.

반면 AdamW는 Training 중 Gradient를 이용하여 Parameter를 업데이트하는 Optimizer이다.

```text
Weight Initialization
        │
        ▼
Initial Parameters
        │
        ▼
Training
        │
        ▼
AdamW Optimizer
        │
        ▼
Parameter Update
```

따라서 서로 다른 단계에 적용되는 개념이다.

---

### 25.4 AdamW와 Gradient Clipping은 같은가?

아니다.

Gradient Clipping은 계산된 Gradient의 크기를 제한하는 방법이다.

AdamW는 Moment-based Optimization과 Weight Decay를 수행한다.

두 방법은 함께 사용할 수도 있다.

```python
optimizer.zero_grad()

loss.backward()

torch.nn.utils.clip_grad_norm_(
    model.parameters(),
    max_norm=1.0
)

optimizer.step()
```

이 경우 Gradient Clipping이 먼저 적용되고, 이후 AdamW가 업데이트를 수행한다.

## 26. 핵심 공식 총정리

### SGD

$$
\boxed{ \theta_{t+1} = \theta_t-\eta g_t }
$$

### First Moment

$$
\boxed{ m_t = \beta_1m_{t-1} + (1-\beta_1)g_t }
$$

### Second Moment

$$
\boxed{ v_t = \beta_2v_{t-1} + (1-\beta_2)g_t^2 }
$$

### Bias Correction

$$
\boxed{ \hat m_t = \frac{m_t}{1-\beta_1^t} }
$$

$$
\boxed{ \hat v_t = \frac{v_t}{1-\beta_2^t} }
$$

### Adam Update

$$
\boxed{ \theta_{t+1} = \theta_t - \eta \frac{\hat m_t} {\sqrt{\hat v_t}+\epsilon} }
$$

### L2 Regularization

$$
\boxed{ \mathcal{L}_{reg} = \mathcal{L} + \frac{\lambda}{2}\|\theta\|_2^2 }
$$

### SGD with L2 Penalty

$$
\boxed{ \theta_{t+1} = (1-\eta\lambda)\theta_t - \eta g_t }
$$

### AdamW Update

$$
\boxed{ \theta_{t+1} = (1-\eta\lambda)\theta_t - \eta \frac{\hat m_t} {\sqrt{\hat v_t}+\epsilon} }
$$

---

## 27. 최종 정리

AdamW는 Adam의 Adaptive Moment Estimation을 유지하면서 Weight Decay를 Gradient-based Optimization과 분리한 Optimizer이다.

Adam은 Gradient의 First Moment와 Second Moment를 추정하여 Parameter Update에 활용한다.

First Moment는 Gradient의 평균적인 방향과 크기를 반영한다.

Second Moment는 Gradient의 Scale을 반영하여 Parameter별 Update를 적응적으로 조절한다.

하지만 Adam에서 L2 Regularization을 Gradient에 직접 포함하면 Regularization 항도 Moment Estimation과 Adaptive Scaling의 영향을 받는다.

따라서 일반적인 Adam에서는 L2 Regularization과 Weight Decay가 동일한 Parameter Update를 생성하지 않는다.

AdamW는 이 문제를 해결하기 위해 Weight Decay를 별도로 적용한다.

```text
SGD
  │
  ▼
Momentum + Adaptive Step Size
  │
  ▼
Adam
  │
  ▼
Moment-based Optimization
  │
  ▼
Coupled L2 Penalty 문제
  │
  ▼
Decoupled Weight Decay
  │
  ▼
AdamW
```

AdamW의 최종 Update는 다음과 같다.

$$
\boxed{ \theta_{t+1} = \theta_t - \eta \frac{\hat m_t} {\sqrt{\hat v_t}+\epsilon} - \eta\lambda\theta_t }
$$

이 식에서 첫 번째 Update 항은 Adam의 Moment-based Optimization을 수행한다.

두 번째 Update 항은 Parameter의 크기를 직접 감소시키는 Weight Decay를 수행한다.

따라서 **AdamW의 핵심은 Adam의 Adaptive Optimization과 Weight Decay를 Decoupling하는 것**이다.

---

### 핵심 요약

> Adam은 Gradient의 First Moment와 Second Moment를 추정하여 Parameter별 Adaptive Update를 수행하는 Optimizer이다. 그러나 Adam에서 L2 Regularization을 Gradient에 직접 포함하면 Regularization 항이 Moment Estimation과 Adaptive Scaling에 함께 반영된다. AdamW는 이러한 문제를 해결하기 위해 Weight Decay를 Moment-based Optimization에서 분리하고, Parameter Shrinkage를 독립적인 Update 항으로 적용한다.
