Deep Neural Network에서는 Backpropagation을 통해 Loss Function에 대한 Gradient를 계산하고 이를 이용하여 Parameter를 갱신한다.

일반적인 Gradient Descent는 다음과 같이 표현할 수 있다.

$$
\boxed{ \theta_{t+1} = \theta_t - \eta\nabla_\theta L(\theta_t) }
$$

여기서

- $\theta_t$: 현재 Model Parameters
- $\eta$: Learning Rate
- $\nabla_\theta L$: Loss에 대한 Gradient

이다.

그런데 Backpropagation 과정에서 Gradient가 지나치게 커지는 경우가 있다.

이러한 현상을 **Exploding Gradient Problem**이라고 한다.

Exploding Gradient가 발생하면 Parameter Update가 지나치게 커져 학습이 불안정해질 수 있다.

이를 완화하기 위한 대표적인 방법이 **Gradient Clipping(기울기 클리핑)** 이다.

Gradient Clipping은 계산된 Gradient가 미리 설정한 기준을 초과하지 않도록 크기를 제한하는 방법이다.

대표적인 방법은 다음과 같다.

- Gradient Clipping by Value
- Gradient Clipping by Norm

이 글에서는 두 방법의 수학적 원리를 살펴보고, PyTorch에서 직접 구현하는 방법을 정리한다.

---

## 1. Exploding Gradient란?

Deep Neural Network의 Backpropagation에서는 Chain Rule에 의해 여러 Gradient가 곱해진다.

예를 들어 다음과 같은 신경망을 생각하자.

```text
Input
  │
  ▼
Layer 1
  │
  ▼
Layer 2
  │
  ▼
Layer 3
  │
  ▼
Output
```

Forward Propagation에서는 Input에서 Output 방향으로 연산이 진행된다.

Backpropagation에서는 Output에서 Input 방향으로 Gradient를 계산한다.

```text
Output
  │
  ▼
Gradient
  │
  ▼
Layer 3
  │
  ▼
Gradient
  │
  ▼
Layer 2
  │
  ▼
Gradient
  │
  ▼
Layer 1
```

이때 Weight Matrix 및 Activation Function의 미분값이 반복적으로 곱해진다.

따라서 특정 조건에서는 Gradient가 매우 커질 수 있다.

예를 들어

$$
2\times2\times2\times2\times2=32
$$

이고,

$$
3\times3\times3\times3\times3=243
$$

이다.

이처럼 1보다 큰 값이 반복적으로 곱해지면 결과가 빠르게 증가한다.

신경망에서도 유사한 현상이 발생할 수 있다.

---

## 2. Exploding Gradient가 학습에 미치는 영향

Gradient Descent에서는 다음과 같이 Parameter를 갱신한다.

$$
\theta_{t+1} = \theta_t - \eta\nabla_\theta L
$$

여기서 Gradient의 크기가 지나치게 크면 Update의 크기도 커질 수 있다.

예를 들어

$$
\eta=0.01
$$

이고

$$
\nabla_\theta L=10000
$$

이라면 단순한 Gradient Descent의 Update 크기는

$$
\boxed{ \eta\nabla_\theta L=100 }
$$

이다.

한 번의 Update로 Parameter가 100만큼 변화할 수 있다는 의미이다.

이러한 큰 Update는 Loss를 감소시키기보다 오히려 증가시킬 수 있다.

결과적으로 다음 문제가 발생할 수 있다.

- Training Loss의 급격한 증가
- Parameter Update의 불안정
- Loss Divergence
- Numerical Overflow
- NaN 또는 Inf 발생

이를 완화하기 위해 Gradient의 크기를 제한할 수 있다.

---

## 3. Gradient Clipping의 기본 개념

Gradient Clipping은 Backpropagation으로 계산한 Gradient를 Optimizer에 전달하기 전에 제한하는 방법이다.

일반적인 학습 과정은 다음과 같다.

```text
Forward Propagation
        │
        ▼
Loss Calculation
        │
        ▼
Backward Propagation
        │
        ▼
Gradient Calculation
        │
        ▼
Gradient Clipping
        │
        ▼
Optimizer Step
        │
        ▼
Parameter Update
```

즉 중요한 점은 **Gradient Clipping을 Backward 이후, Optimizer Step 이전에 적용한다는 것**이다.

Gradient Clipping은 이미 계산된 Gradient를 수정한다.

Weight Initialization처럼 학습 시작 전에 적용하는 방법과는 다르다.

## 4. Gradient Clipping by Value

Gradient Clipping by Value는 Gradient의 각 원소를 지정한 범위 안으로 제한하는 방법이다.

예를 들어 기준값을 $c$라고 하자.

그러면 각 Gradient 원소는 다음 범위로 제한된다.

$$
\boxed{ -c\le g_i\le c }
$$

이때 새로운 Gradient는 다음과 같이 정의된다.

$$
\boxed{ g_i^{clip} = \begin{cases} -c,&g_i<-c\\ g_i,&-c\le g_i\le c\\ c,&g_i>c \end{cases} }
$$

이다.

---

### 4.1 Value Clipping 예제

다음 Gradient Vector를 생각하자.

$$
\boxed{ \mathbf{g} = \begin{bmatrix} 3\\ -4\\ 0.5 \end{bmatrix} }
$$

Clipping Threshold를 다음과 같이 설정한다.

$$
\boxed{ c=1 }
$$

각 원소를 $[-1,1]$ 범위로 제한하면 다음과 같다.

$$
\boxed{ \mathbf{g}_{clip} = \begin{bmatrix} 1\\ -1\\ 0.5 \end{bmatrix} }
$$

즉

- 3은 1로 변경된다.
- -4는 -1로 변경된다.
- 0.5는 그대로 유지된다.

이러한 방법이 Gradient Clipping by Value이다.

---

### 4.2 PyTorch 구현

PyTorch에서는 다음 함수를 사용한다.

```python
torch.nn.utils.clip_grad_value_()
```

사용 방법은 다음과 같다.

```python
import torch
import torch.nn as nn

parameter = nn.Parameter(
    torch.zeros(3)
)

parameter.grad = torch.tensor([
    3.0,
    -4.0,
    0.5
])

print(
    "Before:",
    parameter.grad
)

nn.utils.clip_grad_value_(
    [parameter],
    clip_value=1.0
)

print(
    "After:",
    parameter.grad
)
```

출력:

```text
Before: tensor([ 3.0000, -4.0000,  0.5000])

After: tensor([ 1.0000, -1.0000,  0.5000])
```

여기서 중요한 점은 `clip_grad_value_()`가 Parameter 자체가 아니라 **Parameter의 `.grad` 값을 수정한다는 것**이다.

## 5. Gradient Clipping by Norm

Gradient Clipping by Norm은 Gradient Vector 전체의 크기를 제한하는 방법이다.

특히 많이 사용되는 방법은 L2 Norm을 기준으로 Clipping하는 것이다.

Gradient Vector를 다음과 같이 정의하자.

$$
\boxed{ \mathbf{g} = \begin{bmatrix} g_1\\ g_2\\ \vdots\\ g_n \end{bmatrix} }
$$

이 벡터의 L2 Norm은 다음과 같다.

$$
\boxed{ \|\mathbf{g}\|_2 = \sqrt{ \sum_{i=1}^{n}g_i^2 } }
$$

이다.

Gradient Clipping by Norm은 이 값이 지정한 Threshold를 초과하면 전체 Gradient Vector의 크기를 줄인다.

---

### 5.1 Norm Clipping 수식

Clipping Threshold를 $c$라고 하자.

그러면 Gradient Clipping by Norm은 다음과 같이 표현할 수 있다.

$$
\boxed{ \mathbf{g}_{clip} = \begin{cases} \mathbf{g}, & \|\mathbf{g}\|_2\le c \\[6pt] \displaystyle c\frac{\mathbf{g}}{\|\mathbf{g}\|_2}, & \|\mathbf{g}\|_2>c \end{cases} }
$$

이다.

이를 하나의 식으로 표현하면 다음과 같다.

$$
\boxed{ \mathbf{g}_{clip} = \mathbf{g} \cdot \min \left( 1, \frac{c}{\|\mathbf{g}\|_2} \right) }
$$

이다.

따라서 Gradient Norm이 Threshold보다 작으면 변경하지 않는다.

반면 Gradient Norm이 Threshold보다 크면 벡터 전체에 같은 비율을 곱하여 크기를 줄인다.

---

## 6. Norm Clipping 계산 예제

다음 Gradient Vector를 생각하자.

$$
\boxed{ \mathbf{g} = \begin{bmatrix} 3\\ 4 \end{bmatrix} }
$$

L2 Norm은 다음과 같다.

$$
\|\mathbf{g}\|_2 = \sqrt{3^2+4^2}
$$

따라서

$$
\boxed{ \|\mathbf{g}\|_2=5 }
$$

이다.

Clipping Threshold를 2로 설정하자.

$$
\boxed{ c=2 }
$$

현재 Gradient Norm은 5이므로 Threshold를 초과한다.

따라서 다음과 같이 Scaling한다.

$$
\mathbf{g}_{clip} = \frac{2}{5} \begin{bmatrix} 3\\ 4 \end{bmatrix}
$$

계산하면

$$
\boxed{ \mathbf{g}_{clip} = \begin{bmatrix} 1.2\\ 1.6 \end{bmatrix} }
$$

이다.

이 벡터의 Norm을 계산하면

$$
\|\mathbf{g}_{clip}\|_2 = \sqrt{1.2^2+1.6^2}
$$

따라서

$$
\boxed{ \|\mathbf{g}_{clip}\|_2=2 }
$$

이다.

즉 원래 Gradient Vector의 Norm은 5였지만 Clipping 이후에는 2가 된다.

여기서 중요한 점은 두 원소에 동일한 비율을 곱했다는 것이다.

따라서 **Gradient Vector의 방향은 유지하고 크기만 제한한다.**

---

## 7. PyTorch에서 Norm Clipping 구현

PyTorch에서는 다음 함수를 사용한다.

```python
torch.nn.utils.clip_grad_norm_()
```

직접 구현해 보자.

```python
import torch
import torch.nn as nn

parameter = nn.Parameter(
    torch.zeros(2)
)

parameter.grad = torch.tensor([
    3.0,
    4.0
])

print(
    "Before:",
    parameter.grad
)

total_norm = nn.utils.clip_grad_norm_(
    [parameter],
    max_norm=2.0
)

print(
    "Original Norm:",
    total_norm.item()
)

print(
    "After:",
    parameter.grad
)
```

출력은 다음과 같다.

```text
Before: tensor([3., 4.])

Original Norm: 5.0

After: tensor([1.2000, 1.6000])
```

여기서

```python
max_norm=2.0
```

은 Gradient의 전체 Norm이 2를 초과하지 않도록 제한한다는 의미이다.

---

### 7.1 clip*grad_norm*()의 반환값

다음 코드를 살펴보자.

```python
total_norm = nn.utils.clip_grad_norm_(
    model.parameters(),
    max_norm=1.0
)
```

`clip_grad_norm_()`는 Gradient를 In-place로 수정한다.

그리고 반환값은 **Clipping 이전의 Total Gradient Norm**이다.

따라서 반환값이 1보다 크다고 해서 Clipping이 실패한 것은 아니다.

예를 들어 다음과 같은 상황이 가능하다.

```text
Original Gradient Norm
          5.0
           │
           ▼
Gradient Clipping
    max_norm = 1.0
           │
           ▼
Clipped Gradient Norm
          1.0
```

하지만 함수의 반환값은 5.0에 해당한다.

이 점은 Gradient Norm을 모니터링할 때 중요하다.

## 8. Value Clipping과 Norm Clipping의 차이

두 방법은 모두 Gradient의 크기를 제한하지만 적용 방식이 다르다.

#### Value Clipping

Gradient의 각 원소를 개별적으로 제한한다.

$$
\boxed{ g_i^{clip} = \operatorname{clip}(g_i,-c,c) }
$$

#### Norm Clipping

Gradient Vector 전체의 Norm을 제한한다.

$$
\boxed{ \mathbf{g}_{clip} = \mathbf{g} \min\left( 1, \frac{c}{\|\mathbf{g}\|_2} \right) }
$$

두 방법을 비교하면 다음과 같다.

| 구분 | Value Clipping | Norm Clipping |
| --- | --- | --- |
| 기준 | 각 Gradient 원소 | Gradient Vector 전체 |
| 제한 대상 | 개별 값 | 전체 Norm |
| Gradient 방향 | 변할 수 있음 | 일반적으로 유지 |
| PyTorch 함수 | `clip_grad_value_()` | `clip_grad_norm_()` |
| 대표 활용 | 원소별 값 제한 | 전체 Gradient Scale 제한 |

실제 딥러닝에서는 Norm Clipping이 널리 사용된다.

특히 Gradient Vector의 방향을 유지하면서 크기를 제한하고 싶을 때 유용하다.

## 9. Global Gradient Norm이란?

PyTorch의 `clip_grad_norm_()`에서 중요한 개념이 Global Gradient Norm이다.

일반적인 신경망에는 여러 Parameter Tensor가 존재한다.

예를 들어 다음과 같다.

```text
Layer 1
  ├── Weight
  └── Bias

Layer 2
  ├── Weight
  └── Bias

Layer 3
  ├── Weight
  └── Bias
```

각 Parameter마다 Gradient Tensor가 존재한다.

`clip_grad_norm_(model.parameters(), ...)`는 이러한 Gradient들을 하나의 긴 Vector로 연결했다고 생각하고 전체 Norm을 계산한다.

따라서 모든 Parameter의 Gradient에 동일한 Scaling Factor가 적용된다.

---

### 9.1 Global L2 Norm

각 Parameter의 Gradient Tensor를 다음과 같이 정의하자.

$$
G_1,G_2,\cdots,G_K
$$

전체 Gradient의 L2 Norm은 다음과 같다.

$$
\boxed{ \|\mathbf{g}\|_2 = \sqrt{ \sum_{k=1}^{K} \|G_k\|_2^2 } }
$$

즉 각 Parameter Tensor의 Norm을 계산한 후 이를 결합하여 전체 Norm을 계산한다.

PyTorch에서는 다음과 같이 사용할 수 있다.

```python
total_norm = torch.nn.utils.clip_grad_norm_(
    model.parameters(),
    max_norm=1.0,
    norm_type=2.0
)
```

여기서

```python
norm_type=2.0
```

은 L2 Norm을 사용한다는 의미이다.

## 10. Training Loop에 Gradient Clipping 적용

이제 실제 Training Loop에 Gradient Clipping을 적용해 보자.

먼저 간단한 ANN을 정의한다.

```python
import torch
import torch.nn as nn


class SimpleANN(nn.Module):

    def __init__(self):

        super().__init__()

        self.net = nn.Sequential(
            nn.Linear(4, 32),
            nn.ReLU(),

            nn.Linear(32, 32),
            nn.ReLU(),

            nn.Linear(32, 3)
        )

    def forward(self, x):

        return self.net(x)
```

모델과 Optimizer를 생성한다.

```python
model = SimpleANN()

criterion = nn.CrossEntropyLoss()

optimizer = torch.optim.Adam(
    model.parameters(),
    lr=0.001
)
```

Training Loop는 다음과 같이 작성할 수 있다.

```python
model.train()

for X, y in train_loader:

    # 1. Gradient 초기화
    optimizer.zero_grad()

    # 2. Forward Propagation
    logits = model(X)

    # 3. Loss Calculation
    loss = criterion(
        logits,
        y
    )

    # 4. Backward Propagation
    loss.backward()

    # 5. Gradient Clipping
    torch.nn.utils.clip_grad_norm_(
        model.parameters(),
        max_norm=1.0
    )

    # 6. Parameter Update
    optimizer.step()
```

여기서 중요한 부분은 다음 순서이다.

```python
loss.backward()

torch.nn.utils.clip_grad_norm_(
    model.parameters(),
    max_norm=1.0
)

optimizer.step()
```

즉 Gradient Clipping은 **Backward Propagation 이후, Parameter Update 이전에 수행한다.**

## 11. Gradient Norm 모니터링

Gradient Clipping이 필요한지 판단하려면 실제 Gradient Norm을 확인하는 것이 도움이 된다.

예를 들어 다음과 같이 작성할 수 있다.

```python
optimizer.zero_grad()

logits = model(X)

loss = criterion(
    logits,
    y
)

loss.backward()

# Clipping 전 Gradient Norm
original_norm = torch.nn.utils.clip_grad_norm_(
    model.parameters(),
    max_norm=1.0
)

print(
    "Original Gradient Norm:",
    original_norm.item()
)

optimizer.step()
```

이 코드는 Clipping을 수행하면서 동시에 Clipping 이전의 Gradient Norm을 확인한다.

예를 들어 다음과 같은 값이 나왔다고 하자.

```text
Original Gradient Norm: 5.7
```

이는 계산된 Gradient의 원래 Norm이 5.7이었다는 의미이다.

`max_norm=1.0`으로 설정했으므로 Clipping 이후 Gradient의 Norm은 약 1.0 이하로 제한된다.

다만 이 출력값은 설명을 위한 예시이며 실제 실행 결과는 모델과 데이터에 따라 달라진다.

## 12. Gradient Clipping Threshold 설정

Gradient Clipping에서는 Threshold가 중요한 Hyperparameter이다.

예를 들어 다음과 같이 설정할 수 있다.

```python
max_norm = 1.0
```

Threshold가 지나치게 크면 Clipping이 거의 발생하지 않을 수 있다.

반면 Threshold가 지나치게 작으면 대부분의 Gradient가 강하게 축소될 수 있다.

이 경우 학습 속도나 최적화 방향에 영향을 줄 수 있다.

따라서 적절한 Threshold는 다음 요소들을 고려하여 결정해야 한다.

- Model Architecture
- Dataset
- Optimizer
- Learning Rate
- Gradient Norm의 분포

실제로는 Gradient Norm을 기록한 뒤, 비정상적으로 큰 Gradient가 발생할 때만 적절하게 제한하는 방향으로 설정할 수 있다.

## 13. Gradient Clipping은 Vanishing Gradient도 해결할까?

Gradient Clipping은 기본적으로 지나치게 큰 Gradient를 제한하는 기법이다.

따라서 주로 Exploding Gradient를 완화하기 위해 사용한다.

반면 Vanishing Gradient는 Gradient가 지나치게 작아지는 문제이다.

Gradient Clipping은 작은 Gradient를 크게 만드는 방법이 아니다.

따라서

$$
\boxed{ \text{Gradient Clipping} \not\Rightarrow \text{Vanishing Gradient 해결} }
$$

이다.

Vanishing Gradient를 완화하려면 Activation Function, Weight Initialization, Network Architecture 등을 함께 고려해야 한다.

## 14. Gradient Clipping과 Learning Rate

Gradient Clipping과 Learning Rate는 서로 다른 역할을 한다.

Learning Rate는 Gradient를 이용하여 Parameter를 갱신할 때 적용하는 Scale이다.

$$
\boxed{ \theta_{t+1} = \theta_t - \eta\mathbf{g} }
$$

반면 Gradient Clipping은 Optimizer가 사용하기 전에 Gradient의 크기를 제한한다.

$$
\boxed{ \mathbf{g}_{clip} = \mathbf{g} \min\left( 1, \frac{c}{\|\mathbf{g}\|} \right) }
$$

일반적인 SGD에서는 다음과 같이 표현할 수 있다.

$$
\boxed{ \theta_{t+1} = \theta_t - \eta\mathbf{g}_{clip} }
$$

따라서 Gradient Clipping은 Learning Rate를 직접 변경하는 방법이 아니다.

또한 Adam과 같은 Adaptive Optimizer에서는 Gradient Clipping 이후 실제 Parameter Update의 크기가 Gradient Norm에 단순 비례하지 않을 수 있다.

즉 **Gradient Norm을 제한한다고 해서 모든 Optimizer에서 Parameter Update의 크기가 같은 값 이하로 제한된다는 의미는 아니다.**

---

## 15. Gradient Clipping과 Weight Initialization 비교

Weight Initialization과 Gradient Clipping은 모두 신경망 학습을 안정화하는 데 사용된다.

하지만 적용 시점과 목적이 다르다.

| 구분 | Weight Initialization | Gradient Clipping |
| --- | --- | --- |
| 적용 시점 | 학습 시작 전 | Backward 이후 |
| 적용 대상 | 초기 Weight | 계산된 Gradient |
| 주요 목적 | 신호 및 Gradient Scale 안정화 | 과도하게 큰 Gradient 제한 |
| 대표 방법 | Xavier, He, LeCun | Value, Norm |
| PyTorch | `torch.nn.init` | `torch.nn.utils` |

전체 Training Process에서 두 기법의 위치는 다음과 같다.

```text
Model Creation
      │
      ▼
Weight Initialization
      │
      ▼
Forward Propagation
      │
      ▼
Loss Calculation
      │
      ▼
Backward Propagation
      │
      ▼
Gradient Calculation
      │
      ▼
Gradient Clipping
      │
      ▼
Optimizer Step
      │
      ▼
Parameter Update
```

따라서 두 방법은 서로 대체되는 것이 아니라 함께 사용할 수 있다.

---

## 16. Gradient Clipping 사용 시 주의사항

### 16.1 Clipping은 Gradient를 직접 수정한다

PyTorch의 `clip_grad_norm_()`와 `clip_grad_value_()`는 Parameter의 `.grad`를 In-place로 수정한다.

따라서 Gradient Clipping 이후의 값이 Optimizer에 전달된다.

---

### 16.2 Optimizer Step 이전에 호출해야 한다

다음 순서가 일반적이다.

```python
optimizer.zero_grad()

loss.backward()

torch.nn.utils.clip_grad_norm_(
    model.parameters(),
    max_norm=1.0
)

optimizer.step()
```

Clipping을 `optimizer.step()` 이후에 수행하면 이미 해당 Step의 Parameter Update가 완료되었으므로 의도한 효과를 얻을 수 없다.

---

### 16.3 Gradient Accumulation을 사용하는 경우

Gradient Accumulation은 여러 Mini-batch에서 Gradient를 누적한 뒤 한 번의 Parameter Update를 수행하는 방법이다.

이 경우 일반적으로 누적된 Gradient에 대해 Clipping을 수행한다.

```text
Mini-batch 1
    │
    ▼
Backward
    │
    ▼
Mini-batch 2
    │
    ▼
Backward
    │
    ▼
Accumulated Gradient
    │
    ▼
Gradient Clipping
    │
    ▼
Optimizer Step
```

각 Mini-batch마다 Clipping한 Gradient를 누적하는 것과, 누적된 Gradient를 마지막에 Clipping하는 것은 일반적으로 같은 연산이 아니다.

따라서 Gradient Accumulation을 사용하는 경우 Clipping 시점을 주의해야 한다.

---

### 16.4 Mixed Precision Training의 경우

Automatic Mixed Precision(AMP)과 Gradient Scaling을 사용하는 경우에는 Clipping 전에 Gradient를 Unscale해야 한다.

대표적인 순서는 다음과 같다.

```python
scaler.scale(loss).backward()

scaler.unscale_(optimizer)

torch.nn.utils.clip_grad_norm_(
    model.parameters(),
    max_norm=1.0
)

scaler.step(optimizer)

scaler.update()
```

여기서는 AMP용 `scaler`가 이미 생성되어 있다고 가정한다.

Scaling된 Gradient를 그대로 Clipping하면 의도한 Threshold와 다른 기준으로 처리될 수 있다.

따라서 Gradient Scaling을 사용하는 경우에는 `unscale_()` 이후 Clipping을 수행해야 한다.

## 17. 핵심 공식 총정리

#### Gradient Descent

$$
\boxed{ \theta_{t+1} = \theta_t - \eta\nabla_\theta L }
$$

#### Gradient L2 Norm

$$
\boxed{ \|\mathbf{g}\|_2 = \sqrt{ \sum_{i=1}^{n}g_i^2 } }
$$

#### Value Clipping

$$
\boxed{ g_i^{clip} = \operatorname{clip}(g_i,-c,c) }
$$

#### Norm Clipping

$$
\boxed{ \mathbf{g}_{clip} = \mathbf{g} \min \left( 1, \frac{c}{\|\mathbf{g}\|_2} \right) }
$$

#### Gradient Clipping 적용 후 SGD

$$
\boxed{ \theta_{t+1} = \theta_t - \eta\mathbf{g}_{clip} }
$$

## 18. 최종 정리

Gradient Clipping은 Backpropagation으로 계산된 Gradient가 지나치게 커졌을 때 이를 제한하는 방법이다.

Deep Neural Network에서는 여러 Layer를 통과하면서 Gradient가 급격하게 증가하는 Exploding Gradient Problem이 발생할 수 있다.

이러한 문제는 Training Loss의 불안정이나 Parameter Update의 급격한 변화로 이어질 수 있다.

Gradient Clipping은 이러한 문제를 완화하기 위해 사용된다.

대표적인 방법은 두 가지이다.

**Gradient Clipping by Value**

각 Gradient 원소를 미리 설정한 범위 안으로 제한한다.

```python
torch.nn.utils.clip_grad_value_(
    model.parameters(),
    clip_value=1.0
)
```

**Gradient Clipping by Norm**

Gradient Vector 전체의 Norm을 제한한다.

```python
torch.nn.utils.clip_grad_norm_(
    model.parameters(),
    max_norm=1.0
)
```

Norm Clipping은 Gradient의 전체 방향을 유지하면서 크기를 제한하는 방식이므로 실제 딥러닝에서 널리 사용된다.

또한 Gradient Clipping은 일반적으로 다음 순서로 적용한다.

```python
loss.backward()

torch.nn.utils.clip_grad_norm_(
    model.parameters(),
    max_norm=1.0
)

optimizer.step()
```

중요한 점은 Gradient Clipping이 모든 Gradient 문제를 해결하는 방법은 아니라는 것이다.

특히 Gradient Clipping은 작은 Gradient를 크게 만드는 방법이 아니므로 Vanishing Gradient를 직접 해결하지는 못한다.

따라서 Weight Initialization, Activation Function, Network Architecture 등을 함께 고려해야 한다.

---

### 핵심 요약

> Gradient Clipping은 역전파로 계산된 Gradient의 크기를 제한하여 Exploding Gradient 문제를 완화하는 방법이다. Value Clipping은 각 Gradient 원소를 제한하며, Norm Clipping은 Gradient Vector 전체의 Norm을 제한한다. PyTorch에서는 `clip_grad_norm_()`와 `clip_grad_value_()`를 제공하며, 일반적으로 `loss.backward()` 이후 `optimizer.step()` 이전에 적용한다.
