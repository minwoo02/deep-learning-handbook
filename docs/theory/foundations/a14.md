Categorical Distribution(범주형 분포)은 여러 개의 범주(Category) 중 하나가 선택되는 확률실험을 표현하는 이산확률분포이다.

Bernoulli Distribution이 두 가지 결과 중 하나를 모델링한다면, Categorical Distribution은 이를 $K$개의 결과로 확장한 형태이다.

대표적인 예시는 다음과 같다.

- 주사위 던지기: 6가지 결과
- 붓꽃 분류: 3가지 품종
- 이미지 분류: 여러 객체의 Class
- 자연어 처리: Vocabulary 중 하나의 Token 선택

특히 Categorical Distribution은 Multiclass Classification과 Cross-Entropy Loss를 이해하기 위한 중요한 수학적 기반이다.

이 글에서는 Categorical Random Variable과 One-Hot Encoding을 살펴보고, Probability Mass Function(PMF), Expected Value, Variance를 유도한다.

이후 Multinomial Distribution과의 관계, SciPy를 이용한 Simulation, PyTorch의 Cross-Entropy Loss까지 정리한다.

---

# 1. Categorical Random Variable

Categorical Random Variable은 $K$개의 Class 중 하나의 값을 가지는 이산확률변수이다.

예를 들어 주사위를 한 번 던지는 실험을 생각하자.

가능한 값은 다음과 같다.

$$
\boxed{ X\in\{1,2,3,4,5,6\} }
$$

따라서

$$
\boxed{ K=6 }
$$

이다.

각 값은 하나의 Category에 대응한다.

이러한 확률변수를 Categorical Random Variable이라고 한다.

---

# 2. Bernoulli Distribution과의 관계

Bernoulli Distribution은 결과가 두 가지인 확률분포이다.

$$
X\in\{0,1\}
$$

반면 Categorical Distribution은 $K$개의 결과를 가진다.

$$
X\in\{1,2,\cdots,K\}
$$

따라서 $K=2$라면 Categorical Distribution은 Bernoulli Distribution과 동등한 형태로 표현할 수 있다.

즉

$$
\boxed{ \text{Bernoulli} \subset \text{Categorical} }
$$

이라는 관계로 이해할 수 있다.

정확히는 Bernoulli Distribution을 두 개의 범주를 갖는 Categorical Distribution으로 나타낼 수 있다는 의미이다.

---

# 3. One-Hot Encoding

Categorical Random Variable은 하나의 정수로 표현할 수 있지만, One-Hot Encoding을 이용하여 Vector로 표현할 수도 있다.

One-Hot Encoding은 $K$개의 원소 중 하나만 1이고 나머지는 모두 0인 Vector로 표현하는 방법이다.

주사위를 한 번 던지는 경우를 생각해 보자.

주사위의 눈이 1이면 다음과 같이 표현한다.

$$
\boxed{ \mathbf{x} = (1,0,0,0,0,0) }
$$

주사위의 눈이 2이면 다음과 같다.

$$
\boxed{ \mathbf{x} = (0,1,0,0,0,0) }
$$

주사위의 눈이 3이면

$$
\boxed{ \mathbf{x} = (0,0,1,0,0,0) }
$$

이다.

모든 결과는 다음과 같이 표현할 수 있다.

| 주사위 눈 | One-Hot Vector |
| --- | --- |
| 1 | $(1,0,0,0,0,0)$ |
| 2 | $(0,1,0,0,0,0)$ |
| 3 | $(0,0,1,0,0,0)$ |
| 4 | $(0,0,0,1,0,0)$ |
| 5 | $(0,0,0,0,1,0)$ |
| 6 | $(0,0,0,0,0,1)$ |

---

## 3.1 One-Hot Vector의 조건

$K$개의 Class에 대해 One-Hot Vector를 다음과 같이 정의하자.

$$
\boxed{ \mathbf{x} = (x_1,x_2,\cdots,x_K) }
$$

각 원소는 다음 값을 가진다.

$$
\boxed{ x_i\in\{0,1\} }
$$

또한 하나의 Class만 선택되므로

$$
\boxed{ \sum_{i=1}^{K}x_i=1 }
$$

이다.

즉 One-Hot Vector의 핵심은 다음과 같다.

```text
K개의 원소
     │
     ▼
하나의 원소만 1
     │
     ▼
나머지는 모두 0
```

---

# 4. Categorical Distribution의 Parameters

Categorical Distribution은 각 Class에 대한 확률을 Parameter로 가진다.

이를 다음과 같이 정의하자.

$$
\boxed{ \boldsymbol{\mu} = (\mu_1,\mu_2,\cdots,\mu_K) }
$$

여기서 $\mu_i$는 $i$번째 Class가 선택될 확률이다.

$$
\boxed{ \mu_i=P(X=i) }
$$

각 확률은 다음 조건을 만족한다.

$$
\boxed{ 0\le\mu_i\le1 }
$$

또한 전체 확률의 합은 1이다.

$$
\boxed{ \sum_{i=1}^{K}\mu_i=1 }
$$

예를 들어 주사위의 각 눈이 나타날 확률을 다음과 같이 설정할 수 있다.

$$
\boxed{ \boldsymbol{\mu} = (0.1,0.2,0.2,0.2,0.2,0.1) }
$$

이는 다음과 같은 의미이다.

| Class | Probability |
| --- | --- |
| 1 | 0.1 |
| 2 | 0.2 |
| 3 | 0.2 |
| 4 | 0.2 |
| 5 | 0.2 |
| 6 | 0.1 |

전체 확률은 다음과 같다.

$$
0.1+0.2+0.2+0.2+0.2+0.1=1
$$

따라서 유효한 Categorical Probability Vector이다.

---

# 5. Categorical Distribution의 PMF

Categorical Distribution의 PMF는 특정 Class가 선택될 확률을 나타낸다.

정수 형태의 확률변수라면 다음과 같이 표현할 수 있다.

$$
\boxed{ P(X=i)=\mu_i }
$$

One-Hot Vector를 사용하면 모든 Class의 확률을 하나의 수식으로 표현할 수 있다.

$$
\boxed{ P(\mathbf{X}=\mathbf{x}) = \prod_{i=1}^{K}\mu_i^{x_i} }
$$

여기서

- $\mathbf{x}$: One-Hot Vector
- $\mu_i$: $i$번째 Class의 확률
- $x_i$: $i$번째 Class 선택 여부

이다.

---

## 5.1 PMF 유도

세 개의 Class가 있다고 하자.

$$
K=3
$$

확률벡터는 다음과 같다.

$$
\boldsymbol{\mu} = (0.2,0.5,0.3)
$$

두 번째 Class가 선택되었다면 One-Hot Vector는 다음과 같다.

$$
\mathbf{x} = (0,1,0)
$$

이다.

PMF에 대입하면

$$
P(\mathbf{x}) = \mu_1^{x_1} \mu_2^{x_2} \mu_3^{x_3}
$$

이므로

$$
P(\mathbf{x}) = 0.2^0 \times 0.5^1 \times 0.3^0
$$

이다.

따라서

$$
\boxed{ P(\mathbf{x})=0.5 }
$$

이다.

즉 One-Hot Vector에서 1에 해당하는 Class의 확률만 남는다.

---

# 6. One-Hot Vector의 Expected Value

Categorical Distribution을 One-Hot Vector로 표현하면 각 성분 $X_i$는 0 또는 1을 갖는 Indicator Random Variable이다.

즉

$$
\boxed{ X_i= \begin{cases} 1,&\text{Class }i\text{가 선택됨}\\ 0,&\text{그 외} \end{cases} }
$$

이다.

따라서 각 성분의 기댓값은 다음과 같다.

$$
E[X_i] = 0\cdot(1-\mu_i) + 1\cdot\mu_i
$$

그러므로

$$
\boxed{ E[X_i]=\mu_i }
$$

이다.

전체 Vector의 기댓값은 다음과 같다.

$$
\boxed{ E[\mathbf{X}] = \boldsymbol{\mu} }
$$

즉 One-Hot Random Vector의 Expected Value는 Categorical Probability Vector와 같다.

---

# 7. One-Hot Vector의 Variance

각 성분 $X_i$는 Bernoulli Random Variable로 해석할 수 있다.

따라서

$$
\boxed{ \operatorname{Var}(X_i) = \mu_i(1-\mu_i) }
$$

이다.

여기서 주의할 점은 원문 수식의 왼쪽이 `Var[μ_i]`로 표기되어 있지만, 분산을 계산하는 대상은 확률 Parameter $\mu_i$가 아니라 **Random Variable $X_i$** 라는 것이다.

따라서 수학적으로는

$$
\operatorname{Var}(X_i)
$$

로 표현하는 것이 정확하다.

---

## 7.1 One-Hot Vector의 성분들은 독립일까?

각 성분 $X_i$는 Bernoulli Distribution을 따르지만 서로 독립은 아니다.

왜냐하면 하나의 Class만 선택될 수 있기 때문이다.

예를 들어

$$
X_1=1
$$

이면 나머지 성분은 반드시 0이어야 한다.

$$
X_2=X_3=\cdots=X_K=0
$$

이다.

따라서 One-Hot Vector의 성분들은 서로 의존적이다.

서로 다른 두 성분 $X_i$, $X_j$에 대해

$$
i\neq j
$$

이면

$$
X_iX_j=0
$$

이다.

따라서

$$
E[X_iX_j]=0
$$

이다.

Covariance는 다음과 같다.

$$
\operatorname{Cov}(X_i,X_j) = E[X_iX_j]-E[X_i]E[X_j]
$$

이므로

$$
\boxed{ \operatorname{Cov}(X_i,X_j) = -\mu_i\mu_j \quad(i\neq j) }
$$

이다.

즉 서로 다른 One-Hot 성분의 Covariance는 일반적으로 음수이다.

---

# 8. Covariance Matrix

Categorical One-Hot Random Vector의 Covariance Matrix는 다음과 같이 표현할 수 있다.

$$
\boxed{ \operatorname{Cov}(\mathbf{X}) = \operatorname{diag}(\boldsymbol{\mu}) - \boldsymbol{\mu}\boldsymbol{\mu}^{T} }
$$

여기서

$$
\operatorname{diag}(\boldsymbol{\mu})
$$

는 확률벡터의 각 성분을 대각 원소로 갖는 행렬이다.

이 식은 Categorical Distribution에서 각 Class의 Indicator Variable들이 어떻게 서로 관련되어 있는지 보여준다.

---

# 9. Categorical과 Multinomial Distribution

Categorical Distribution은 한 번의 시행에서 하나의 Class를 선택하는 분포이다.

반면 Multinomial Distribution은 $K$개의 Class를 갖는 독립적인 Categorical Trial을 여러 번 수행했을 때 각 Class가 선택된 횟수를 나타내는 분포이다.

예를 들어 주사위를 한 번 던지는 경우에는 Categorical Distribution을 사용할 수 있다.

하지만 주사위를 100번 던져 각 눈이 몇 번 나왔는지를 모델링하려면 Multinomial Distribution을 사용할 수 있다.

Multinomial Distribution의 PMF는 다음과 같다.

$$
\boxed{ P(\mathbf{n}) = \frac{N!}{n_1!n_2!\cdots n_K!} \prod_{i=1}^{K}\mu_i^{n_i} }
$$

여기서

$$
\sum_{i=1}^{K}n_i=N
$$

이다.

특히 시행 횟수가 1이면 다음과 같다.

$$
\boxed{ N=1 \Rightarrow \text{Categorical Distribution} }
$$

즉 Categorical Distribution은 시행 횟수가 1인 Multinomial Distribution과 동일한 구조로 볼 수 있다.

---

# 10. SciPy로 Categorical PMF 구현

> 원문의 `scipy.stats.multinomial` 예제를 기반으로 정리한 코드이다.

SciPy에서는 `scipy.stats.multinomial`을 제공한다.

시행 횟수를 1로 설정하면 Categorical Distribution을 표현할 수 있다.

```python
import numpy as np

from scipy.stats import multinomial


mu = np.array([
    0.1,
    0.2,
    0.2,
    0.2,
    0.2,
    0.1
])

# One Categorical Trial
rv = multinomial(
    n=1,
    p=mu
)

# 6개의 One-Hot Vector
one_hot_vectors = np.eye(
    6,
    dtype=int
)

probabilities = rv.pmf(
    one_hot_vectors
)

print(probabilities)
```

출력은 다음과 같다.

```text
[0.1 0.2 0.2 0.2 0.2 0.1]
```

각 One-Hot Vector에 해당하는 Class Probability를 계산한다.

---

# 11. Categorical Sampling

이번에는 실제 Categorical Sample을 생성해 보자.

```python
samples = rv.rvs(
    size=1000,
    random_state=42
)

print(samples.shape)
```

출력:

```text
(1000, 6)
```

각 Sample은 6개의 원소를 가지는 One-Hot Vector이다.

이제 각 Class가 나타난 비율을 계산한다.

```python
measured = samples.mean(
    axis=0
)

print(measured)
```

Sample을 충분히 많이 생성하면 다음 이론적 확률에 가까워질 수 있다.

$$
\boldsymbol{\mu} = (0.1,0.2,0.2,0.2,0.2,0.1)
$$

---

# 12. Ideal Probability와 Simulation 비교

이론적인 확률과 실제 Sampling으로 계산한 비율을 시각화할 수 있다.

```python
import matplotlib.pyplot as plt

classes = np.arange(1, 7)

width = 0.35

plt.figure(figsize=(8, 5))

plt.bar(
    classes - width / 2,
    mu,
    width=width,
    label="Ideal"
)

plt.bar(
    classes + width / 2,
    measured,
    width=width,
    label="Measured"
)

plt.xlabel("Class")
plt.ylabel("Probability")

plt.title(
    "Categorical Distribution"
)

plt.xticks(classes)

plt.legend()
plt.grid(alpha=0.3)

plt.show()
```

Sampling으로 얻은 비율은 이론적인 확률과 완전히 일치하지 않을 수 있다.

하지만 시행 횟수가 충분히 커지면 각 Class의 관측 비율은 이론적인 확률에 가까워지는 경향을 가진다.

# 13. Categorical Distribution과 Multiclass Classification

Categorical Distribution은 딥러닝의 Multiclass Classification에서 중요한 역할을 한다.

예를 들어 Iris Dataset은 세 개의 Class를 가진다.

```text
Setosa
Versicolor
Virginica
```

모델이 예측하는 확률벡터를 다음과 같이 정의하자.

$$
\boxed{ \mathbf{q}_\theta = (q_{\theta,1},q_{\theta,2},q_{\theta,3}) }
$$

이 값은 Categorical Distribution의 Parameter에 해당한다.

모든 확률의 합은 다음과 같다.

$$
\boxed{ \sum_{k=1}^{3}q_{\theta,k}=1 }
$$

일반적인 ANN에서는 Softmax Function을 이용하여 Logit을 Categorical Probability로 변환할 수 있다.

$$
\boxed{ q_{\theta,k} = \frac{e^{z_k}} {\sum_{j=1}^{K}e^{z_j}} }
$$

여기서 $z_k$는 모델이 출력한 $k$번째 Class의 Logit이다.

---

# 14. Categorical Distribution과 Cross-Entropy

정답 Class가 $c$라고 하자.

Categorical Distribution에서 해당 Class의 확률은 다음과 같다.

$$
P_\theta(Y=c\mid x)=q_{\theta,c}
$$

Negative Log-Likelihood를 적용하면

$$
\ell_{NLL} = -\log q_{\theta,c}
$$

이다.

One-Hot Target을 사용하면 다음과 같이 표현할 수 있다.

$$
\boxed{ \ell_{CE} = -\sum_{k=1}^{K} y_k\log q_{\theta,k} }
$$

여기서 $y_k$는 정답 Class만 1인 One-Hot Vector의 성분이다.

이 식이 Categorical Cross-Entropy이다.

즉

$$
\boxed{ \text{Categorical NLL} = \text{Cross-Entropy} }
$$

이다.

---

# 15. PyTorch에서 CrossEntropyLoss

PyTorch에서는 다음과 같이 사용할 수 있다.

```python
import torch
import torch.nn as nn

logits = torch.tensor([
    [2.0, 0.5, -1.0],
    [0.1, 0.2, 1.3]
])

targets = torch.tensor(
    [0, 2],
    dtype=torch.long
)

criterion = nn.CrossEntropyLoss()

loss = criterion(
    logits,
    targets
)

print(loss.item())
```

여기서 Tensor Shape는 다음과 같다.

```text
Logits:  [2, 3]
Targets: [2]
```

모델은 두 개의 Sample에 대해 각각 세 개의 Logit을 출력한다.

Target은 각 Sample의 Class Index이다.

`nn.CrossEntropyLoss`는 내부적으로 Log-Softmax와 NLL에 해당하는 계산을 수행한다.

따라서 Raw Logit을 직접 전달한다.

# 16. 최종 정리

Categorical Distribution은 $K$개의 Class 중 하나가 선택되는 확률분포이다.

각 Class의 확률은 Probability Vector로 표현할 수 있다.

$$
\boxed{ \boldsymbol{\mu} = (\mu_1,\mu_2,\cdots,\mu_K) }
$$

각 확률은 0 이상이고 전체 합은 1이다.

One-Hot Encoding을 사용하면 Categorical PMF를 다음과 같이 표현할 수 있다.

$$
\boxed{ P(\mathbf{X}=\mathbf{x}) = \prod_{i=1}^{K}\mu_i^{x_i} }
$$

또한 각 One-Hot 성분은 Bernoulli Random Variable로 볼 수 있으므로 기댓값과 분산은 다음과 같다.

$$
\boxed{ E[X_i]=\mu_i }
$$

$$
\boxed{ \operatorname{Var}(X_i) = \mu_i(1-\mu_i) }
$$

Categorical Trial을 여러 번 독립적으로 반복하고 Class별 발생 횟수를 계산하면 Multinomial Distribution과 연결된다.

딥러닝에서는 Categorical Distribution이 Multiclass Classification의 확률모델로 사용된다.

이때 Negative Log-Likelihood는 Cross-Entropy Loss와 연결된다.

---

## 핵심 요약

> Categorical Distribution은 $K$개의 Class 중 하나를 선택하는 이산확률분포이다. One-Hot Vector와 Probability Vector를 이용해 표현할 수 있으며, PMF는 $\prod_i\mu_i^{x_i}$이다. Multiclass Classification에서 Categorical Likelihood의 NLL을 최소화하는 것은 Cross-Entropy Loss를 최소화하는 것과 연결된다.
