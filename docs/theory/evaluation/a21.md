Machine Learning과 Deep Learning에서는 모델의 Prediction Performance를 정량적으로 평가하기 위해 다양한 Evaluation Metric을 사용한다.

Classification에서는 Accuracy, Precision, Recall, F1-score 등을 활용한다.

반면 Regression(회귀)은 연속적인 수치 값을 예측하는 문제이므로, **실제값과 예측값이 얼마나 차이 나는지**를 중심으로 모델의 성능을 평가한다.

예를 들어 주택 가격을 예측하는 Regression Model이 있다고 하자.

```text
Actual Price    : 500,000,000원
Predicted Price : 480,000,000원
```

이 모델의 Prediction Error는 2,000만 원이다.

하지만 하나의 Sample에 대한 Error만으로 모델 전체의 성능을 평가하기는 어렵다.

따라서 전체 Dataset에서 발생한 Error를 종합하는 지표가 필요하다.

대표적인 Regression Evaluation Metric에는 다음과 같은 것들이 있다.

- MAE(Mean Absolute Error)
- MSE(Mean Squared Error)
- RMSE(Root Mean Squared Error)
- SSE(Sum of Squared Errors)
- MAPE(Mean Absolute Percentage Error)
- RMSPE(Root Mean Squared Percentage Error)
- R²(Coefficient of Determination)

각 지표는 동일한 Prediction Result를 평가하더라도 서로 다른 관점에서 성능을 나타낸다.

이번 글에서는 Metric의 수학적 의미부터 Residual 기반 지표, Percentage 기반 지표, 결정계수 R²까지 살펴본다.

# Part 1. Regression Evaluation의 기초 개념

## 1. Regression이란?

Regression은 Input Feature를 이용하여 연속적인 Target Value를 예측하는 Supervised Learning Task이다.

일반적으로 다음과 같이 표현한다.

$$
\boxed{ \hat y=f_\theta(\mathbf{x}) }
$$

여기서

- $\mathbf{x}$: Input Feature Vector
- $f_\theta$: Model
- $\theta$: Model Parameter
- $\hat y$: Predicted Value

이다.

Regression Model의 대표적인 활용 사례는 다음과 같다.

| Task | Input | Target |
| --- | --- | --- |
| House Price Prediction | 면적, 위치, 건축 연도 | 주택 가격 |
| Temperature Prediction | 기상 관측값 | 온도 |
| Blood Pressure Estimation | 생체신호 Feature | 혈압 |
| Energy Consumption Prediction | 시간, 온도, 사용량 | 전력 소비량 |

Regression에서는 예측값이 실제값과 얼마나 가까운지 평가해야 한다.

이를 위해 Prediction Error 또는 Residual을 계산한다.

---

## 2. Metric, Distance, Similarity

Regression Evaluation을 이해하기 전에 Metric, Distance, Similarity의 차이를 구분할 필요가 있다.

### 2.1 Metric

Machine Learning에서 Metric은 모델의 성능을 정량적으로 평가하는 지표를 의미한다.

예를 들어 다음과 같다.

- Classification Accuracy
- Mean Absolute Error
- Root Mean Squared Error
- R² Score

그러나 수학에서 Metric은 보다 엄밀한 의미를 가진다.

수학적 Metric은 두 점 사이의 Distance를 정의하는 함수 $d(x,y)$이며, 다음 네 가지 조건을 만족해야 한다.

**① Non-negativity**

$$
\boxed{ d(x,y)\geq0 }
$$

**② Identity of Indiscernibles**

$$
\boxed{ d(x,y)=0\iff x=y }
$$

**③ Symmetry**

$$
\boxed{ d(x,y)=d(y,x) }
$$

**④ Triangle Inequality**

$$
\boxed{ d(x,y)\leq d(x,z)+d(z,y) }
$$

따라서 Machine Learning에서 Metric이라고 부르는 모든 지표가 수학적인 의미의 Distance Metric인 것은 아니다.

예를 들어 R²는 Regression Performance Metric이지만 수학적인 Distance Metric은 아니다.

---

### 2.2 Distance

Distance는 두 대상이 서로 얼마나 떨어져 있는지를 나타낸다.

Vector 사이의 Distance는 일반적으로 Norm을 이용하여 계산할 수 있다.

예를 들어 두 Vector $\mathbf{a}$, $\mathbf{b}$ 사이의 Euclidean Distance는 다음과 같다.

$$
\boxed{ d(\mathbf{a},\mathbf{b}) = \|\mathbf{a}-\mathbf{b}\|_2 }
$$

이를 전개하면

$$
\boxed{ d(\mathbf{a},\mathbf{b}) = \sqrt{ \sum_{i=1}^{n}(a_i-b_i)^2 } }
$$

이다.

Regression에서는 실제값과 예측값의 차이를 기반으로 MAE나 RMSE를 계산한다.

---

### 2.3 Similarity

Similarity는 두 대상이 얼마나 유사한지 나타내는 개념이다.

일반적으로 Distance가 작을수록 서로 가까운 대상이고, Similarity가 클수록 서로 유사한 대상이다.

대표적인 Similarity Measure는 Cosine Similarity이다.

$$
\boxed{ \operatorname{CosSim}(\mathbf{a},\mathbf{b}) = \frac{ \mathbf{a}^{T}\mathbf{b} }{ \|\mathbf{a}\|_2\|\mathbf{b}\|_2 } }
$$

Cosine Similarity는 두 Vector의 크기보다 방향의 유사성을 평가한다.

다만 모든 Similarity가 적절한 Distance Metric으로 변환되는 것은 아니다.

---

## 3. Residual(잔차)이란?

Regression에서는 실제값과 예측값의 차이를 Residual이라고 한다.

전체 Dataset에 $m$개의 Sample이 있다고 하자.

각 Sample의 실제값을 $y_i$, 예측값을 $\hat y_i$라고 하면 Residual은 다음과 같다.

$$
\boxed{ r_i=y_i-\hat y_i }
$$

여기서

- $m$: Sample 수
- $y_i$: i번째 Sample의 실제값
- $\hat y_i$: i번째 Sample의 예측값
- $r_i$: Residual

이다.

예를 들어 다음과 같은 데이터가 있다고 하자.

| Sample | 실제값 $y_i$ | 예측값 $\hat y_i$ | Residual $r_i$ |
| --- | --- | --- | --- |
| 1 | 2 | 2 | 0 |
| 2 | 4 | 5 | -1 |
| 3 | 6 | 4 | 2 |
| 4 | 8 | 9 | -1 |

Residual은 다음과 같다.

$$
\boxed{ \mathbf r=[0,-1,2,-1] }
$$

Residual이 양수이면 예측값이 실제값보다 작다는 의미이다.

반대로 Residual이 음수이면 예측값이 실제값보다 크다는 의미이다.

단순히 Residual을 모두 더하면 양수와 음수가 상쇄될 수 있다.

따라서 Regression Evaluation에서는 일반적으로 Residual의 절댓값이나 제곱값을 사용한다.

---

# Part 2. Residual-based Metrics

Residual-based Metrics는 실제값과 예측값의 차이를 절댓값 또는 제곱으로 변환하여 요약한 지표이다.

대표적인 방법은 다음과 같다.

- MAE
- MSE
- RMSE
- SSE

이 지표들은 Target의 단위와 Scale에 영향을 받는다.

---

## 4. Mean Absolute Error (MAE)

MAE는 Mean Absolute Error의 약자이며, **Residual의 절댓값을 평균한 지표**이다.

$$
\boxed{ \mathrm{MAE} = \frac1m \sum_{i=1}^{m}|y_i-\hat y_i| }
$$

Residual을 사용하면 다음과 같다.

$$
\boxed{ \mathrm{MAE} = \frac1m \sum_{i=1}^{m}|r_i| }
$$

각 Sample의 Absolute Error를 동일한 비중으로 평균한다.

---

### 4.1 MAE 계산 예제

앞의 데이터에서 Residual은 다음과 같다.

$$
\mathbf r=[0,-1,2,-1]
$$

Absolute Residual은 다음과 같다.

$$
|\mathbf r|=[0,1,2,1]
$$

따라서

$$
\mathrm{MAE} = \frac{0+1+2+1}{4}
$$

이다.

결과적으로

$$
\boxed{ \mathrm{MAE}=1 }
$$

이다.

이는 해당 Dataset에서 예측값과 실제값의 평균 절댓값 차이가 1이라는 의미이다.

---

### 4.2 MAE의 특징

- 값이 작을수록 예측 오차가 작다.
- 최솟값은 0이다.
- Target과 동일한 단위를 가진다.
- 각 Sample의 Absolute Error를 선형적으로 반영한다.
- MSE·RMSE보다 큰 Residual을 상대적으로 덜 강조한다.

예를 들어 Target이 혈압(mmHg)이라면 MAE도 mmHg 단위로 나타난다.

$$
\mathrm{MAE}=5\ \mathrm{mmHg}
$$

라면 평균적으로 5 mmHg의 Absolute Prediction Error가 발생했다는 의미이다.

다만 MAE가 작다고 모든 Sample에서 Error가 작은 것은 아니다.

일부 Sample에서 큰 Error가 발생하더라도 평균값만으로는 이를 충분히 파악하기 어려울 수 있다.

---

## 5. Mean Squared Error (MSE)

MSE는 Mean Squared Error의 약자이며, **Residual을 제곱한 뒤 평균한 지표**이다.

$$
\boxed{ \mathrm{MSE} = \frac1m \sum_{i=1}^{m}(y_i-\hat y_i)^2 }
$$

Residual을 이용하면 다음과 같다.

$$
\boxed{ \mathrm{MSE} = \frac1m \sum_{i=1}^{m}r_i^2 }
$$

MAE와 달리 Residual을 제곱한다.

따라서 큰 Residual에 상대적으로 더 큰 Penalty를 부여한다.

---

### 5.1 MSE 계산 예제

같은 Residual을 사용한다.

$$
\mathbf r=[0,-1,2,-1]
$$

Squared Residual은 다음과 같다.

$$
\mathbf r^2=[0,1,4,1]
$$

따라서

$$
\mathrm{MSE} = \frac{0+1+4+1}{4}
$$

이다.

결과적으로

$$
\boxed{ \mathrm{MSE}=1.5 }
$$

이다.

---

### 5.2 MSE의 특징

- 최솟값은 0이다.
- 값이 작을수록 예측 오차가 작다.
- 큰 Residual을 강하게 반영한다.
- Outlier의 영향을 MAE보다 크게 받는다.
- Target 단위의 제곱을 사용한다.

예를 들어 Target 단위가 mmHg라면 MSE의 단위는 다음과 같다.

$$
\boxed{ \mathrm{mmHg}^2 }
$$

따라서 MSE는 실제 Prediction Error를 원래 단위로 직관적으로 해석하기 어렵다는 단점이 있다.

반면 제곱 연산을 사용하기 때문에 수학적으로 다루기 편리하며, Regression Model의 Loss Function으로 널리 사용된다.

---

## 6. Root Mean Squared Error (RMSE)

RMSE는 Root Mean Squared Error의 약자이다.

MSE에 Square Root를 적용한 지표이다.

$$
\boxed{ \mathrm{RMSE} = \sqrt{ \frac1m \sum_{i=1}^{m}(y_i-\hat y_i)^2 } }
$$

또는

$$
\boxed{ \mathrm{RMSE}=\sqrt{\mathrm{MSE}} }
$$

이다.

MSE에 Square Root를 적용하기 때문에 결과를 원래 Target과 같은 단위로 해석할 수 있다.

---

### 6.1 RMSE 계산 예제

앞에서 계산한 MSE는 다음과 같다.

$$
\mathrm{MSE}=1.5
$$

따라서

$$
\mathrm{RMSE} = \sqrt{1.5}
$$

이다.

결과적으로

$$
\boxed{ \mathrm{RMSE}\approx1.225 }
$$

이다.

---

### 6.2 RMSE의 특징

- Target과 같은 단위를 가진다.
- 큰 Residual을 MAE보다 강하게 반영한다.
- Outlier에 상대적으로 민감하다.
- MSE보다 원래 단위에서 해석하기 쉽다.

예를 들어 혈압 예측에서

$$
\mathrm{RMSE}=8\ \mathrm{mmHg}
$$

라면 Root Mean Squared Error의 크기가 8 mmHg라는 의미이다.

이는 단순한 평균 Absolute Error와 동일한 개념은 아니다.

RMSE는 Residual을 제곱한 후 평균하고 다시 Square Root를 적용하기 때문이다.

---

## 7. MAE와 RMSE의 차이

MAE와 RMSE는 모두 실제값과 같은 단위를 사용한다.

그러나 큰 Error를 반영하는 정도가 다르다.

예를 들어 두 모델의 Residual이 다음과 같다고 하자.

```text
Model A: [2, 2, 2, 2]

Model B: [0, 0, 0, 8]
```

두 모델의 MAE를 계산하면 다음과 같다.

**Model A**

$$
\mathrm{MAE}_A = \frac{2+2+2+2}{4}=2
$$

**Model B**

$$
\mathrm{MAE}_B = \frac{0+0+0+8}{4}=2
$$

따라서

$$
\boxed{ \mathrm{MAE}_A=\mathrm{MAE}_B }
$$

이다.

하지만 RMSE는 다르다.

**Model A**

$$
\mathrm{RMSE}_A = \sqrt{\frac{4+4+4+4}{4}} =2
$$

**Model B**

$$
\mathrm{RMSE}_B = \sqrt{\frac{0+0+0+64}{4}} =4
$$

따라서

$$
\boxed{ \mathrm{RMSE}_B>\mathrm{RMSE}_A }
$$

이다.

두 모델의 평균 Absolute Error는 동일하지만, Model B는 하나의 Sample에서 매우 큰 Error가 발생했다.

RMSE는 이러한 큰 Error를 더 강하게 반영한다.

따라서 큰 Prediction Error가 중요한 문제에서는 RMSE를 함께 확인하는 것이 유용하다.

---

## 8. Sum of Squared Errors (SSE)

SSE는 Sum of Squared Errors의 약자이며, Residual의 제곱값을 모두 더한 지표이다.

$$
\boxed{ \mathrm{SSE} = \sum_{i=1}^{m}(y_i-\hat y_i)^2 }
$$

Residual을 사용하면 다음과 같다.

$$
\boxed{ \mathrm{SSE} = \sum_{i=1}^{m}r_i^2 }
$$

MSE와의 차이는 Sample 수로 나누는 과정이 없다는 것이다.

따라서 다음 관계가 성립한다.

$$
\boxed{ \mathrm{MSE}=\frac{\mathrm{SSE}}{m} }
$$

또는

$$
\boxed{ \mathrm{SSE}=m\cdot\mathrm{MSE} }
$$

이다.

---

### 8.1 SSE 계산 예제

앞의 데이터에서

$$
\mathbf r=[0,-1,2,-1]
$$

이므로

$$
\mathrm{SSE} = 0^2+(-1)^2+2^2+(-1)^2
$$

이다.

따라서

$$
\boxed{ \mathrm{SSE}=6 }
$$

이다.

SSE는 동일한 Dataset에서 Model들의 Squared Error를 비교하는 데 활용할 수 있다.

하지만 Sample 수가 증가하면 SSE도 커질 수 있으므로, Sample 수가 다른 Dataset의 SSE를 직접 비교하는 것은 적절하지 않을 수 있다.

통계에서는 SSE를 RSS(Residual Sum of Squares)라고 부르기도 한다.

---

# Part 3. Percentage-based Metrics

## 9. Percentage-based Metric이란?

앞에서 살펴본 MAE, MSE, RMSE는 실제 Target의 단위와 Scale에 영향을 받는다.

예를 들어 동일한 Prediction Problem에서도 Target을 원에서 천 원 단위로 변경하면 Error Metric의 값이 달라진다.

이때 상대적인 Prediction Error를 평가하고 싶다면 Percentage-based Metric을 고려할 수 있다.

Percentage-based Metric은 일반적으로 Residual을 실제값의 크기로 나누어 계산한다.

대표적인 방법은 다음과 같다.

- MAPE
- RMSPE

이러한 지표는 Target의 단위에 의존하지 않는다는 장점이 있다.

하지만 실제값이 0이거나 0에 가까운 경우 문제가 발생할 수 있다.

---

## 10. Mean Absolute Percentage Error (MAPE)

MAPE는 Mean Absolute Percentage Error의 약자이다.

각 Sample의 Absolute Residual을 실제값의 크기로 나눈 뒤 평균하는 지표이다.

$$
\boxed{ \mathrm{MAPE} = \frac{100}{m} \sum_{i=1}^{m} \left| \frac{y_i-\hat y_i}{y_i} \right| \% }
$$

여기서 $y_i\neq0$이라고 가정한다.

MAPE는 실제값을 기준으로 예측 오차가 어느 정도의 비율을 가지는지 나타낸다.

---

### 10.1 MAPE 계산 예제

다음 데이터를 사용하자.

| Sample | 실제값 | 예측값 | Absolute Percentage Error |
| --- | --- | --- | --- |
| 1 | 2 | 2 | 0% |
| 2 | 4 | 5 | 25% |
| 3 | 6 | 4 | 약 33.33% |
| 4 | 8 | 9 | 12.5% |

따라서

$$
\mathrm{MAPE} = \frac{ 0+25+33.33+12.5 }{4} \%
$$

이다.

결과적으로

$$
\boxed{ \mathrm{MAPE}\approx17.71\% }
$$

이다.

즉 이 Dataset에서 평균 Absolute Percentage Error는 약 17.71%이다.

---

### 10.2 MAPE의 특징

- Target의 원래 단위에 의존하지 않는다.
- 상대적인 Prediction Error를 표현한다.
- 결과를 Percentage로 해석하기 쉽다.
- 실제값이 0이면 수학적으로 정의되지 않는다.
- 실제값이 0에 가까우면 매우 큰 Error가 발생할 수 있다.

예를 들어 다음과 같은 상황을 생각하자.

$$
y=0.01,\qquad\hat y=0.11
$$

Absolute Error는 다음과 같다.

$$
|y-\hat y|=0.1
$$

이다.

하지만 Percentage Error는

$$
\left| \frac{0.01-0.11}{0.01} \right| \times100\%=1000\%
$$

이다.

따라서 실제값이 0에 가까운 Dataset에서는 MAPE가 매우 불안정할 수 있다.

또한 MAPE는 실제값을 분모로 사용하므로 실제값과 예측값을 교환하면 일반적으로 값이 달라진다.

따라서 MAPE는 수학적 Distance Metric이 아니다.

---

## 11. Root Mean Squared Percentage Error (RMSPE)

RMSPE는 Root Mean Squared Percentage Error의 약자이다.

MAPE처럼 Relative Error를 사용하지만, 각 Percentage Error를 제곱한 뒤 평균하고 Square Root를 적용한다.

$$
\boxed{ \mathrm{RMSPE} = 100 \sqrt{ \frac1m \sum_{i=1}^{m} \left( \frac{y_i-\hat y_i}{y_i} \right)^2 } \% }
$$

여기서도 $y_i\neq0$이라고 가정한다.

RMSPE는 MAPE보다 큰 Relative Error에 더 민감하다.

---

### 11.1 RMSPE 계산 예제

같은 데이터에서 Relative Error는 다음과 같다.

$$
\left[ 0, -\frac14, \frac26, -\frac18 \right]
$$

이다.

따라서

$$
\mathrm{RMSPE} = 100\sqrt{ \frac14 \left( 0^2+ \left(-\frac14\right)^2+ \left(\frac26\right)^2+ \left(-\frac18\right)^2 \right) } \%
$$

이다.

이를 계산하면

$$
\boxed{ \mathrm{RMSPE}\approx21.75\% }
$$

이다.

앞에서 계산한 MAPE는 약 17.71%였지만 RMSPE는 약 21.75%이다.

이는 RMSPE가 큰 Relative Error를 제곱하여 상대적으로 더 강하게 반영하기 때문이다.

---

## 12. MAPE와 RMSPE 비교

| 구분 | MAPE | RMSPE |
| --- | --- | --- |
| 기본 연산 | Absolute Percentage Error 평균 | Squared Percentage Error 평균 후 제곱근 |
| 단위 | % | % |
| 큰 상대 오차 | 선형적으로 반영 | 더 강하게 반영 |
| 실제값이 0인 경우 | 정의되지 않음 | 정의되지 않음 |
| 실제값이 0에 가까운 경우 | 불안정 | 불안정 |

따라서 Percentage-based Metric을 사용할 때는 실제값의 분포를 확인하는 것이 중요하다.

특히 Target에 0 또는 매우 작은 값이 많이 포함되어 있다면 MAPE와 RMSPE를 주요 Evaluation Metric으로 사용하는 것이 적절하지 않을 수 있다.

---

# Part 4. Coefficient of Determination

## 13. 결정계수 R²란?

**Coefficient of Determination(결정계수, R²)** 은 Regression Model의 성능을 평가하는 대표적인 지표이다.

앞에서 살펴본 MAE, MSE, RMSE는 실제값과 예측값의 차이가 얼마나 큰지 평가한다.

반면 R²는 **실제값의 평균만 예측하는 기준 모델과 비교했을 때 현재 모델이 얼마나 잘 예측하는지**를 나타낸다.

일반적으로 다음과 같이 정의한다.

$$
\boxed{ R^2 = 1- \frac{ \sum_{i=1}^{m}(y_i-\hat y_i)^2 }{ \sum_{i=1}^{m}(y_i-\bar y)^2 } }
$$

여기서

- $y_i$: 실제값
- $\hat y_i$: 예측값
- $\bar y$: 실제값의 평균
- $m$: Sample 수

이다.

실제값의 평균은 다음과 같다.

$$
\boxed{ \bar y= \frac1m\sum_{i=1}^{m}y_i }
$$

R²를 이해하려면 분자와 분모의 의미를 구분해야 한다.

---

## 14. SSE와 SST

R²의 분자와 분모에는 두 가지 Squared Sum이 사용된다.

### 14.1 SSE(Residual Sum of Squares)

SSE는 실제값과 모델의 예측값 사이에 발생하는 Squared Error의 합이다.

$$
\boxed{ \mathrm{SSE} = \sum_{i=1}^{m}(y_i-\hat y_i)^2 }
$$

즉 모델이 얼마나 많은 Prediction Error를 발생시키는지 나타낸다.

### 14.2 SST(Total Sum of Squares)

SST는 실제값이 평균으로부터 얼마나 떨어져 있는지 나타내는 Squared Sum이다.

$$
\boxed{ \mathrm{SST} = \sum_{i=1}^{m}(y_i-\bar y)^2 }
$$

여기서 SST는 실제값의 평균만 예측하는 단순한 기준 모델의 SSE에 해당한다.

따라서

$$
\boxed{ R^2=1-\frac{\mathrm{SSE}}{\mathrm{SST}} }
$$

이다.

이 식의 의미는 다음과 같다.

> 실제값의 평균을 예측하는 모델과 비교하여, 현재 Regression Model이 Squared Error를 얼마나 줄였는가?

즉 R²는 모델의 Error를 기준 모델의 Error와 비교한 상대적인 성능 지표이다.

---

## 15. R² 직접 계산하기

앞에서 사용한 데이터로 결정계수를 계산해 보자.

| Sample | 실제값 $y_i$ | 예측값 $\hat y_i$ |
| --- | --- | --- |
| 1 | 2 | 2 |
| 2 | 4 | 5 |
| 3 | 6 | 4 |
| 4 | 8 | 9 |

먼저 실제값의 평균을 계산한다.

$$
\bar y = \frac{2+4+6+8}{4}
$$

따라서

$$
\boxed{ \bar y=5 }
$$

이다.

---

### 15.1 SSE 계산

모델의 Squared Error는 다음과 같다.

$$
\mathrm{SSE} = (2-2)^2+(4-5)^2+(6-4)^2+(8-9)^2
$$

$$
=0+1+4+1
$$

따라서

$$
\boxed{ \mathrm{SSE}=6 }
$$

이다.

---

### 15.2 SST 계산

실제값과 평균의 Squared Difference를 계산한다.

$$
\mathrm{SST} = (2-5)^2+(4-5)^2+(6-5)^2+(8-5)^2
$$

$$
=9+1+1+9
$$

따라서

$$
\boxed{ \mathrm{SST}=20 }
$$

이다.

---

### 15.3 R² 계산

결정계수의 정의에 대입한다.

$$
R^2 = 1-\frac{\mathrm{SSE}}{\mathrm{SST}}
$$

$$
= 1-\frac6{20}
$$

따라서

$$
\boxed{ R^2=0.7 }
$$

이다.

이 결과는 현재 모델이 해당 평가 데이터에서 평균 예측 기준 모델보다 SSE를 70% 줄였다는 의미이다.

이를 단순히 **모델의 예측 정확도가 70%이다**라고 해석해서는 안 된다.

R²는 Classification Accuracy와 다른 지표이기 때문이다.

---

## 16. R²의 값은 어떻게 해석할까?

R²는 일반적으로 값이 클수록 좋은 Regression Performance를 나타낸다.

대표적인 해석은 다음과 같다.

| R² | 의미 |
| --- | --- |
| $R^2=1$ | 모든 예측값이 실제값과 일치 |
| $0<R^2<1$ | 평균 예측 기준보다 낮은 SSE |
| $R^2=0$ | 평균 예측 기준과 같은 SSE |
| $R^2<0$ | 평균 예측 기준보다 높은 SSE |

여기서 중요한 점은 **R²가 항상 0과 1 사이의 값을 가지는 것은 아니라는 사실**이다.

특히 Machine Learning에서는 Test Set에서 R²가 음수로 나타날 수 있다.

---

## 17. R²가 음수가 되는 이유

R²는 다음과 같이 정의한다.

$$
\boxed{ R^2=1-\frac{\mathrm{SSE}}{\mathrm{SST}} }
$$

만약 현재 모델의 SSE가 기준 모델의 SST보다 크다면

$$
\mathrm{SSE}>\mathrm{SST}
$$

이다.

따라서

$$
\frac{\mathrm{SSE}}{\mathrm{SST}}>1
$$

이고

$$
\boxed{ R^2<0 }
$$

이다.

예를 들어 실제값이 다음과 같다고 하자.

$$
\mathbf y=[2,4,6,8]
$$

모델이 모든 Sample에서 다음과 같이 예측한다고 가정한다.

$$
\hat{\mathbf y}=[8,8,8,8]
$$

이 경우

$$
\mathrm{SSE} = (2-8)^2+(4-8)^2+(6-8)^2+(8-8)^2
$$

$$
=36+16+4+0=56
$$

이다.

앞에서 계산한 SST는 20이므로

$$
R^2 = 1-\frac{56}{20}
$$

따라서

$$
\boxed{ R^2=-1.8 }
$$

이다.

이는 해당 모델이 실제값의 평균 5만 예측하는 모델보다도 더 큰 Squared Error를 발생시켰다는 의미이다.

따라서 R²가 음수라는 것은 모델의 Regression Performance가 좋지 않다는 신호일 수 있다.

---

## 18. R²를 해석할 때 주의할 점

### 18.1 R²는 Accuracy가 아니다

R²는 Classification Accuracy와 다른 개념이다.

$$
R^2=0.9
$$

라고 해서 예측값의 90%가 정확하다는 뜻은 아니다.

해당 평가 데이터에서 평균 예측 기준 대비 Squared Error를 얼마나 줄였는지 나타내는 것이다.

---

### 18.2 R²는 실제 Error의 크기를 알려주지 않는다

R²는 상대적인 성능 지표이다.

따라서

$$
R^2=0.95
$$

라고 하더라도 MAE나 RMSE가 실제로 얼마인지 알 수 없다.

예를 들어 같은 R²를 가지는 두 Regression Model도 Target의 Scale이 다르면 실제 Prediction Error의 크기는 크게 달라질 수 있다.

따라서 R²는 MAE 또는 RMSE와 함께 확인하는 것이 좋다.

---

### 18.3 R²가 반드시 Correlation Coefficient의 제곱은 아니다

전통적인 통계학에서는 Intercept를 포함한 OLS(Ordinary Least Squares) Regression을 이용할 때 R²를 설명력의 비율로 해석할 수 있다.

이 경우 다음과 같은 관계가 성립한다.

$$
\boxed{ \mathrm{SST} = \mathrm{ESS}+\mathrm{SSE} }
$$

여기서 ESS는 Explained Sum of Squares이다.

$$
\boxed{ \mathrm{ESS} = \sum_i(\hat y_i-\bar y)^2 }
$$

따라서 해당 조건에서는

$$
\boxed{ R^2=\frac{\mathrm{ESS}}{\mathrm{SST}} }
$$

로 표현할 수 있다.

하지만 이러한 분해는 모든 Regression Model에 대해 성립하는 것은 아니다.

특히 일반적인 Non-linear Model 또는 Test Set에서의 평가에서는

$$
\mathrm{SST}=\mathrm{ESS}+\mathrm{SSE}
$$

를 그대로 적용할 수 없다.

따라서 Machine Learning에서는 보다 일반적인 정의인 다음 식을 사용하는 것이 안전하다.

$$
\boxed{ R^2=1-\frac{\mathrm{SSE}}{\mathrm{SST}} }
$$

이 내용은 R²를 단순한 Correlation Coefficient의 제곱과 혼동하지 않기 위한 보충 설명이다.

---

### 18.4 실제값이 모두 같은 경우

실제 Target이 모두 동일한 값이라고 하자.

$$
\mathbf y=[5,5,5,5]
$$

이 경우 실제값의 평균도 5이다.

따라서

$$
\mathrm{SST} = \sum_i(y_i-\bar y)^2=0
$$

이다.

R² 식에서 분모가 0이 되므로 일반적인 정의로는 계산할 수 없다.

scikit-learn의 `r2_score()`는 기본적으로 `force_finite=True`를 사용하며, 이러한 상황을 특별하게 처리한다.

- 완벽한 예측: 1.0으로 반환
- 완벽하지 않은 예측: 0.0으로 반환

반면 `force_finite=False`를 사용하면 원래의 NaN 또는 음의 무한대 결과를 확인할 수 있다.

따라서 R²를 사용할 때는 Evaluation Dataset의 Target Variance도 확인해야 한다.

# Part 5. Regression Evaluation Metric 비교

## 19. 전체 지표 비교

| Metric | 핵심 계산 | 단위 | 최적값 | 특징 |
| --- | --- | --- | --- | --- |
| MAE | Absolute Error 평균 | Target과 동일 | 0 | 평균적인 절댓값 오차 |
| MSE | Squared Error 평균 | Target 단위의 제곱 | 0 | 큰 Error에 민감 |
| RMSE | MSE의 제곱근 | Target과 동일 | 0 | 큰 Error를 강조하면서 원래 단위 사용 |
| SSE | Squared Error 합 | Target 단위의 제곱 | 0 | Sample 수의 영향을 받음 |
| MAPE | Absolute Percentage Error 평균 | % | 0% | 상대적 오차율 |
| RMSPE | Squared Percentage Error의 제곱근 | % | 0% | 큰 상대 오차에 민감 |
| R² | 평균 예측 기준 대비 SSE 감소 | 무차원 | 1 | 기준 모델 대비 상대적인 예측 성능 |

이 표에서 중요한 점은 각 Metric이 서로 다른 관점에서 Regression Performance를 나타낸다는 것이다.

따라서 하나의 Metric만으로 모델의 모든 성능 특성을 설명하기는 어렵다.

---

## 20. 어떤 Regression Metric을 선택해야 할까?

평가 목적에 따라 Metric을 선택해야 한다.

**① 실제 단위에서 평균 Error를 확인하고 싶다면**

MAE를 고려할 수 있다.

예를 들어 혈압 예측에서 평균적으로 몇 mmHg의 Error가 발생하는지 알고 싶은 경우이다.

**② 큰 Prediction Error가 중요하다면**

RMSE 또는 MSE를 고려할 수 있다.

일부 Sample에서 매우 큰 Error가 발생하는 것을 강하게 반영하고 싶을 때 유용하다.

**③ 상대적인 Error가 중요하다면**

MAPE 또는 RMSPE를 고려할 수 있다.

다만 Target이 0 또는 0에 가까운 값을 포함한다면 주의해야 한다.

**④ 평균 예측 기준보다 얼마나 좋은지 확인하고 싶다면**

R²를 사용할 수 있다.

R²는 현재 모델이 평균만 예측하는 기준 모델보다 얼마나 좋은 성능을 보이는지 비교하는 데 유용하다.

따라서 Regression Evaluation에서는 다음과 같은 조합을 사용할 수 있다.

```text
Regression Evaluation
         │
         ├── MAE
         │     └── 평균 Absolute Error
         │
         ├── RMSE
         │     └── 큰 Error에 대한 민감도
         │
         └── R²
               └── 평균 예측 기준 대비 성능
```

물론 실제 Metric 선택은 Dataset과 Application의 요구사항에 따라 달라질 수 있다.

# Part 6. Python으로 Regression Metric 계산하기

## 21. scikit-learn을 이용한 계산

앞에서 사용한 예제 데이터를 Python으로 계산해 보자.

```python
import numpy as np

from sklearn.metrics import (
    mean_absolute_error,
    mean_squared_error,
    root_mean_squared_error,
    mean_absolute_percentage_error,
    r2_score
)

# Actual / Predicted
y_true = np.array([2, 4, 6, 8])
y_pred = np.array([2, 5, 4, 9])

# Residual-based Metrics
mae = mean_absolute_error(y_true, y_pred)
mse = mean_squared_error(y_true, y_pred)
rmse = root_mean_squared_error(y_true, y_pred)

sse = np.sum((y_true - y_pred) ** 2)

# Percentage-based Metrics
mape = 100 * mean_absolute_percentage_error(
    y_true,
    y_pred
)

rmspe = 100 * np.sqrt(
    np.mean(
        ((y_true - y_pred) / y_true) ** 2
    )
)

# Coefficient of Determination
r2 = r2_score(y_true, y_pred)

print(f"MAE   : {mae:.4f}")
print(f"MSE   : {mse:.4f}")
print(f"RMSE  : {rmse:.4f}")
print(f"SSE   : {sse:.4f}")
print(f"MAPE  : {mape:.2f}%")
print(f"RMSPE : {rmspe:.2f}%")
print(f"R²    : {r2:.4f}")
```

결과는 다음과 같다.

```text
MAE   : 1.0000
MSE   : 1.5000
RMSE  : 1.2247
SSE   : 6.0000
MAPE  : 17.71%
RMSPE : 21.75%
R²    : 0.7000
```

여기서 주의할 점은 scikit-learn의 `mean_absolute_percentage_error()`가 결과를 백분율이 아니라 비율 형태로 반환한다는 것이다.

예를 들어 반환값이 `0.2`이면 20%에 해당한다.

따라서 Percentage로 표시하려면 100을 곱해야 한다.

또한 `root_mean_squared_error()`는 별도의 RMSE 함수로 제공된다.

## 22. PyTorch에서 계산하기

PyTorch에서도 Tensor Operation을 이용하여 Regression Metric을 계산할 수 있다.

```python
import torch
import torch.nn as nn

y_true = torch.tensor(
    [2.0, 4.0, 6.0, 8.0]
)

y_pred = torch.tensor(
    [2.0, 5.0, 4.0, 9.0]
)

# MAE
mae = nn.L1Loss()(y_pred, y_true)

# MSE
mse = nn.MSELoss()(y_pred, y_true)

# RMSE
rmse = torch.sqrt(mse)

# SSE
sse = torch.sum(
    (y_true - y_pred) ** 2
)

# MAPE
mape = 100 * torch.mean(
    torch.abs(
        (y_true - y_pred) / y_true
    )
)

# RMSPE
rmspe = 100 * torch.sqrt(
    torch.mean(
        ((y_true - y_pred) / y_true) ** 2
    )
)

# R²
ss_res = torch.sum(
    (y_true - y_pred) ** 2
)

ss_tot = torch.sum(
    (y_true - torch.mean(y_true)) ** 2
)

r2 = 1 - ss_res / ss_tot

print("MAE  :", mae.item())
print("MSE  :", mse.item())
print("RMSE :", rmse.item())
print("SSE  :", sse.item())
print("MAPE :", mape.item())
print("RMSPE:", rmspe.item())
print("R²   :", r2.item())
```

이 예제는 Target이 0이 아니고 SST가 0이 아닌 경우를 가정한다.

실제 모델을 평가할 때는 0으로 나누는 상황과 Multi-output Regression 등의 조건을 추가로 고려해야 한다.

# 23. Loss Function과 Evaluation Metric의 차이

MSE와 MAE는 Loss Function으로도 사용되고 Evaluation Metric으로도 사용된다.

그렇다면 두 개념은 무엇이 다를까?

**Loss Function**

Training 과정에서 Model Parameter를 업데이트하기 위해 최소화하는 Objective이다.

**Evaluation Metric**

학습된 모델의 예측 성능을 정량적으로 평가하기 위해 사용하는 지표이다.

예를 들어 다음과 같은 Training Process를 생각할 수 있다.

```text
Training Dataset
       │
       ▼
Model Prediction
       │
       ▼
MSE Loss Calculation
       │
       ▼
Backpropagation
       │
       ▼
Parameter Update
       │
       ▼
Model Evaluation
       │
       ├── MAE
       ├── RMSE
       └── R²
```

MSE를 Loss Function으로 사용하더라도 모델 평가에는 MAE, RMSE, R² 등을 함께 사용할 수 있다.

즉 Loss Function과 Evaluation Metric은 같은 수식을 사용할 수도 있지만, 사용 목적이 다르다.

# 24. 최종 정리

Regression은 연속적인 Target Value를 예측하는 Supervised Learning Task이다.

Regression Model의 성능을 평가하기 위해서는 실제값과 예측값의 차이를 정량적으로 측정해야 한다.

이때 사용하는 대표적인 개념이 Residual이다.

$$
\boxed{ r_i=y_i-\hat y_i }
$$

Residual을 기반으로 다양한 Evaluation Metric을 계산할 수 있다.

MAE는 Absolute Residual을 평균하여 평균적인 예측 오차를 나타낸다.

MSE는 Residual을 제곱하여 큰 Error를 강하게 반영한다.

RMSE는 MSE에 Square Root를 적용하므로 Target과 동일한 단위로 Error를 해석할 수 있다.

SSE는 Squared Residual을 합산한 값이며, Sample 수의 영향을 받는다.

MAPE와 RMSPE는 실제값을 기준으로 상대적인 Percentage Error를 나타낸다.

하지만 실제값이 0 또는 0에 가까운 상황에서는 계산이 불안정할 수 있다.

마지막으로 R²는 평균 예측 기준 모델과 비교하여 현재 모델의 상대적인 Prediction Performance를 평가한다.

$$
\boxed{ R^2 = 1-\frac{\mathrm{SSE}}{\mathrm{SST}} }
$$

여기서 R²는 1이 최적값이며, 평균 예측 기준보다 성능이 나쁘면 음수가 될 수 있다.

따라서 Regression Performance는 하나의 Metric만으로 판단하기보다, Evaluation Objective에 적합한 여러 Metric을 함께 사용하는 것이 좋다.

전체적인 관계를 정리하면 다음과 같다.

```text
Regression Evaluation
          │
          ▼
       Residual
          │
          ├── Residual-based Metrics
          │      ├── MAE
          │      ├── MSE
          │      ├── RMSE
          │      └── SSE
          │
          ├── Percentage-based Metrics
          │      ├── MAPE
          │      └── RMSPE
          │
          └── Baseline-relative Metric
                 │
                 ▼
                 R²
```

**핵심은 각각의 Evaluation Metric이 무엇을 측정하는지 이해하고, 실제 Application에서 중요한 Error의 특성에 따라 적절한 지표를 선택하는 것이다.**

## 핵심 요약

> Regression Evaluation Metric은 실제값과 예측값의 차이를 정량적으로 평가하기 위한 지표이다. MAE는 평균 Absolute Error, MSE는 평균 Squared Error, RMSE는 큰 Error를 강조하면서 Target과 같은 단위를 제공한다. MAPE와 RMSPE는 상대적인 Percentage Error를 나타내며, R²는 실제값의 평균을 예측하는 기준 모델 대비 얼마나 좋은 성능을 보이는지 평가한다. 따라서 모델의 Regression Performance를 정확하게 이해하려면 각 Metric의 수학적 의미와 한계를 함께 고려해야 한다.
