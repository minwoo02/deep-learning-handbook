## 확인된 차이와 보존 원칙

- Perceptron 예제는 Iris 3개 class를 사용합니다. 이전 대화의 binary 예시를 적용하지 않았습니다.
- XOR c08은 모델 클래스만 있습니다. Loss·Optimizer·학습 결과는 미확인으로 표시합니다.
- 회귀 c06은 이미 수동 gradient, autograd, SGD, nn.Linear, CelsiusANN, Dataset/DataLoader를 포함합니다.
- c07과 c09는 모두 Iris이지만 구조와 범위가 달라 원문을 각각 유지합니다.
- CNN·RNN 독립 실습 글은 시리즈 목록에 없습니다. 정규화 글의 CNN 예제를 완성된 CNN 과정으로 재분류하지 않습니다.
- 복수 예제 글의 구성표는 예제별 차이를 명시합니다. API 내부 기본 loss는 실제 코드에 지정되지 않은 경우 추정하지 않습니다.
- 코드 조각은 순서·언어·SHA-256과 함께 examples/fragments에 저장합니다. 일부는 부분 코드·출력·텍스트 도표이므로 모두 연결해 실행하지 않습니다.
- 본문 이미지 15개를 로컬로 보존하고 이관본에서 연결했습니다. 원래 URL과 이미지 SHA-256은 sources/image-manifest.json에 보존합니다. 외부 링크 전체의 가용성 검증은 별도입니다.
